Exercise 1 · Shop stock · about 38 min

The form saves the products of a shop. Each product is an object: { name: "Mouse", code: "MOU-001", price: 15.5, units: 10 }.

  1. Opening. When the page loads, ask with prompt who opens the shop and write Shop opened by Ana in the console (or Shop opened if they press Cancel or write nothing).
  2. Load and save. Read the products from localStorage (key products) or start with an empty array. If the saved data is broken, start with an empty array: the page must not break. Every time you save, show the array as a table in the console.
  3. Draw. The list is built with createElement: one line per product with a Delete button. Use the function unitsText for the units:
    Mouse (MOU-001) · 15,50 € · 10 units [Delete]
    Under the list, with filter, reduce and toLocaleString:
    3 products · 1 out of stock · stock value: 1.422,00 €
  4. unitsText. The function is given, but it has 2 errors. Write three console.assert (normal, edge and strange case), find the errors and fix them, with a comment above each line you fix. Write its JSDoc.
  5. Save a product. When the form is sent (the page must not reload):
    • The code is saved in capital letters. The price can be written with a comma (15,50): change it to a dot with replace and a regular expression.
    • Check: the name has from 1 to 30 characters; the code is 3 letters, a dash and 3 digits (regular expression); the price is a number bigger than 0; the units are a number, 0 or more.
    • If there are errors: show all of them in red, mark the wrong fields with the class wrong and put the cursor in the first one. Fixed fields stop being red.
    • If everything is right: if a product with that code already exists, add the units to it; if not, add a new product. Save, draw, show Product saved. in green, empty the form and put the cursor in the name.
  6. Counter. While the user types the name, show 7 / 30 next to it, in red over 30.
  7. Delete. One single listener on the list for all the Delete buttons (event.target and data-). It removes the product, saves and draws.

Exercise 2 · Shelves · about 12 min

START_SHELVES has the units in each place of the shelves when the shop opens (0 = empty).

  1. Draw the shelves as a table built with createElement and two loops, one inside the other. The empty places have the class empty. Under it: Empty places: 3 · Total units: 25.
  2. When the user clicks a place, it gets one more unit. Use one single listener on the table: each cell knows its row and its column with data-.
  3. The shelves are saved in localStorage (key shelves) every time they change, and loaded when the page opens (or START_SHELVES if there is nothing or it is broken).
  4. Start again asks for confirmation with confirm and puts back the units of START_SHELVES, which must never change.

Before you hand in

  • Try the form with wrong and right data, press F5, delete a product, click the shelves and press F5 again.
  • To start from zero, delete the keys in DevTools → Application → Local Storage. The console must not show any red error.
