Variables and data types
What is a variable? A variable is a *box with a name* where you keep a value, so you can use it later. let score = 0; document.write(score + "<br>"); // 0 score = 10; document.write(score + "<br>"); // 10 `=` is not "equals" in the maths sense. It means *"put this value in this box"*. You read it from right to left. let and const let points = 0; // I can change it later points = 5; // fine const PI = 3.14159; // I cannot change it PI = 3; // TypeError: Assignment to constant variable
  • Use `const` by default. It protects you: if you try to change it by accident, the browser tells you.
  • Use `let` when the value really has to change (a counter, a total, a user answer).
  • You will see `var` in old code. *Do not use it.* It behaves in strange ways.
    •      Rules for names
  • Letters, numbers, `_` and `$`. *No spaces*, and it cannot start with a number.
  • JavaScript is *case sensitive*: `score`, `Score` and `SCORE` are three different variables.
  • Use *camelCase*: `userName`, `totalPrice`, `isLoggedIn`.
  • Name things for what they hold. `x` and `data2` tell you nothing. `remainingLives` tells you everything.
    •      Data types // String: text. Always between quotes let name = "Marta"; let city = 'Valencia'; // Number: whole numbers and decimals, all the same type let age = 16; let price = 19.95; // Boolean: only two values let isStudent = true; let hasPassed = false; // Nothing let prize = null; // "empty on purpose" let unknown; // undefined: declared, never given a value To ask what type something is: document.write(typeof "hello" + "<br>"); // "string" document.write(typeof 16 + "<br>"); // "number" document.write(typeof true + "<br>"); // "boolean" "5" and 5 are NOT the same thing. The first is text, the second is a number. "5" + 1 gives "51". 5 + 1 gives 6. This single confusion causes a huge number of bugs. Template literals Joining text with `+` gets ugly fast: let name = "Marta"; let age = 16; document.write("Hello, " + name + ". You are " + age + " years old.<br>"); With backticks `` ` `` you can put variables inside the text with `${ }`: document.write(`Hello, ${name}. You are ${age} years old.<br>`); The backtick is not the same key as the normal quote. On a Spanish keyboard it is next to the `P`. Use this style from now on: it is shorter and much easier to read. Reading data from the user let name = prompt("Your name?"); let ageText = prompt("Your age?"); *Careful: `prompt` always gives you a string*, even if the user types a number. Converting types let ageText = "16"; let age = Number(ageText); // 16 as a number let age2 = parseInt("16 years"); // 16 (reads until it is not a number) let price = parseFloat("19.95"); // 19.95 let text = String(16); // "16" let text2 = (16).toString(); // "16" document.write(Number("hello")); // NaN = Not a Number `NaN` means "this is not a number". If you see `NaN` in your page, somewhere you did maths with something that was not a number.
