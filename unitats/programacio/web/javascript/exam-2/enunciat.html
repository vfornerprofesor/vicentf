Exercise 1 · Final mark of a student · about 25 min

The final mark of the module is: 30 % exam 1 + 30 % exam 2 + 40 % project. When the user clicks Calculate, the page shows the final mark with two decimals and its word, in green if it is a pass and in red if it is a fail.

  1. readMark(input) returns the mark of a field as a number. If the field is empty, if it is not a number or if it is not between 0 and 10, it throws an error with the name "ValidationError" and a clear message, different for each case.
  2. finalMark(exam1, exam2, project) returns the final mark.
  3. gradeWord(mark) returns "Fail" (less than 5), "Pass" (5 to less than 7), "Good" (7 to less than 9) or "Excellent" (9 or more).
  4. The listener uses the three functions. If there is an error, it shows its message in red and the program never breaks. With correct marks, the old error disappears.
  5. Write the JSDoc comment of readMark, with the errors it throws.
Examples 6, 7, 7.5 → Final mark: 6.90 · Pass (green)
6, abc, 7 → "abc" is not a number. (red)
6, 7, 11 → The marks go from 0 to 10. (red)

Tip: isNaN(x) is true when x is not a number. The classes ok (green) and error (red) are already in the HTML.

Exercise 2 · The group · about 22 min

In script.js there is the array groupMarks. A negative mark means "end of the list": that mark and all the marks after it do not count.

  1. The function bestMark(marks) is given, but it has 3 errors (the page will not work until you fix the first one). Write three console.assert for it (a normal case, an edge case and a strange case), use them to find the errors and fix them. Above each line you fix, write a comment with the line, the type of error (syntax or logic) and what was wrong.
  2. When the user clicks Show the group, a loop builds a table with one row per mark: the number of the student, the mark and its word (use your gradeWord), the word in green or red. The loop stops at the first negative mark.
  3. Under the table: how many marks, how many passed, how many failed, the average with two decimals and the best mark (use bestMark).
Expected summary 6 marks · 4 passed · 2 failed · average 6.33 · best 9.5
