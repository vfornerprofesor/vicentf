Arrays
What is an array An array is a *list of values* with one name. Each value has a position, called the *index*. const fruits = ["apple", "banana", "orange"]; const marks = [7, 4, 9, 10]; const mixed = ["Marta", 16, true]; // possible, but avoid it const empty = []; Reading and changing *Indexes start at 0.* The first element is `[0]`, not `[1]`. This surprises everybody at first, and then it becomes normal. const fruits = ["apple", "banana", "orange"]; output.textContent = fruits[0]; // "apple" output.textContent = fruits[2]; // "orange" output.textContent = fruits[5]; // undefined (there is nothing there) fruits[1] = "pear"; // ["apple", "pear", "orange"] We wrote const fruits, and yet we changed an element. That is allowed: const protects the *box*, not what is inside. You cannot do fruits = [...] again, but you can change, add and remove elements. length const fruits = ["apple", "banana", "orange"]; output.textContent = fruits.length; // 3 output.textContent = fruits[fruits.length - 1]; // "orange", the last one Adding and removing const list = ["a", "b"]; list.push("c"); // add at the end -> ["a", "b", "c"] list.pop(); // remove the last one -> ["a", "b"] list.unshift("z"); // add at the start -> ["z", "a", "b"] list.shift(); // remove the first one -> ["a", "b"] list.splice(1, 1); // remove 1 element starting at index 1 -> ["a"] Searching const names = ["Ana", "Luis", "Marta"]; names.includes("Luis"); // true names.indexOf("Marta"); // 2 names.indexOf("Pere"); // -1 (it is not there) `indexOf` gives `-1` when it does not find it. Remember that number: `if (names.indexOf(x) === -1)` means "it is not in the list". Going through an array const marks = [7, 4, 9, 10]; // With for...of: simple, when you do not need the index for (const mark of marks) { // ... } // With for: when you need the index for (let i = 0; i < marks.length; i++) { // `Student ${i + 1}: ${marks[i]}` } Drawing an array in the page This is the pattern you will repeat for the rest of the unit and in your project. *One function that draws the whole list from the array*, called every time the data changes: const names = ["Ana", "Luis", "Marta"]; const output = document.querySelector("#output"); function draw() { let html = "<ul>"; for (const name of names) { html += `<li>${name}</li>`; } html += "</ul>"; output.innerHTML = html; } draw(); // Add one and redraw document.querySelector("#addButton").addEventListener("click", function () { const input = document.querySelector("#nameInput"); const value = input.value.trim(); if (value === "") { return; // nothing typed: do nothing } names.push(value); input.value = ""; draw(); // the array changed, so we draw again }); Never change the page and the array separately. Change the ARRAY, then call draw(). The array is the truth; the page is only a picture of it. If you follow this rule your project will work. If you do not, you will spend hours wondering why the screen and the data disagree. `.trim()` removes the spaces at the start and at the end. Without it, a user could add an item made only of spaces. Useful methods const words = ["one", "two", "three"]; words.join(", "); // "one, two, three" words.slice(0, 2); // ["one", "two"] (a copy, does not change the original) words.reverse(); // ["three", "two", "one"] const numbers = [10, 3, 25, 7]; numbers.sort((a, b) => a - b); // [3, 7, 10, 25] from small to big Plain sort() sorts as *text*: [10, 3, 25] becomes [10, 25, 3], because "1" comes before "2".
