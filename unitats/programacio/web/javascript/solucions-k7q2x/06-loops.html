Exercici 6.1

Exercise 6.1. Show the numbers from 1 to 20 in the page, one per line. Do it with while and then with for.

Solució

script.js 
// with while
let i = 1;
while (i <= 20) {
    document.write(i + "<br>");
    i++;
}

// with for
document.write("<hr>");
for (let n = 1; n <= 20; n++) {
    document.write(n + "<br>");
}

Exercici 6.2

Exercise 6.2. Show the even numbers from 0 to 50, separated by commas.

Solució

script.js 
let text = "";

for (let n = 0; n <= 50; n += 2) {
    text += n;
    if (n < 50) {
        text += ", ";
    }
}

document.write(text);

Resultat

Exercici 6.3

Exercise 6.3. The user types a number and the page draws its multiplication table as an HTML table.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Multiplication table</title>
</head>

<body>
    <input type="number" id="value" placeholder="A number">
    <button id="draw">Draw</button>
    <div id="output"></div>

    <script>
        document.querySelector("#draw").addEventListener("click", function () {
            const number = Number(document.querySelector("#value").value);
            let rows = "";

            for (let i = 1; i <= 10; i++) {
                rows += `<tr><td>${number} x ${i}</td><td>${number * i}</td></tr>`;
            }

            document.querySelector("#output").innerHTML = "<table>" + rows + "</table>";
        });
    </script>
</body>

</html>

Exercici 6.4

Exercise 6.4. Draw a triangle of stars of the height the user asks for, inside a <pre> so the spaces are respected: 
*
**
***
****
*****

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Triangle of stars</title>
</head>

<body>
    <input type="number" id="value" placeholder="Height">
    <button id="draw">Draw</button>
    <div id="output"></div>

    <script>
        document.querySelector("#draw").addEventListener("click", function () {
            const height = Number(document.querySelector("#value").value);
            let text = "";

            for (let row = 1; row <= height; row++) {
                for (let i = 1; i <= row; i++) {
                    text += "*";
                }
                text += "\n";
            }

            document.querySelector("#output").innerHTML = "<pre>" + text + "</pre>";
        });
    </script>
</body>

</html>

Exercici 6.5

Exercise 6.5. Chessboard. Draw an 8 × 8 board of <div>s, alternating black and white. Two loops, one inside the other. The trick for the colour: (row + column) % 2 === 0.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Chessboard</title>
    <style>
        .row {
            display: flex;
        }

        .square {
            width: 40px;
            height: 40px;
            border: 1px solid #888888;
        }
    </style>
</head>

<body>
    <div id="output"></div>

    <script>
        let html = "";

        for (let row = 0; row < 8; row++) {
            html += "<div class='row'>";
            for (let column = 0; column < 8; column++) {
                const colour = (row + column) % 2 === 0 ? "white" : "black";
                html += `<div class="square" style="background: ${colour}"></div>`;
            }
            html += "</div>";
        }

        document.querySelector("#output").innerHTML = html;
    </script>
</body>

</html>
El truc del color: (row + column) % 2 === 0 és cert en les caselles d'un color i fals en les de l'altre.

Exercici 6.6

Exercise 6.6. Colour ramp. Draw 20 boxes in a row, each one a little darker than the one before. (backgroundColor = 'rgb(' + v + ',' + v + ',' + v + ')')

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Colour ramp</title>
    <style>
        #output {
            display: flex;
        }

        .box {
            width: 30px;
            height: 60px;
        }
    </style>
</head>

<body>
    <div id="output"></div>

    <script>
        let html = "";

        for (let i = 0; i < 20; i++) {
            const v = 255 - i * 12;   // every box is a little darker
            html += `<div class="box" style="background-color: rgb(${v}, ${v}, ${v})"></div>`;
        }

        document.querySelector("#output").innerHTML = html;
    </script>
</body>

</html>

Exercici 6.7

Exercise 6.7. Given const marks = [4, 8, 6, 2, 9, 5];, show the highest mark, the lowest mark and the average. Do not use Math.max: find it with a loop.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Marks</title>
</head>

<body>
    <p id="output"></p>

    <script>
        const marks = [4, 8, 6, 2, 9, 5];
        let highest = marks[0];
        let lowest = marks[0];
        let total = 0;

        for (const mark of marks) {
            if (mark > highest) {
                highest = mark;
            }
            if (mark < lowest) {
                lowest = mark;
            }
            total += mark;
        }

        document.querySelector("#output").innerHTML = `Highest: ${highest}<br>Lowest: ${lowest}<br>Average: ${total / marks.length}`;
    </script>
</body>

</html>
Es comença amb el primer element de l'array, no amb 0: si es comença amb 0, cap nota negativa seria mai la mínima.
