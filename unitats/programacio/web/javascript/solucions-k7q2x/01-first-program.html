Exercici 1.1

Exercise 1.1. Create the two files (index.html and script.js) and write "Hello, my name is ..." in the page.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My first program</title>
</head>

<body>
    <h1>My first program</h1>
    <script src="script.js"></script>
</body>

</html>
script.js 
document.write("Hello, my name is Marc.");

Resultat

Exercici 1.2

Exercise 1.2. Write the result of 7 * 8, of 100 / 3 and of 10 - 4, each one on its own line in the page.

Solució

script.js 
document.write(7 * 8 + "<br>");
document.write(100 / 3 + "<br>");
document.write(10 - 4 + "<br>");
Es suposa el mateix index.html de l'exercici 1.1 (amb <script src="script.js"></script> al final del body); només canvia el script.js. Resultats: 56, 33.333333333333336 i 6.

Resultat

Exercici 1.3

Exercise 1.3. Use prompt to ask for the user's name, and then write a greeting in the page (not in an alert).

Solució

script.js 
const name = prompt("What is your name?");
document.write("Hello, " + name + "! Nice to meet you.");
Es suposa el mateix index.html de l'exercici 1.1 (amb <script src="script.js"></script> al final del body); només canvia el script.js.

Resultat

Dades de prova usades en la previsualització: Marc

Exercici 1.4

Exercise 1.4. Ask for the user's name and their favourite colour, and write a sentence with both.

Solució

script.js 
const name = prompt("What is your name?");
const colour = prompt("What is your favourite colour?");
document.write(name + " likes " + colour + ".");
Es suposa el mateix index.html de l'exercici 1.1 (amb <script src="script.js"></script> al final del body); només canvia el script.js.

Resultat

Dades de prova usades en la previsualització: Marc, green

Exercici 1.5

Exercise 1.5. Break your code on purpose: remove a ). Open the console, read the error, and write down which type of error it is and on which line.

Solució

script.js 
// the closing parenthesis is missing on purpose
document.write("Hello, my name is Marc."
Resposta: la consola mostra Uncaught SyntaxError: missing ) after argument list, amb el nom del fitxer i la línia on el navegador ha deixat de poder llegir el codi. És un error de sintaxi: el codi està mal escrit i no s'executa res d'eixe fitxer.
