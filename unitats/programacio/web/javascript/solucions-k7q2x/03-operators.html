Exercici 3.1

Exercise 3.1. Ask for the price of a product and write the price with 21 % VAT added.

Solució

script.js 
const price = Number(prompt("Price of the product?"));
const withVat = price * 1.21;
document.write(`${price} EUR + 21 % VAT = ${withVat.toFixed(2)} EUR`);

Resultat

Dades de prova usades en la previsualització: 100

Exercici 3.2

Exercise 3.2. Ask for a number of seconds and write how many minutes and how many seconds are left. (Use /, Math.floor() and %.)

Solució

script.js 
const total = Number(prompt("How many seconds?"));
const minutes = Math.floor(total / 60);
const seconds = total % 60;
document.write(`${total} seconds = ${minutes} min and ${seconds} s`);

Resultat

Dades de prova usades en la previsualització: 200

Exercici 3.4

Exercise 3.4. Say what each of these writes, without running it: 
document.write(10 % 3);
document.write("10" === 10);
document.write("10" == 10);
document.write(true && false);
document.write(!(3 > 5));

Solució

script.js 
document.write(10 % 3);        // 1      the remainder of 10 / 3
document.write("10" === 10);   // false  different types
document.write("10" == 10);    // true   == converts the types
document.write(true && false); // false  both must be true
document.write(!(3 > 5));      // true   3 > 5 is false, and ! reverses it
Resposta: 1, false, true, false i true (escrits tots seguits: 1falsetruefalsetrue).

Resultat

Exercici 3.5

Exercise 3.5. A person can enter a concert if they are 16 or older and they have a ticket, or if they are on the guest list. Write the condition with variables age, hasTicket and isGuest, and show the result in the page.

Solució

script.js 
const age = 17;
const hasTicket = true;
const isGuest = false;

const canEnter = (age >= 16 && hasTicket) || isGuest;
document.write("Can enter the concert: " + canEnter);
Els parèntesis deixen clar què es combina primer: (edat i entrada) o llista de convidats. Prova amb age = 14 i isGuest = true: també pot entrar.

Resultat

Exercici 3.6

Exercise 3.6. Ask for three marks and write the average with two decimals. (toFixed(2))

Solució

script.js 
const mark1 = Number(prompt("First mark?"));
const mark2 = Number(prompt("Second mark?"));
const mark3 = Number(prompt("Third mark?"));

const average = (mark1 + mark2 + mark3) / 3;
document.write("Average: " + average.toFixed(2));

Resultat

Dades de prova usades en la previsualització: 7, 8, 5
