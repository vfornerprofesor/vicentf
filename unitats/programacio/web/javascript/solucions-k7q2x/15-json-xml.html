Exercici 15.1

Exercise 15.1. Turn the products array of exercise 11.2 into JSON text, show the text in a <pre>, and turn it back into an array.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Products as JSON</title>
</head>

<body>
    <h1>Products as JSON</h1>
    <pre id="json"></pre>
    <p id="back"></p>

    <script>
        const products = [
            { name: "Keyboard", price: 25, stock: 10 },
            { name: "Mouse", price: 15, stock: 0 },
            { name: "Monitor", price: 120, stock: 3 },
            { name: "Cable", price: 5, stock: 40 },
            { name: "Webcam", price: 45, stock: 0 }
        ];

        const text = JSON.stringify(products, null, 2);          // array -> JSON text
        document.querySelector("#json").textContent = text;

        const again = JSON.parse(text);                          // JSON text -> array
        document.querySelector("#back").textContent =
            `Back to an array: ${again.length} products, the first one is ${again[0].name}.`;
    </script>
</body>

</html>

Resultat

Exercici 15.2

Exercise 15.2. Copy the content of books.json into a string. Parse it, change the price of one book, add a new book and show the result as indented JSON.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Books</title>
</head>

<body>
    <h1>Books</h1>
    <pre id="output"></pre>

    <script>
        const text = `[
            { "title": "Dune", "author": "Frank Herbert", "year": 1965, "price": 12.95 },
            { "title": "Matilda", "author": "Roald Dahl", "year": 1988, "price": 8.5 },
            { "title": "The Hobbit", "author": "J. R. R. Tolkien", "year": 1937, "price": 10.9 },
            { "title": "Wonder", "author": "R. J. Palacio", "year": 2012, "price": 9.99 }
        ]`;

        const books = JSON.parse(text);

        books[0].price = 14.5;                                   // change the price of one book
        books.push({ title: "The Little Prince", author: "Antoine de Saint-Exupery", year: 1943, price: 7.95 });

        document.querySelector("#output").textContent = JSON.stringify(books, null, 2);
    </script>
</body>

</html>
Es copia el contingut de books.json en una cadena (entre accents greus), es converteix amb JSON.parse, es modifica l'array i es mostra amb JSON.stringify(books, null, 2) (el 2 és el sagnat).

Resultat

Exercici 15.3

Exercise 15.3. Remove one quote from the JSON of 15.2 and show a clear message instead of a broken page.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Broken JSON</title>
</head>

<body>
    <h1>Broken JSON</h1>
    <p id="output"></p>

    <script>
        // one quote is missing after "Dune
        const text = '[{ "title": "Dune, "author": "Frank Herbert" }]';

        try {
            const books = JSON.parse(text);
            document.querySelector("#output").textContent = "Books: " + books.length;
        } catch (error) {
            document.querySelector("#output").textContent =
                "The JSON has an error and it cannot be read (" + error.name + ").";
            document.querySelector("#output").style.color = "red";
        }
    </script>
</body>

</html>
JSON.parse llança un SyntaxError si el text no és JSON vàlid; amb try/catch es mostra un missatge clar en lloc d'una pàgina trencada.

Resultat

Exercici 15.4

Exercise 15.4. Copy the content of books.xml into a string and show the list of titles using DOMParser.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Titles from XML</title>
</head>

<body>
    <h1>Titles</h1>
    <ul id="titles"></ul>

    <script>
        const text = `<?xml version="1.0" encoding="UTF-8"?>
        <catalog>
            <book><title>Dune</title><author>Frank Herbert</author><year>1965</year><price>12.95</price></book>
            <book><title>Matilda</title><author>Roald Dahl</author><year>1988</year><price>8.5</price></book>
            <book><title>The Hobbit</title><author>J. R. R. Tolkien</author><year>1937</year><price>10.9</price></book>
            <book><title>Wonder</title><author>R. J. Palacio</author><year>2012</year><price>9.99</price></book>
        </catalog>`;

        const doc = new DOMParser().parseFromString(text, "application/xml");
        const titles = doc.querySelectorAll("title");

        let html = "";
        for (const title of titles) {
            html += `<li>${title.textContent}</li>`;
        }
        document.querySelector("#titles").innerHTML = html;
    </script>
</body>

</html>

Resultat

Exercici 15.5

Exercise 15.5. Use the second parameter of JSON.stringify to keep only the title and the year.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Only title and year</title>
</head>

<body>
    <h1>Only title and year</h1>
    <pre id="output"></pre>

    <script>
        const books = [
            { "title": "Dune", "author": "Frank Herbert", "year": 1965, "price": 12.95 },
            { "title": "Matilda", "author": "Roald Dahl", "year": 1988, "price": 8.5 },
            { "title": "The Hobbit", "author": "J. R. R. Tolkien", "year": 1937, "price": 10.9 },
            { "title": "Wonder", "author": "R. J. Palacio", "year": 2012, "price": 9.99 }
        ];

        // the second parameter is an array with the properties to keep
        document.querySelector("#output").textContent = JSON.stringify(books, ["title", "year"], 2);
    </script>
</body>

</html>
