Exercici 8.1

Exercise 8.1. Put a breakpoint inside your function biggest from exercise 7.3. Call it with 4, 9 and 2 and go line by line with F10. Write a table with the value of max after each line.

Solució

script.js 
function biggest(a, b, c) {
    let max = a;        // breakpoint here
    if (b > max) {
        max = b;
    }
    if (c > max) {
        max = c;
    }
    return max;
}

biggest(4, 9, 2);
Resposta: cridant a biggest(4, 9, 2) i avançant amb F10, el valor de max és: abans de la primera línia undefined · després de let max = a → 4 · després de if (b > max) max = b → 9 (9 > 4) · després de if (c > max) → 9 (2 no és major que 9) · retorna 9.

Exercici 8.2

Exercise 8.2. Download the starter file average.html. The average is wrong. Find the bug with the debugger (not by reading the code) and fix it. Above the line you fixed, write a comment saying what was wrong.

Fitxer de partida: average.html

Solució

average.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Average of marks</title>
</head>

<body>
    <div class="container">
        <h1>Average of marks</h1>
        <input type="text" id="marks" placeholder="e.g. 5, 7, 9">
        <button id="averageButton">Calculate</button>
        <p id="result"></p>
    </div>

    <script>
        // Returns the average of an array of numbers.
        function average(marks) {
            // BUG FIXED: the sum started at 1 and it must start at 0.
            // With sum = 1 every result was 1 / length too high.
            let sum = 0;
            for (const mark of marks) {
                sum = sum + mark;
            }
            return sum / marks.length;
        }

        // Reads the field, turns "5, 7, 9" into [5, 7, 9] and shows the average.
        function showAverage() {
            const text = document.querySelector("#marks").value;
            const parts = text.split(",");
            const marks = [];
            for (const part of parts) {
                marks.push(Number(part));
            }
            const result = average(marks);
            document.querySelector("#result").textContent = `Average: ${result.toFixed(2)}`;
        }

        document.querySelector("#averageButton").addEventListener("click", showAverage);
    </script>
</body>

</html>
El bug: let sum = 1 en lloc de let sum = 0. Amb un punt d'interrupció en el return es veu que sum val 22 en lloc de 21 per a [5, 7, 9]. Sense el bug, la mitjana de 5, 7 i 9 és 7.00 (amb el bug donava 7.33).

Exercici 8.3

Exercise 8.3. Write three console.assert (normal, edge and strange case) for each of your functions square, isEven and biggest of lesson 7.

Solució

script.js 
// square
console.assert(square(4) === 16, "normal: 4 squared is 16");
console.assert(square(0) === 0, "edge: 0 squared is 0");
console.assert(square(-3) === 9, "strange: a negative number gives a positive result");

// isEven
console.assert(isEven(8) === true, "normal: 8 is even");
console.assert(isEven(0) === true, "edge: 0 is even");
console.assert(isEven(-3) === false, "strange: -3 is odd");

// biggest
console.assert(biggest(4, 9, 2) === 9, "normal: the biggest of 4, 9 and 2 is 9");
console.assert(biggest(5, 5, 5) === 5, "edge: all equal");
console.assert(biggest(-1, -8, -3) === -1, "strange: all negative");
Es posen al final del script, després de les funcions de la lliçó 7 (square, isEven i biggest). Si una afirmació és falsa, la consola mostra "Assertion failed: ..." amb el missatge; si tot és correcte, no mostra res.

Exercici 8.4

Exercise 8.4. Download leap.html. Write assertions for 2024, 2023, 2000 and 1900. One of them fails: use it to find the bug and fix the function.

Fitxer de partida: leap.html

Solució

leap.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Leap year</title>
</head>

<body>
    <h1>Leap year</h1>
    <p>Open the console (F12) to see the result of the assertions.</p>

    <script>
        // Returns true if the year is a leap year, false if it is not.
        // BUG FIXED: it only checked the 4. A year divisible by 100 is NOT a leap
        // year, unless it is also divisible by 400.
        function isLeapYear(year) {
            return (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0;
        }

        console.assert(isLeapYear(2024) === true, "2024 should be a leap year");
        console.assert(isLeapYear(2023) === false, "2023 should NOT be a leap year");
        console.assert(isLeapYear(2000) === true, "2000 should be a leap year");
        console.assert(isLeapYear(1900) === false, "1900 should NOT be a leap year");
    </script>
</body>

</html>
Resposta: les afirmacions de 2024, 2023 i 2000 passen, però 1900 falla: la funció original només comprovava si era divisible per 4, i 1900 ho és, però també és divisible per 100 i no per 400, així que no és de traspàs. La correcció afig les condicions dels 100 i 400.
