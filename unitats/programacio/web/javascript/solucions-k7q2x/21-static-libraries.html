Exercici 21.1

Exercise 21.1. Classify these 10 calls into "method of an object" and "static": Math.max(3, 8), "hi".includes("h"), JSON.stringify(a), list.indexOf(3), Number.parseFloat("2.5"), today.getFullYear(), Math.random(), text.split(","), Array.isArray(list), (5).toFixed(1).

Solució

Resposta:
CridaTipus
Math.max(3, 8)static
"hi".includes("h")mètode d'objecte
JSON.stringify(a)static
list.indexOf(3)mètode d'objecte
Number.parseFloat("2.5")static
today.getFullYear()mètode d'objecte
Math.random()static
text.split(",")mètode d'objecte
Array.isArray(list)static
(5).toFixed(1)mètode d'objecte
Regla: si abans del punt hi ha el nom d'una classe (Math, JSON, Number, Array) és static; si hi ha una variable o un valor, és mètode d'un objecte.

Exercici 21.2

Exercise 21.2. Add Day.js to a page. Show today's date as DD/MM/YYYY and the days until your birthday with diff. Compare it with your result of exercise 20.2.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Day.js</title>
    <script src="https://cdn.jsdelivr.net/npm/dayjs@1/dayjs.min.js"></script>
</head>

<body>
    <h1>Day.js</h1>
    <p id="today"></p>
    <p id="birthday"></p>

    <script>
        document.querySelector("#today").textContent = "Today: " + dayjs().format("DD/MM/YYYY");

        // days until 24 June (this year or next)
        let birthday = dayjs(dayjs().year() + "-06-24");
        if (birthday.isBefore(dayjs(), "day")) {
            birthday = birthday.add(1, "year");
        }
        document.querySelector("#birthday").textContent =
            "Days until my birthday: " + birthday.diff(dayjs().startOf("day"), "day");
    </script>
</body>

</html>
La biblioteca s'afig abans del teu script (si no, "dayjs is not defined"). El resultat de diff coincidix amb el de l'exercici 20.2.

Exercici 21.3

Exercise 21.3. A price field: show the price in euros and in dollars with the options of toLocaleString.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Price</title>
</head>

<body>
    <h1>Price</h1>
    <input type="number" id="price" placeholder="Price in euros" step="0.01">
    <button id="show">Show</button>
    <p id="euros"></p>
    <p id="dollars"></p>

    <script>
        const RATE = 1.08;    // dollars for one euro (an example value)

        document.querySelector("#show").addEventListener("click", function () {
            const price = Number(document.querySelector("#price").value);

            document.querySelector("#euros").textContent =
                price.toLocaleString("es-ES", { style: "currency", currency: "EUR" });

            document.querySelector("#dollars").textContent =
                (price * RATE).toLocaleString("en-US", { style: "currency", currency: "USD" });
        });
    </script>
</body>

</html>
Amb style: "currency" i currency, toLocaleString posa el símbol i el format de cada llengua (12,50 € en espanyol, $13.50 en anglés). La taxa de canvi és un valor d'exemple.

Exercici 21.4

Exercise 21.4. Find the library canvas-confetti, add it, and launch confetti when a button is clicked.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Confetti</title>
    <script src="https://cdn.jsdelivr.net/npm/canvas-confetti@1/dist/confetti.browser.min.js"></script>
</head>

<body>
    <h1>Party time</h1>
    <button id="party">Launch confetti</button>

    <script>
        document.querySelector("#party").addEventListener("click", function () {
            confetti({ particleCount: 150, spread: 80, origin: { y: 0.7 } });
        });
    </script>
</body>

</html>
Biblioteca: canvas-confetti. S'afig amb un <script> i, en fer clic, es crida a la funció global confetti(). Necessita connexió a internet.
