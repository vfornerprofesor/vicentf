Exercici 2.1

Exercise 2.1. Declare variables for your name, age, height (with decimals) and whether you have a driving licence. Write each one in the page, with its typeof next to it.

Solució

script.js 
const name = "Marc";
const age = 16;
const height = 1.72;
const hasLicence = false;

document.write(name + " - " + typeof name + "<br>");
document.write(age + " - " + typeof age + "<br>");
document.write(height + " - " + typeof height + "<br>");
document.write(hasLicence + " - " + typeof hasLicence + "<br>");
Es suposa el mateix index.html de l'exercici 1.1 (amb <script src="script.js"></script> al final del body); només canvia el script.js. Tipus: string, number, number i boolean.

Resultat

Exercici 2.2

Exercise 2.2. Write a sentence in the page with all four values, using a template literal.

Solució

script.js 
const name = "Marc";
const age = 16;
const height = 1.72;
const hasLicence = false;

document.write(`${name} is ${age} years old, is ${height} m tall and has a driving licence: ${hasLicence}.`);

Resultat

Exercici 2.3

Exercise 2.3. Try to change a const. Open the console and copy the error you get.

Solució

script.js 
const PI = 3.14;
PI = 3;
document.write(PI);
Resposta: Uncaught TypeError: Assignment to constant variable. Una const no es pot reassignar; si el valor ha de canviar cal declarar-la amb let.

Exercici 2.4

Exercise 2.4. Predict, without running it, what these show. Then run them and check: 
document.write("5" + 3 + "<br>");
document.write(5 + 3 + "<br>");
document.write("5" - 3 + "<br>");
document.write(typeof (5 + "3") + "<br>");

Solució

script.js 
document.write("5" + 3 + "<br>");           // "53"  -> + with a string joins text
document.write(5 + 3 + "<br>");             // 8
document.write("5" - 3 + "<br>");           // 2     -> - only works with numbers
document.write(typeof (5 + "3") + "<br>");  // "string"
Resposta: 53, 8, 2 i string. Amb un text, el + concatena; el - només sap restar números i converteix el text "5" a número.

Resultat

Exercici 2.5

Exercise 2.5. Ask the user for two numbers with prompt, add them, and write the result in the page. Make sure the result is 8 and not "35" when the user types 3 and 5.

Solució

script.js 
const a = Number(prompt("First number?"));
const b = Number(prompt("Second number?"));
document.write(`${a} + ${b} = ${a + b}`);
prompt sempre torna text. Sense Number(), "3" + "5" donaria "35"; amb Number() el resultat és 8.

Resultat

Dades de prova usades en la previsualització: 3, 5

Exercici 2.6

Exercise 2.6. Ask for a temperature in Celsius and write it in Fahrenheit. The formula is F = C * 9 / 5 + 32.

Solució

script.js 
const celsius = Number(prompt("Temperature in Celsius?"));
const fahrenheit = celsius * 9 / 5 + 32;
document.write(`${celsius} C = ${fahrenheit} F`);

Resultat

Dades de prova usades en la previsualització: 25

Exercici 2.7

Exercise 2.7. Ask for the price of a product and the quantity, and write an invoice line: name, quantity, price per unit and total.

Solució

script.js 
const product = prompt("Name of the product?");
const price = Number(prompt("Price of one unit?"));
const quantity = Number(prompt("Quantity?"));

const total = price * quantity;
document.write(`${product}: ${quantity} x ${price} EUR = ${total} EUR`);

Resultat

Dades de prova usades en la previsualització: USB cable, 3.5, 4
