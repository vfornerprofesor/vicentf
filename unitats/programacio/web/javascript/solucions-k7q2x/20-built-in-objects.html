Exercici 20.1

Exercise 20.1. Show today's date and time in the page in local format.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Today</title>
</head>

<body>
    <h1>Today</h1>
    <p id="output"></p>

    <script>
        const now = new Date();
        document.querySelector("#output").textContent = now.toLocaleString("es-ES");
    </script>
</body>

</html>
toLocaleString("es-ES") dona la data i l'hora en format local (per exemple 20/5/2027, 10:30:15).

Exercici 20.2

Exercise 20.2. Calculate how many days are left until your birthday. If it has already passed this year, count until next year.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Birthday</title>
</head>

<body>
    <h1>My birthday is on 24 June</h1>
    <p id="output"></p>

    <script>
        const today = new Date();
        today.setHours(0, 0, 0, 0);                                // ignore the hour

        let birthday = new Date(today.getFullYear(), 5, 24);       // the months start at 0: June is 5
        if (birthday < today) {
            birthday.setFullYear(today.getFullYear() + 1);         // it has passed: next year
        }

        const milliseconds = birthday - today;
        const days = Math.round(milliseconds / (1000 * 60 * 60 * 24));

        document.querySelector("#output").textContent = `Days until my birthday: ${days}`;
    </script>
</body>

</html>
Els mesos de Date comencen en 0 (juny és el 5). La diferència entre dues dates són mil·lisegons: es divideix per 1000 · 60 · 60 · 24 per a tenir dies.

Exercici 20.3

Exercise 20.3. An <input type="date"> for the date of birth: show the exact age in years.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Age</title>
</head>

<body>
    <h1>How old are you?</h1>
    <label for="birth">Date of birth</label>
    <input type="date" id="birth">
    <button id="calculate">Calculate</button>
    <p id="output"></p>

    <script>
        document.querySelector("#calculate").addEventListener("click", function () {
            const birth = new Date(document.querySelector("#birth").value);
            const today = new Date();

            let age = today.getFullYear() - birth.getFullYear();

            // if the birthday has not arrived yet this year, subtract one
            const monthDifference = today.getMonth() - birth.getMonth();
            if (monthDifference < 0 || (monthDifference === 0 && today.getDate() < birth.getDate())) {
                age--;
            }

            document.querySelector("#output").textContent = `You are ${age} years old.`;
        });
    </script>
</body>

</html>
No basta restar els anys: si encara no ha arribat l'aniversari d'enguany cal restar-ne un.

Resultat

Exercici 20.4

Exercise 20.4. Create the same date in three ways (numbers, text, milliseconds) and check that their getTime() is equal.

Solució

script.js 
const a = new Date(2027, 4, 20);                 // with numbers (the month 4 is May)
const b = new Date("2027-05-20T00:00:00");       // with text (with the hour, so it is local time)
const c = new Date(a.getTime());                 // with milliseconds

console.log(a.getTime() === b.getTime());        // true
console.log(a.getTime() === c.getTime());        // true
Pregunta típica: sense l'hora, new Date("2027-05-20") es considera en UTC i pot no coincidir amb la data local; per això s'afig T00:00:00.
