Exercici 12.1

Exercise 12.1. Redo exercise 11.3 (total value of the stock) with reduce.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Stock value</title>
</head>

<body>
    <p id="output"></p>

    <script>
        const products = [
            { name: "Keyboard", price: 25, stock: 10 },
            { name: "Mouse", price: 15, stock: 0 },
            { name: "Monitor", price: 120, stock: 3 },
            { name: "Cable", price: 5, stock: 40 },
            { name: "Webcam", price: 45, stock: 0 }
        ];

        const stockValue = products.reduce((total, p) => total + p.price * p.stock, 0);
        document.querySelector("#output").textContent = `Total value of the stock: ${stockValue} euros`;
    </script>
</body>

</html>
reduce va acumulant: comença en 0 (segon argument) i a cada producte suma preu × estoc.

Exercici 12.2

Exercise 12.2. Redo exercise 11.5 (names of the products out of stock) with filter and map.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Out of stock</title>
</head>

<body>
    <p id="output"></p>

    <script>
        const products = [
            { name: "Keyboard", price: 25, stock: 10 },
            { name: "Mouse", price: 15, stock: 0 },
            { name: "Monitor", price: 120, stock: 3 },
            { name: "Cable", price: 5, stock: 40 },
            { name: "Webcam", price: 45, stock: 0 }
        ];

        const names = products
            .filter(p => p.stock === 0)
            .map(p => p.name);

        document.querySelector("#output").textContent = "Out of stock: " + names.join(", ");
    </script>
</body>

</html>

Exercici 12.3

Exercise 12.3. Redo exercise 11.7 (average, best student, how many passed) with reduce, find and filter. No for loop allowed.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Class list</title>
</head>

<body>
    <p id="output"></p>

    <script>
        const students = [
            { name: "Pere", age: 16, mark: 7 },
            { name: "Joan", age: 17, mark: 4 },
            { name: "Marta", age: 16, mark: 9 },
            { name: "Nuria", age: 18, mark: 3.5 },
            { name: "Laia", age: 16, mark: 6 }
        ];

        const average = students.reduce((total, s) => total + s.mark, 0) / students.length;
        const best = students.reduce((a, b) => (b.mark > a.mark ? b : a));
        const passed = students.filter(s => s.mark >= 5).length;
        const marta = students.find(s => s.name === "Marta");   // find: the first one that matches

        document.querySelector("#output").textContent =
            `Average: ${average.toFixed(2)} | Best: ${best.name} | Passed: ${passed} | Marta is ${marta.age}`;
    </script>
</body>

</html>
Sense cap bucle for: reduce per a la mitjana i la millor nota, filter per a comptar els aprovats i find per a trobar un alumne pel nom.

Exercici 12.4

Exercise 12.4. With some and every, show whether any product is out of stock and whether all of them cost less than 50 €.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>some and every</title>
</head>

<body>
    <p id="output"></p>

    <script>
        const products = [
            { name: "Keyboard", price: 25, stock: 10 },
            { name: "Mouse", price: 15, stock: 0 },
            { name: "Monitor", price: 120, stock: 3 },
            { name: "Cable", price: 5, stock: 40 },
            { name: "Webcam", price: 45, stock: 0 }
        ];

        const anyOut = products.some(p => p.stock === 0);
        const allCheap = products.every(p => p.price < 50);

        document.querySelector("#output").textContent =
            `Any product out of stock: ${anyOut} | All cost less than 50 euros: ${allCheap}`;
    </script>
</body>

</html>
El Monitor costa 120 €, per això every dona false.

Exercici 12.5

Exercise 12.5. In one chain: the names of the products under 20 €, in alphabetical order, joined with commas.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Chain</title>
</head>

<body>
    <p id="output"></p>

    <script>
        const products = [
            { name: "Keyboard", price: 25, stock: 10 },
            { name: "Mouse", price: 15, stock: 0 },
            { name: "Monitor", price: 120, stock: 3 },
            { name: "Cable", price: 5, stock: 40 },
            { name: "Webcam", price: 45, stock: 0 }
        ];

        const result = products
            .filter(p => p.price < 20)
            .map(p => p.name)
            .sort()
            .join(", ");

        document.querySelector("#output").textContent = result;
    </script>
</body>

</html>
