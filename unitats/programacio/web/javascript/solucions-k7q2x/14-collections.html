Exercici 14.1

Exercise 14.1. Redo exercise 10.6 (no duplicates) with a Set, in one line.

Solució

script.js 
function noDuplicates(list) {
    return [...new Set(list)];
}

console.log(noDuplicates([1, 2, 2, 3, 1, 4]));   // [1,2,3,4]
Un Set no admet repetits; [...set] el torna a convertir en array.

Exercici 14.2

Exercise 14.2. The user types a text; show how many times each word appears, using a Map. Show the result as a list, from the most repeated word to the least.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Word counter</title>
</head>

<body>
    <h1>How many times does each word appear?</h1>
    <textarea id="text" rows="3" cols="50"></textarea>
    <button id="count">Count</button>
    <ol id="result"></ol>

    <script>
        document.querySelector("#count").addEventListener("click", function () {
            const text = document.querySelector("#text").value.toLowerCase();
            const words = text.match(/[a-zà-ú]+/g) || [];

            const counts = new Map();
            for (const word of words) {
                counts.set(word, (counts.get(word) || 0) + 1);
            }

            // from the most repeated word to the least
            const sorted = [...counts].sort((a, b) => b[1] - a[1]);

            let html = "";
            for (const [word, times] of sorted) {
                html += `<li>${word}: ${times}</li>`;
            }
            document.querySelector("#result").innerHTML = html;
        });
    </script>
</body>

</html>

Exercici 14.3

Exercise 14.3. Copy the comparison table above into your notebook and add one example of your own in each column.

Solució

Resposta: cada columna amb un exemple propi: Array → ["Pere", "Joan", "Pere"] (llista de noms, es poden repetir); Set → new Set(["valencia", "alacant", "valencia"]) (ciutats úniques: queden 2); Map → new Map([["Pere", "600111222"], ["Joan", "600333444"]]) (agenda: es busca per clau amb get); Object → { title: "Dune", year: 1965 } (una cosa amb les seues propietats, .title).

Exercici 14.4

Exercise 14.4. For each situation, choose Array, Set, Map or object, and write why in one line: the students of a class in the order of the list; the different countries the visitors of a web come from; the phone number of each friend; a film with title, year and director; the marks of an exam to calculate the average.

Solució

Resposta:
  • Alumnes d'una classe en l'ordre de la llista → Array: manté l'ordre i es pot repetir.
  • Països diferents d'on venen els visitants → Set: només valors únics.
  • Telèfon de cada amic → Map (o objecte): es busca pel nom (la clau).
  • Una pel·lícula amb títol, any i director → Objecte: una sola cosa amb propietats.
  • Notes d'un examen per a calcular la mitjana → Array: llista de números que es recorre amb reduce.
