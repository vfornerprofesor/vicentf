Exercici 4.1

Exercise 4.1. Reproduce the page below with the names of four classmates. When you click on one of them, that name changes size and colour, and the other three go back to their original size and colour.

Fitxer de partida: ex1.html

Solució

script.js 
const names = document.querySelectorAll("p");

for (const name of names) {
    name.addEventListener("click", function () {
        // first, every name goes back to the original style
        for (const other of names) {
            other.style.fontSize = "";
            other.style.color = "";
        }
        // then the clicked one grows and changes colour
        name.style.fontSize = "48px";
        name.style.color = "crimson";
    });
}

Fitxer de partida: exercises/04-dom/ex1.html (el codi de dalt va en el script.js o dins del <script> d'este fitxer).

Exercici 4.2

Exercise 4.2. Make the paragraph's border grow by 1 px every time you click on it.

Fitxer de partida: ex2.html

Solució

script.js 
let size = 1;
const paragraph = document.querySelector("#p");

paragraph.addEventListener("click", function () {
    // 1. Make a variable with the new size: the size plus 1
    const newSize = size + 1;
    // 2. Change the border of the paragraph using the new size
    paragraph.style.border = newSize + "px solid coral";
    // 3. Store the new size back in the variable size
    size = newSize;
});

Fitxer de partida: exercises/04-dom/ex2.html (el codi de dalt va en el script.js o dins del <script> d'este fitxer).

Després de dos clics la vora és de 3 px: comença en 1 px i cada clic suma 1.

Exercici 4.3

Exercise 4.3. The code below is broken: the colours do not match the boxes. Fix it so that clicking on a box paints it with its own colour and clears the other three.

Fitxer de partida: ex3.html

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Colours</title>
</head>

<body>
    <div id="box">
        <div id="green" onclick="clickGreen()">Green</div>
        <div id="red" onclick="clickRed()">Red</div>
        <div id="blue" onclick="clickBlue()">Blue</div>
        <div id="yellow" onclick="clickYellow()">Yellow</div>
    </div>

    <script>
        // Cleans the four boxes and paints only the one that was clicked
        function paint(id, colour) {
            for (const box of document.querySelectorAll("#box div")) {
                box.style.backgroundColor = "";
            }
            document.getElementById(id).style.backgroundColor = colour;
        }

        function clickGreen() {
            paint("green", "green");
        }

        function clickRed() {
            paint("red", "red");
        }

        function clickBlue() {
            paint("blue", "blue");
        }

        function clickYellow() {
            paint("yellow", "yellow");
        }
    </script>
</body>

</html>
Els tres errors: 1) l'id="blue" estava repetit; 2) els id no coincidien amb el text de la caixa (la caixa "Green" tenia id="red", etc.); 3) les funcions pintaven un element que no era el seu (clickGreen pintava #yellow de blau...). La solució usa una sola funció paint que neteja les quatre caixes i pinta la clicada: no es repeteix codi.

Exercici 4.4

Exercise 4.4. Build the form below. When the user clicks the button, all the data they typed appears under it.

Fitxer de partida: ex4.html

Solució

script.js 
const button = document.querySelector("#sendButton");
const result = document.querySelector("#result");

button.addEventListener("click", function () {
    const name = document.querySelector("#name").value;
    const surname = document.querySelector("#surname").value;
    const birth = document.querySelector("#birth").value;
    const colour = document.querySelector("#colour").value;

    result.textContent = `Name: ${name} | Surname: ${surname} | Date of birth: ${birth} | Favourite colour: ${colour}`;
});

Fitxer de partida: exercises/04-dom/ex4.html (el codi de dalt va en el script.js o dins del <script> d'este fitxer).

S'usa textContent (no innerHTML) perquè el text escrit per l'usuari no es tracte com a HTML.

Exercici 4.5

Exercise 4.5. One input and one button. When you click, the h1 says Hello, NAME! with the name the user typed, and the field is emptied.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Greeting</title>
</head>

<body>
    <h1 id="title">Hello!</h1>
    <input type="text" id="nameInput" placeholder="Your name">
    <button id="myButton">Greet</button>

    <script>
        const input = document.querySelector("#nameInput");
        const button = document.querySelector("#myButton");
        const title = document.querySelector("#title");

        button.addEventListener("click", function () {
            const name = input.value;
            title.textContent = `Hello, ${name}!`;
            input.value = "";
        });
    </script>
</body>

</html>

Exercici 4.6

Exercise 4.6. Three buttons: red, green and blue. Each one changes the background colour of the whole page. (document.body.style.backgroundColor)

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">

            document.body.style.backgroundColor = "green";

Exercici 4.7

Exercise 4.7. A "Show / hide" button that makes a paragraph appear and disappear using classList.toggle.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Show / hide</title>
    <style>
        .hidden {
            display: none;
        }
    </style>
</head>

<body>
    <button id="toggleButton">Show / hide</button>
    <p class="text">This paragraph appears and disappears.</p>

    <script>
        const paragraph = document.querySelector(".text");
        const toggleButton = document.querySelector("#toggleButton");

        toggleButton.addEventListener("click", function () {
            paragraph.classList.toggle("hidden");
        });
    </script>
</body>

</html>
classList.toggle("hidden") posa la classe si no hi és i la lleva si hi és; la classe .hidden del CSS fa display: none.
