Exercise 1 · Our books · about 40 min

The constant booksText has the books of the club in JSON. Each book is an object with title, author, year, pages, genre and read.

  1. Start. Turn booksText into the array books. If the text is broken, show a message in red and start with an empty array: the page must not break. Mark this part with // DATA.
  2. The list. draw() shows the books numbered from 1, using forEach and its index:
    1. Dune (1965) · Frank Herbert · science fiction · 612 pages · read
  3. Numbers of the club. Under the list, always up to date, without for loops except for the map of genres:
    • the titles of the books that are read (filter and map);
    • the total number of pages (reduce);
    • the titles from the oldest book to the newest (sort), without changing the order of the list;
    • the average number of pages with one decimal, using averagePages;
    • how many different authors there are (a Set);
    • how many books each genre has (a Map, shown with for...of and entries()).
    Expected result with the books of the start Read: Dune, The BFG
    Total pages: 1332
    From oldest to newest: Dune, The BFG, Matilda, Holes
    Average pages: 333.0
    Different authors: 3
    Books per genre: science fiction: 1 · adventure: 2 · mystery: 1
  4. averagePages. The function is given, but it has 2 errors. Write three console.assert with your own small lists (normal, edge and strange case), find the errors and fix them. Above each line you fix, write a comment with the line and what was wrong.
  5. Add. The button adds a book that is not read. The title cannot be empty, the year must be 4 digits (check it with a regular expression) and the pages a number bigger than 0. The genre is saved in lowercase. Show each error in red; if everything is right, add it, draw again and show a message in green.
  6. Remove. removeBook(title) removes the book with that title. If it does not exist, it throws an error with the name "NotFoundError" and the message There is no book called "...". The button shows that message in red. Write the JSDoc of removeBook.
  7. Mark as read. indexOfTitle(title) returns the position of the book, or -1, with a loop. The button uses it to change the book to read, or shows a message if it does not exist.
  8. Export. The button shows the array as indented JSON.

Exercise 2 · Reading room · about 12 min

The array seats is the room of the next meeting: 3 rows of 5 seats; "X" is occupied and "" is free.

  1. Draw the room as a table, with two loops, one inside the other.
  2. isRowFull(row) returns true if every seat of that row is occupied, and countFree() returns how many free seats there are. Under the table: Row 1 full: true · Row 2 full: false · Row 3 full: false · Free seats: 6.
  3. Book the seat: the user writes the row and the seat (counting from 1). If the seat does not exist or is occupied, show a message in red. If it is free, it becomes occupied and the room and the line under it are drawn again.
