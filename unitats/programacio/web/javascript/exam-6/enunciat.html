Exercise 1 · The classes (model.js) · about 22 min

model.js only has definitions: no document, no querySelector. Write and export:

  1. The class Product:
    • The constructor receives name, price and units; if units is not given, it is 1.
    • The price is a private field with a get and a set. The set throws an error with the name "PriceError" if the price is not a number or is negative. The constructor uses the set.
    • total() returns the price × the units, and toString() returns Zelda · 59,95 € × 2 = 119,90 € using total() (currency with toLocaleString).
    • toJSON() returns a plain object with the name, the price and the units.
    • The static method fromObject(data) receives a plain object and returns a Product, or a DigitalProduct if the data has a platform.
  2. The class DigitalProduct, child of Product, that also has a platform. Its toString() reuses the one of Product and adds · download for PC; its toJSON() adds the platform to the data of Product.
  3. Mark with a comment each part of your classes: // constructor, // public property, // private field, // get, // set, // method, // static method, // child class.
  4. The function applyDiscount is given, but it has 1 error. Find it with the tests of exercise 2, fix it with a comment and write its JSDoc.

Exercise 2 · The shop (main.js) · about 30 min

  1. Import what you need from model.js.
  2. Load and save. The products are kept in localStorage (key products). The first time there is nothing: use catalogText. Turn the data into objects with fromObject and map. If the data is broken, show a message and start with an empty shop. Every time you save, show the products as a table in the console. Mark this part with // DATA.
  3. Draw. The list built with createElement, each product with its toString() and a Delete button (one single listener on the list). Under it:
    4 products · total: 354,65 € · platforms: PC, Switch · updated 15/04/2027 10:20
    The total adds the total() of each product. The platforms come from a Set of the digital products (instanceof). The date and time use Day.js (HH:mm is the hour and the minutes).
  4. Name check. While the user types the name, show ✓ or ✗: a valid name has from 2 to 30 letters (without accents), numbers or spaces (regular expression).
  5. Add. When the form is sent: the price can have a comma (4,5), change it with replace and a regular expression; if the units are empty, the product gets the units by default; if there is a platform, it is a DigitalProduct. Create the object inside a try and show the message of a PriceError. Check the name and the units too. Errors in red with the cursor in the wrong field. If a product with that name exists, add the units to it; if not, add the new product. Save, draw, message in green, empty the form. Mark the blocks with // INPUT, // PROCESS and // OUTPUT.
  6. Tests. At the end of main.js: three console.assert for applyDiscount (normal, edge and strange case) and at least three for your classes (for example total(), the units by default and the PriceError of a negative price).
