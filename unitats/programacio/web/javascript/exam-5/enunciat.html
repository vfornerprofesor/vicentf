Exercise 1 · My trips · about 40 min

Each trip is an object: { destination: "Rome", date: "2027-04-10", budget: 450 }.

  1. Load and save. The trips are kept in localStorage (key trips). If there is nothing or the data is broken, start with an empty array.
  2. Days left. When the user changes the date, show Paris: 112 days left under the form (or That date has already passed.). Calculate it with Date and getTime(). The date field gives a text like "2027-06-24". new Date(text + "T00:00:00") gives that day in local time.
  3. Destination. It is saved with only the first letter in capitals: "rOME " → "Rome" (use string methods with the right parameters).
  4. Budget. readBudget(text) returns the budget as a number (it accepts a comma: 300,5), or throws an error with the name "BudgetError" and a different message if it is empty, not a number or negative. Write its JSDoc.
  5. Save a trip. When the form is sent (the page must not reload): the destination and the date cannot be empty and the budget is read with readBudget. Show any error in red and put the cursor in the wrong field. If there is already a trip to that destination, change its date and budget; if not, add a new one. Save, draw, show a message in green and empty the form.
  6. Draw. The trips sorted by date, built with createElement, each with a Delete button (one single listener on the list). Use Day.js for the date and the days (the token ddd is the short name of the day):
    Lisbon · Fri 05/03/2027 · in 120 days · 300,50 € [Delete]
    Under the list: the number of trips, the destinations without repetition (a Set, shown with for...of), the total budget and the average per trip rounded to whole euros. Amounts with toLocaleString and the options of a currency in euros.
    2 trips · 2 destinations: Lisbon, Rome · total 900,50 € · about 450,00 € per trip

Exercise 2 · The end of the course · about 12 min

The course ends on 18 June 2027. Show in #courseOutput:

  1. The date in local format and the name of its day of the week (use the array dayNames).
  2. Create that date twice: with new and numbers, and with new and the text "2027-06-18T00:00:00". Show whether they are the same date, compared the right way.
  3. The function daysBetween(a, b) is given, but it has 1 error. Write three console.assert with dates of January 2027 (normal, edge and strange case), find the error and fix it, with a comment above the line. Write its JSDoc.
  4. How many days are left until the end (with daysBetween, rounded up), and the same with Day.js.
  5. How many whole weeks are left and, with a static method of Number, whether the days are an exact number of weeks.
