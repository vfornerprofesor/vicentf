Advanced selectors
Back to The Pixel Times In [CSS basics](unitats/programacio/web/html-css/09-css-basics.html) you styled The Pixel Times with tags, groups, ids, descendants, classes and :hover. Now you know the box model, flexbox, grid and media queries, so it is time to finish the page with *more precise selectors*. Open your Pixel Times folder (if you lost it, download [The Pixel Times|download](unitats/programacio/web/html-css/exercises/09-css-basics/selectors.html) again) and keep adding rules *at the end* of your css/style.css, *one by one*. Save and reload after each one to see what changes. More selectors on a real page Family: children and siblings *1.* *Child selector* >: only the direct children. main > section selects the sections that are right inside main, not deeper. main > section { max-width: 800px; margin: 0 auto; padding: 20px; } *2.* *Adjacent sibling* +: the element that comes *right after* another one, at the same level. Here, the first paragraph after each date. .date + p { font-size: 18px; } *3.* *General sibling* ~: *all* the elements after another one, at the same level. Here, every paragraph after the warning. .warning ~ p { font-style: italic; } blockquote { font-style: italic; color: #6d5fb3; border-left: 4px solid #6d5fb3; padding-left: 12px; } Pseudo-classes: position *4.* :first-child, :last-child and :nth-child(): the position among its siblings. even means 2, 4, 6...; odd means 1, 3, 5... .steps li:first-child { font-weight: bold; } .steps li:last-child { color: #6d5fb3; } table { width: 100%; border-collapse: collapse; background-color: white; } th { background-color: #6d5fb3; color: white; } th, td { padding: 10px; text-align: left; } tbody tr:nth-child(even) { background-color: #f4f1fb; } tbody tr:first-child { font-weight: bold; color: #b8860b; } Attributes *5.* *Attribute selectors* [ ]: elements with an attribute or a value. [href^="https"] means the href *starts with* https: only the external links of the footer change, not Back to top. input[type="text"], input[type="email"], textarea { display: block; width: 100%; box-sizing: border-box; padding: 8px; margin: 4px 0 14px; border: 1px solid #c9c1ec; border-radius: 6px; } a[href^="https"] { font-style: italic; } label { font-weight: bold; } button { background-color: #6d5fb3; color: white; border: none; padding: 10px 20px; border-radius: 6px; cursor: pointer; } *6.* :focus: the field where you are writing right now. Click on a field of the form. input:focus, textarea:focus { border-color: #6d5fb3; background-color: #fbfaff; } :not() and pseudo-elements *7.* :not(): everything *except* what is inside the brackets. All the cards except the featured one. .card:not(.featured) { border-left: 6px solid #c9c1ec; } *8.* *Pseudo-element* ::first-letter (two colons): a part of the element, here only its first letter. Like in old books. .featured .date + p::first-letter { font-size: 32px; color: #6d5fb3; } footer { background-color: #333333; color: white; text-align: center; padding: 20px; } The cascade, live *9.* Write the same rule twice with different colours. Same specificity: the *last one wins*. Then give a class to one of the footer paragraphs and style the class *before* these rules: it still wins, because a class beats a tag. footer p { color: yellow; } footer p { color: #cccccc; /* this one wins: it comes later */ } Open DevTools (F12), click on any element and look at the *Styles* panel: you see every rule that applies to it, and the ones that lose appear crossed out. Exercises Every exercise is a small page: you write the HTML exactly as it is described (tags, ids, classes, types...) and then the CSS rules in css/style.css. Do not change the HTML to make the CSS easier. *Exercise 14b.1. Children and siblings.* Create family.html. You cannot add classes to the <p>: the selectors do all the work. *HTML.* Create these elements:
  • a <div> with class="article";
  • inside, in this order: an <h2>, three <p>, and a <div> with class="box" that has two more <p> inside.
    •  *CSS.* Write these rules:
  • .article > p: line-height: 1.6 (only the three paragraphs that are direct children);
  • h2 + p: size 1.2rem and bold (only the first paragraph after the title);
  • h2 ~ p: colour #333333;
  • .box: background colour #f4f1fb and padding: 15px;
  • .box p: colour #888888 and italic.
    •  Check in DevTools which rules apply to the paragraphs of the box and which do not. *Exercise 14b.2. A league table.* Create league.html. *HTML.* Create these elements:
  • a <table> with class="league", with a <thead> (one <tr> with three <th>: Position, Team, Points) and a <tbody> with six <tr>;
  • a <ul> with class="podium" and three <li> (the first three teams).
    •  *CSS.* Write these rules:
  • .league: width 100% and border-collapse: collapse;
  • .league th: background colour #6d5fb3, colour white and padding: 10px;
  • .league td: padding: 10px;
  • tbody tr:nth-child(even): background colour #f4f1fb;
  • tbody tr:first-child: colour #b8860b and bold;
  • tbody tr:last-child: colour #c0392b;
  • .podium li:first-child: size 1.5rem.
    •  *Exercise 14b.3. A form with attribute selectors.* Create contact.html. *HTML.* Create these elements:
  • a <form> with: an <input> type="text", an <input> type="email", an <input> type="password", a <textarea>, an <input> type="checkbox" and a <button> type="submit"; every field with its <label>;
  • under the form, a <p> with two links: one to https://developer.mozilla.org/ and one to #top.
    •  *CSS.* Write these rules:
  • input[type="text"], input[type="email"], input[type="password"], textarea: display: block, width 100%, padding: 8px, margin-bottom: 14px, border: 1px solid #cccccc and border-radius: 6px;
  • input:focus, textarea:focus: border-color: #6d5fb3 and background colour #fbfaff;
  • input[type="checkbox"]: width 20px and height 20px;
  • button[type="submit"]: background colour #6d5fb3, colour white, border: none, padding: 10px 20px and border-radius: 6px;
  • a[href^="https"]: colour #e07a5f (only the external link changes).
    •  *Exercise 14b.4. :not(), ::first-letter and the cascade.* Create magazine.html. *HTML.* Create these elements:
  • a <nav> with five <a>; the second one has class="active";
  • an <article> with a <p> with class="intro" and two more <p>;
  • an <h2> with id="main-title" *and* class="title".
    •  *CSS.* Write these rules:
  • nav a:not(.active): colour #888888;
  • nav a.active: colour #6d5fb3 and bold;
  • .intro::first-letter: size 3rem and colour #6d5fb3;
  • in this order: #main-title in red, .title in green and h2 in blue.
