Responsive design
Why responsive? More than half of the people who visit a website do it from a phone. A page designed only for a big screen is unusable there: tiny text, horizontal scrolling, buttons you cannot hit with a finger. *Responsive design* means the same page adapts to the size of the screen. Narrow (phone) Medium (tablet) Wide (desktop) The viewport tag <meta name="viewport" content="width=device-width, initial-scale=1.0"> This line goes in the <head> of every page. Without it, a phone pretends its screen is 980px wide and shows your page zoomed out and tiny. *This is the number one cause of "my page looks bad on mobile".* (No live preview here: this tag only changes how a real phone, or DevTools' device mode, reports its width — an iframe on a desktop page cannot show that effect.) Flexible images img { max-width: 100%; height: auto; } Without this, a 1200px image on a 375px screen sticks out and creates horizontal scrolling. <style> .photo { width: 600px; height: 150px; background: #c4baeb; border-radius: 8px; } </style> <div class="photo">A 600px wide photo</div> <style> .photo { width: 600px; max-width: 100%; height: auto; background: #c4baeb; border-radius: 8px; padding: 20px 0; text-align: center; } </style> <div class="photo">A 600px wide photo, shrunk to fit</div> (Coloured boxes stand in for a real photo in this preview; a real <img> behaves the same way.) Media queries A *media query* is a block of CSS that only applies when a condition is true. /* Normal rules: they apply always */ .cards { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; } /* Only when the screen is 768px wide or less */ @media (max-width: 768px) { .cards { grid-template-columns: 1fr; } .site-header { flex-direction: column; gap: 10px; } } The two previews below use the exact same CSS. The only thing that changes is how wide the preview box itself is — and since each preview is a real, independent web page in an iframe, the media query genuinely turns on or off depending on that width, just like it would on a real phone or desktop. <style> .site-header { display: flex; justify-content: space-between; align-items: center; padding: 12px; background-color: #2b2b40; color: white; } .cards { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; padding: 12px; } .cards div { padding: 12px; background: #c4baeb; border-radius: 8px; text-align: center; } @media (max-width: 768px) { .cards { grid-template-columns: 1fr; } .site-header { flex-direction: column; gap: 10px; } } </style> <header class="site-header"> <div>Logo</div> <nav>Menu</nav> </header> <div class="cards"> <div>Card 1</div> <div>Card 2</div> <div>Card 3</div> </div> <style> .site-header { display: flex; justify-content: space-between; align-items: center; padding: 12px; background-color: #2b2b40; color: white; } .cards { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; padding: 12px; } .cards div { padding: 12px; background: #c4baeb; border-radius: 8px; text-align: center; } @media (max-width: 768px) { .cards { grid-template-columns: 1fr; } .site-header { flex-direction: column; gap: 10px; } } </style> <header class="site-header"> <div>Logo</div> <nav>Menu</nav> </header> <div class="cards"> <div>Card 1</div> <div>Card 2</div> <div>Card 3</div> </div> The usual breakpoints:

A live example you can resize in your own browser: [open the media queries sample](unitats/programacio/web/html-css/exercises/14-responsive/sample.html) Mobile first There are two ways to write your CSS:
  • *Desktop first*: write the big design, then use max-width queries to fix the small screens.
  • *Mobile first*: write the simple, one-column design, then use min-width queries to add columns on bigger screens.
    •  Mobile first usually gives shorter and cleaner CSS: /* Base: phone. One column. */ .cards { display: grid; grid-template-columns: 1fr; gap: 20px; } /* From 768px up: two columns */ @media (min-width: 768px) { .cards { grid-template-columns: repeat(2, 1fr); } } /* From 1024px up: three columns */ @media (min-width: 1024px) { .cards { grid-template-columns: repeat(3, 1fr); } } Same trick as above: same CSS, two preview widths, real behaviour. <style> .cards { display: grid; grid-template-columns: 1fr; gap: 10px; } @media (min-width: 768px) { .cards { grid-template-columns: repeat(2, 1fr); } } @media (min-width: 1024px) { .cards { grid-template-columns: repeat(3, 1fr); } } .cards div { padding: 12px; background: #c4baeb; border-radius: 8px; text-align: center; } </style> <div class="cards"> <div>Card 1</div> <div>Card 2</div> <div>Card 3</div> </div> <style> .cards { display: grid; grid-template-columns: 1fr; gap: 10px; } @media (min-width: 768px) { .cards { grid-template-columns: repeat(2, 1fr); } } @media (min-width: 1024px) { .cards { grid-template-columns: repeat(3, 1fr); } } .cards div { padding: 12px; background: #c4baeb; border-radius: 8px; text-align: center; } </style> <div class="cards"> <div>Card 1</div> <div>Card 2</div> <div>Card 3</div> </div>     Testing on a phone Open DevTools (F12) and press the little phone icon (or Ctrl+Shift+M). You get a fake phone screen and you can choose the model and the width. The fastest test of all: grab the corner of your browser window and make it narrow, slowly. Watch where your design breaks.
