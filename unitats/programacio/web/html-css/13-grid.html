CSS Grid
Grid or flexbox?
  • *Flexbox* works in *one direction*: a row, or a column. Perfect for a menu, a row of buttons, a card.
  • *Grid* works in *two directions* at once: columns ~and~ rows. Perfect for a gallery or the layout of a whole page.
    •  You can use both in the same page. In fact you almost always do.     Columns and rows .gallery { display: grid; grid-template-columns: 200px 200px 200px; /* three columns of 200px */ } <style> .gallery { display: grid; grid-template-columns: 200px 200px 200px; gap: 10px; } .gallery div { height: 100px; background: #c4baeb; border-radius: 8px; } </style> <div class="gallery"> <div>1</div> <div>2</div> <div>3</div> <div>4</div> <div>5</div> <div>6</div> </div> (The preview also gives the boxes a gap, a background and some height, just so the three columns are visible — only display: grid and grid-template-columns are in the lesson's code.) repeat and fr .gallery { display: grid; grid-template-columns: repeat(3, 1fr); /* three equal columns */ }
  • repeat(3, ...) saves you writing the same thing three times.
  • fr means ~fraction of the free space~. 1fr 1fr 1fr = three equal columns. 2fr 1fr = the first column is twice as wide as the second.
    •  fr is better than % because it already takes the gap into account. <style> .gallery { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; } .gallery div { height: 100px; background: #c4baeb; border-radius: 8px; } </style> <div class="gallery"> <div>1</div> <div>2</div> <div>3</div> <div>4</div> <div>5</div> <div>6</div> </div>     gap .gallery { display: grid; grid-template-columns: repeat(3, 1fr); gap: 15px; /* same gap in both directions */ gap: 15px 30px; /* rows columns */ } <style> .gallery { display: grid; grid-template-columns: repeat(3, 1fr); gap: 15px 30px; } .gallery div { height: 80px; background: #c4baeb; border-radius: 8px; } </style> <div class="gallery"> <div>1</div> <div>2</div> <div>3</div> <div>4</div> <div>5</div> <div>6</div> </div> Making an image gallery <div class="gallery"> <img src="images/p1.jpg" alt="A red car"> <img src="images/p2.jpg" alt="A blue bike"> <img src="images/p3.jpg" alt="A green bus"> <img src="images/p4.jpg" alt="A yellow taxi"> <img src="images/p5.jpg" alt="A white van"> <img src="images/p6.jpg" alt="A black train"> </div> .gallery { display: grid; grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); gap: 15px; } .gallery img { width: 100%; height: 180px; object-fit: cover; /* fills the box without deforming the photo */ border-radius: 8px; } That one line, repeat(auto-fit, minmax(220px, 1fr)), is magic: "make as many columns as fit, each one at least 220px wide". The gallery reorganises itself on any screen with *no media queries at all*. <style> .gallery { display: grid; grid-template-columns: repeat(auto-fit, minmax(120px, 1fr)); gap: 15px; } .gallery div { width: 100%; height: 100px; border-radius: 8px; background: #c4baeb; display: flex; align-items: center; justify-content: center; color: #2b2b2b; } </style> <div class="gallery"> <div>Photo 1</div> <div>Photo 2</div> <div>Photo 3</div> <div>Photo 4</div> <div>Photo 5</div> <div>Photo 6</div> </div> A page layout with grid .layout { display: grid; grid-template-columns: 1fr 300px; /* main content + sidebar */ gap: 30px; } <div class="layout"> <main>...</main> <aside>...</aside> </div> Both files together, in the browser (with some real content instead of the ...): <style> .layout { display: grid; grid-template-columns: 1fr 300px; gap: 30px; } .layout main, .layout aside { padding: 16px; background: #f5f5f5; border-radius: 8px; } </style> <div class="layout"> <main>Main content of the page goes here.</main> <aside>Sidebar: links, ads, related content.</aside> </div> Exercises *Exercise 13.1.* Build a grid of 9 coloured squares, 3 columns, with a 10px gap. *Exercise 13.2.* Turn it into repeat(auto-fit, minmax(150px, 1fr)) and resize the window.
