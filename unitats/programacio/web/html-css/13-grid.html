CSS Grid
Grid or flexbox?
  • *Flexbox* works in *one direction*: a row, or a column. Perfect for a menu, a row of buttons, a card.
  • *Grid* works in *two directions* at once: columns ~and~ rows. Perfect for a gallery or the layout of a whole page.
    •  You can use both in the same page. In fact you almost always do.     Columns and rows .gallery { display: grid; grid-template-columns: 200px 200px 200px; /* three columns of 200px */ } <style> .gallery { display: grid; grid-template-columns: 200px 200px 200px; gap: 10px; } .gallery div { height: 100px; background: #c4baeb; border-radius: 8px; } </style> <div class="gallery"> <div>1</div> <div>2</div> <div>3</div> <div>4</div> <div>5</div> <div>6</div> </div> (The preview also gives the boxes a gap, a background and some height, just so the three columns are visible — only display: grid and grid-template-columns are in the lesson's code.) repeat and fr .gallery { display: grid; grid-template-columns: repeat(3, 1fr); /* three equal columns */ }
  • repeat(3, ...) saves you writing the same thing three times.
  • fr means ~fraction of the free space~. 1fr 1fr 1fr = three equal columns. 2fr 1fr = the first column is twice as wide as the second.
    •  fr is better than % because it already takes the gap into account. <style> .gallery { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; } .gallery div { height: 100px; background: #c4baeb; border-radius: 8px; } </style> <div class="gallery"> <div>1</div> <div>2</div> <div>3</div> <div>4</div> <div>5</div> <div>6</div> </div>     gap .gallery { display: grid; grid-template-columns: repeat(3, 1fr); gap: 15px; /* same gap in both directions */ gap: 15px 30px; /* rows columns */ } <style> .gallery { display: grid; grid-template-columns: repeat(3, 1fr); gap: 15px 30px; } .gallery div { height: 80px; background: #c4baeb; border-radius: 8px; } </style> <div class="gallery"> <div>1</div> <div>2</div> <div>3</div> <div>4</div> <div>5</div> <div>6</div> </div> Making an image gallery <div class="gallery"> <img src="images/p1.jpg" alt="A red car"> <img src="images/p2.jpg" alt="A blue bike"> <img src="images/p3.jpg" alt="A green bus"> <img src="images/p4.jpg" alt="A yellow taxi"> <img src="images/p5.jpg" alt="A white van"> <img src="images/p6.jpg" alt="A black train"> </div> .gallery { display: grid; grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); gap: 15px; } .gallery img { width: 100%; height: 180px; object-fit: cover; /* fills the box without deforming the photo */ border-radius: 8px; } That one line, repeat(auto-fit, minmax(220px, 1fr)), is magic: "make as many columns as fit, each one at least 220px wide". The gallery reorganises itself on any screen with *no media queries at all*. <style> .gallery { display: grid; grid-template-columns: repeat(auto-fit, minmax(120px, 1fr)); gap: 15px; } .gallery div { width: 100%; height: 100px; border-radius: 8px; background: #c4baeb; display: flex; align-items: center; justify-content: center; color: #2b2b2b; } </style> <div class="gallery"> <div>Photo 1</div> <div>Photo 2</div> <div>Photo 3</div> <div>Photo 4</div> <div>Photo 5</div> <div>Photo 6</div> </div> A page layout with grid .layout { display: grid; grid-template-columns: 1fr 300px; /* main content + sidebar */ gap: 30px; } <div class="layout"> <main>...</main> <aside>...</aside> </div> Both files together, in the browser (with some real content instead of the ...): <style> .layout { display: grid; grid-template-columns: 1fr 300px; gap: 30px; } .layout main, .layout aside { padding: 16px; background: #f5f5f5; border-radius: 8px; } </style> <div class="layout"> <main>Main content of the page goes here.</main> <aside>Sidebar: links, ads, related content.</aside> </div> Exercises Every exercise is a small page: you write the HTML exactly as it is described (tags, ids, classes, types...) and then the CSS rules in css/style.css. Do not change the HTML to make the CSS easier. *Exercise 13.1. Nine squares.* Create squares.html. *HTML.* Create these elements:
  • a <div> with class="grid";
  • inside, nine <div> with class="square" and the numbers 1 to 9;
  • the fifth one has two classes: class="square special".
    •  *CSS.* Write these rules:
  • .grid: display: grid, grid-template-columns: repeat(3, 1fr), gap: 10px and max-width: 400px;
  • .square: height 100px, background colour #6d5fb3, colour white, border-radius: 8px, and the number in the middle with display: flex, justify-content: center and align-items: center;
  • .square.special: background colour #ffd166 and colour #333333.
    •  *Exercise 13.2. A photo gallery.* Create gallery.html and put eight photos in the folder images. *HTML.* Create these elements:
  • a <div> with class="gallery";
  • inside, eight <img>, each one with its alt;
  • under the gallery, a <p> with class="notes".
    •  *CSS.* Write these rules:
  • .gallery: display: grid, grid-template-columns: repeat(auto-fit, minmax(150px, 1fr)) and gap: 10px;
  • .gallery img: width 100%, height 150px, object-fit: cover and border-radius: 6px;
  • .notes: colour #888888 and italic.
    •  Resize the window and write in .notes how many columns you see with a wide, a medium and a narrow window. *Exercise 13.3. A page with a sidebar.* Create blog.html. *HTML.* Create these elements:
  • a <header> with an <h1>;
  • a <div> with class="layout"; inside, a <main> with two <article> (each with an <h2> and a <p>), and an <aside> with an <h3> and a <ul> of links;
  • a <footer> with a <p>.
    •  *CSS.* Write these rules:
  • .layout: display: grid, grid-template-columns: 1fr 280px and gap: 20px;
  • main: padding: 20px and background colour white;
  • aside: padding: 20px, background colour #f4f1fb and border-radius: 8px;
  • header, footer: background colour #2b2b40, colour white, padding: 20px and centred text.
    •      Test 2 At the end of this lesson there is a 1-hour test: you get a page with all its HTML and you write all its CSS. You link the style sheet, style the text with the right selectors, centre the content, calculate the real size of a box (with and without border-box) and lay out a navigation bar, a centred box and a row of cards with flexbox, and a gallery with grid. More exercises *Exercise 13.4. Chessboard.* Create chess.html. The picture is the model. *HTML.* Create these elements:
  • a <div> with class="board";
  • inside, 100 <div> in order, row by row (10 rows of 10): the first row, the last row, and the first and last cell of every row have class="edge" and a letter (A–H) or a number (1–8); the 64 squares in the middle have class="light" or class="dark", alternating;
  • the labels of the right column and the bottom row also have the class flip (for example class="edge flip");
  • optional: an <img> of a piece inside the squares of the first two and the last two rows.
    •  *CSS.* Write these rules:
  • .board: display: grid, grid-template-columns: repeat(10, 50px), grid-template-rows: repeat(10, 50px), width 500px and margin: 40px auto;
  • .edge: background colour #c35e2e;
  • .light: background colour #d1beb1;
  • .dark: background colour #473d36;
  • .edge, .light, .dark: display: flex, justify-content: center and align-items: center (the content in the middle);
  • .flip: transform: rotate(180deg).
