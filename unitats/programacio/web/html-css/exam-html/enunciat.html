Before you start

  • Create a folder called surname-name-html and copy inside it everything from the starter folder (errors.html and the images folder).
  • Create each file of the exam inside that folder, with the name the exercise tells you.
  • You can use VS Code, the browser and the W3C validator. You cannot use notes, the lessons, the internet to search for answers, a mobile phone or any AI tool.
  • Save often. At the end, hand in the whole folder.

Exercise 1 · Skeleton from memory · about 5 min

Create the file skeleton.html and write the complete skeleton of an HTML5 page. Do not copy it from any other file. It must have:

  • the doctype;
  • the html tag with the language set to English;
  • a head with the character encoding UTF-8 and the title HTML exam;
  • a body with an h1 that says HTML exam and a paragraph with the text This is my skeleton.

Remember: every tag closed, well nested and the code indented.

Exercise 2 · Find the errors · about 15 min

Open the file errors.html. It is a small page about a school club, and it has 8 errors. Fix all of them.

  • Some errors are found by the W3C validator. Others you only see by reading the code or by opening the page in the browser.
  • The two images must show in the browser, and the validator must say that there are no errors.
  • Do not change anything else and do not add new errors: that also counts.

Tip: write a comment next to each error you fix. It helps you to count them.

Exercise 3 · Nested list and table · about 15 min

Create the file list-table.html (with its complete skeleton and the title List and table). Write in HTML what you see in the pictures.

Exercise 4 · Form · about 12 min

Create the file form.html (with its complete skeleton and the title Registration form) with a form that has these 4 fields and a button:

Label text What the user writes Compulsory?
Name A short text Yes
Email An email address Yes
Date of birth A date No
Course One option from a list: SMX, ASIR or DAW Yes
  • Every field must have its label linked to it.
  • Use the right type of field for each data.
  • Add the validation that the table asks for.
  • At the end of the form, a button that sends it with the text Send.

Exercise 5 · Semantic tags · about 5 min

Create a text file called answers.txt. For each case, write the best HTML tag. Choose from this list (you may not need all of them):

header · nav · main · section · article · aside · footer · figure · div

  1. The group of links to Home, About, Projects and Contact.
  2. The area at the bottom of the page with the copyright and the email.
  3. A news item that could be published alone in another website.
  4. The unique content of the page, the one that is not repeated in the other pages.
  5. The area at the top of the page with the logo and the title of the site.
  6. A photo together with the text that describes it.
