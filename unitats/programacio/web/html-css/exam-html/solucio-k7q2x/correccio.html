PH2 · Exercici 3 (CA1.2)

Solució: solucio-k7q2x/list-table.html. Es corregix obrint-lo en el navegador i mirant el codi.

  • Llista: ul amb 3 li; Frontend i Backend contenen un ol de 2 li. La sublista ha d'anar dins del li, no després de tancar-lo.
  • Taula: fila de capçalera amb th (4 columnes), files amb th per a l'hora i td per a la resta, i la fila Break amb una sola cel·la colspan="4" (ni 3 ni 5).
  • Defectes de codi (compten per a Notable): subllista fora del li, capçalera amb td en lloc de th, etiqueta sense tancar.
Insuficient (1-4) Suficient-Bé (5-6) Notable (7-8) Excel·lent (9-10)
Ni la llista niada ni la taula es veuen com demana l'enunciat. Almenys una de les dues es veu com demana. Totes dues es veuen com demana, amb com a màxim un defecte de codi. Totes dues sense cap defecte de codi; el colspan ocupa exactament les columnes demanades.

PH3 · Exercici 4 (CA1.3)

Solució: solucio-k7q2x/form.html. Un camp és complet quan té les tres coses:

Camp label associada (for = id) Tipus adequat required
Name Sí type="text" Sí
Email Sí type="email" Sí
Date of birth Sí type="date" No (si el posa, no és un defecte greu però no és el que demana l'enunciat)
Course Sí select amb 3 option (SMX, ASIR, DAW) Sí

Per a Excel·lent, els 4 camps han d'anar dins d'un form i amb un botó <button type="submit">Send</button> (o input type="submit"). Error típic: label amb for però l'input sense id (o amb name en lloc d'id).

Insuficient (1-4) Suficient-Bé (5-6) Notable (7-8) Excel·lent (9-10)
Menys de 2 camps complets. 2 camps complets. 3 camps complets. Els 4 camps complets, dins d'un form amb botó d'enviament.
