Text, fonts and colours
Font family body { font-family: Arial, Helvetica, sans-serif; } <style> body { font-family: Arial, Helvetica, sans-serif; } </style> <p>The quick brown fox jumps over the lazy dog.</p> You give a *list*. The browser uses the first font that exists on the user's computer. The last one is always a generic family, as a safety net:
  • sans-serif — no little feet on the letters (Arial, Verdana). Best for screens.
  • serif — with little feet (Times). More classic.
  • monospace — all letters take the same width. For code.
    •      Web fonts (Google Fonts) If you want a font the user may not have, you can load it from the internet. Go to [fonts.google.com](https://fonts.google.com), choose a font, copy the <link> and paste it in your <head> *before* your own CSS file: <link rel="preconnect" href="https://fonts.googleapis.com"> <link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap" rel="stylesheet"> <link rel="stylesheet" href="css/style.css"> body { font-family: 'Roboto', Arial, sans-serif; } Do not load six fonts. Two is plenty: one for headings, one for text. Size: px, rem and % h1 { font-size: 32px; /* pixels: an exact size */ } p { font-size: 1rem; /* rem: relative to the browser's base size (16px) */ } small { font-size: 0.875rem; } <style> h1 { font-size: 32px; } p { font-size: 1rem; } small { font-size: 0.875rem; } </style> <h1>A heading</h1> <p>A normal paragraph.</p> <p><small>Small print, a little smaller than the paragraph.</small></p> rem is better than px for text, because if the user makes the text bigger in the browser settings, your page follows. 1rem is normally 16px, 2rem is 32px. Weight, style and spacing h2 { font-weight: bold; /* or a number: 400 normal, 700 bold */ } .quote { font-style: italic; } p { line-height: 1.6; /* space between lines. 1.5-1.7 is comfortable */ letter-spacing: 0.5px; /* space between letters */ } <style> h2 { font-weight: bold; } .quote { font-style: italic; } p { line-height: 1.6; letter-spacing: 0.5px; } </style> <h2>A bold heading</h2> <p class="quote">An italic quote.</p> <p>A paragraph with extra line-height and letter-spacing, so it is more comfortable to read on more than one line.</p> line-height: 1.6 means "1.6 times the font size". Text with no line-height is hard to read: it looks squashed. Alignment and decoration h1 { text-align: center; /* left, right, center, justify */ text-transform: uppercase; /* uppercase, lowercase, capitalize */ } a { text-decoration: none; /* removes the underline of links */ } a:hover { text-decoration: underline; /* and puts it back when the mouse is over */ } <style> h1 { text-align: center; text-transform: uppercase; } a { text-decoration: none; } a:hover { text-decoration: underline; } </style> <h1>centered and uppercase</h1> <p><a href="#">A link with no underline (try hovering it)</a></p> :hover is a *pseudo-class*: a rule that only applies in a certain situation. a:hover means "a link, while the mouse is on top of it". A sister pseudo-class is :focus: it applies while an element is *selected to write in it* (you clicked on it or you arrived with the Tab key). It is very useful in forms, to show clearly which field is active. input { border: 2px solid gray; } input:focus { border-color: orange; /* the active field changes colour */ outline: 2px solid orange; /* the line the browser draws around it */ } <style> input { border: 2px solid gray; } input:focus { border-color: orange; outline: 2px solid orange; } </style> <p><label for="f1">Name</label> <input type="text" id="f1"></p> <p><label for="f2">Email</label> <input type="email" id="f2"></p> <p>Click on a field, or move with the Tab key.</p> Do not remove the focus line with outline: none unless you put another visible style instead: people who use the keyboard need it to know where they are. Backgrounds body { background-color: #f5f5f5; } header { background-image: url("../images/hero.jpg"); background-size: cover; /* fill the box, cut what is left over */ background-position: center; background-repeat: no-repeat; } <style> body { background-color: #f5f5f5; } header { padding: 20px; } </style> <header> <h1>Site header</h1> </header> <p>The rest of the page has the light grey background-color.</p> The path inside url() is relative to the *CSS file*, not to the HTML file. If your CSS is in css/style.css and your image in images/hero.jpg, you need url("../images/hero.jpg"). Exercises Every exercise is a small page: you write the HTML exactly as it is described (tags, ids, classes, types...) and then the CSS rules in css/style.css. Do not change the HTML to make the CSS easier. *Exercise 10.1. A poem with Google Fonts.* Create poem.html and choose two fonts in Google Fonts: *Pacifico* for the title and *Lora* for the text. Copy their <link> into the <head>, before your style.css. *HTML.* Create these elements:
  • an <h1> with the title of the poem;
  • a <p> with class="author" with the name of the poet;
  • three <p> with class="verse", one per stanza (use <br> to break the lines).
    •  *CSS.* Write these rules:
  • body: font "Lora", serif;
  • h1: font "Pacifico", cursive, size 3rem, centred (text-align: center) and colour #6d5fb3;
  • .author: italic (font-style: italic), aligned to the right and colour #888888;
  • .verse: size 1.1rem and line-height: 1.8.
    •  *Exercise 10.2. A newspaper article.* Create news.html. *HTML.* Create these elements:
  • an <article> with an <h1> (the headline);
  • a <p> with class="subtitle";
  • a <p> with class="date" (for example “25 November 2026”);
  • three <p> with the text of the news.
    •  *CSS.* Write these rules:
  • body: size 1rem and line-height: 1.6;
  • h1: size 2.5rem and font-weight: 800;
  • .subtitle: size 1.25rem and font-weight: 300;
  • .date: in capitals (text-transform: uppercase), letter-spacing: 2px, size 0.8rem and colour #888888;
  • article p: justified (text-align: justify).
    •  Change the font-size of body to 1.25rem: everything with rem grows at the same time. *Exercise 10.3. Navigation links.* Create links.html. *HTML.* Create these elements:
  • a <header> with a <nav> inside and four <a>: Home, Gallery, Blog, Contact;
  • a <main> with a <p> that contains a normal link <a> to any website.
    •  *CSS.* Write these rules:
  • header: background colour #222222 and padding: 20px;
  • nav a: colour white, *no underline*, in capitals and margin-right: 20px;
  • nav a:hover: *underlined* (text-decoration: underline) and colour #ffd166;
  • main a: colour #6d5fb3, bold.
    •  Check that the link of the <main> is still underlined: only the links of the <nav> lose the underline. *Exercise 10.4. A header with a background image.* Create hero.html and put a photo called hero.jpg in a folder images. *HTML.* Create these elements:
  • a <header> with class="hero", with an <h1> and a <p> inside;
  • a <section> with class="highlight" and a <p> inside.
    •  *CSS.* Write these rules:
  • .hero: background image url("../images/hero.jpg"), background-size: cover, background-position: center, padding: 80px 20px, centred text and colour white;
  • .hero h1, .hero p: text-shadow: 0 2px 4px rgba(0, 0, 0, 0.7), so you can read the text on any photo;
  • body: background colour #fafafa;
  • .highlight: background colour rgba(109, 95, 179, 0.15).
    •  The path has ../ because the CSS file is inside the css folder: first it goes up one folder and then it goes into images.     More exercises *Exercise 10.5. Personal page.* Create personal.html. The picture is the model. *HTML.* Create these elements:
  • a <div> with class="profile" that contains everything;
  • inside, an <img> with class="photo" (a photo of your hobby) and a <div> with class="info";
  • inside .info: an <h1> with your name, a <p> with your birthday and age, an <h2> “Interests”, a <table> with three <tr> and two <td> in each row (six interests), and two <a> with class="button" (Instagram and Twitter).
    •  *CSS.* Write these rules:

  • .profile: background colour #ef6b5c, padding: 20px, margin: 50px auto, width 860px and border-radius: 6px;
  • .photo: width 400px;
  • .info: centred text;
  • h1: size 2rem; h2: size 1.5rem;
  • table: width 100%;
  • .button: background colour #f6f1bd, colour black, *no underline*, in capitals and padding: 18px 20px;
  • .button:hover: background colour white.
    •  The photo and the information are not side by side yet: you will put them in a row with flexbox in lesson 12. For now, one under the other is fine. *Exercise 10.6. Sign-up form.* Style the sign-up form of exercise 7.4 (signup.html). The picture is the model. *HTML.* Create these elements:
  • the form of exercise 7.4, inside a <div> with class="box";
  • an <h1> “Computerize” and an <h2> “Sign up” at the top of the box;
  • every <label> with its for and every <input> with its id and its type (text, date, email, password, number, radio, checkbox) and a <button> type="submit".
    •  *CSS.* Write these rules:
  • body: background colour #ff7f50 and font "Noto Sans", sans-serif (Google Fonts);
  • .box: background colour white, width 500px, margin: 40px auto, padding: 20px, border-radius: 6px and centred text;
  • h1, h2, label: colour #ff7f50; h1, h2: in capitals;
  • label: display: block;
  • input[type="text"], input[type="date"], input[type="email"], input[type="password"], input[type="number"]: width 300px, border: 1px solid #ff7f50 and border-radius: 3px;
  • input:focus: outline: 2px solid #ff7f50;
  • button: width 300px, background colour #ff7f50, colour white, border: none, size 1.2rem and in capitals.
