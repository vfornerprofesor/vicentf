Exercici 6.1

Exercise 6.1. Build a table with your school timetable: one column per day, one row per hour.

Solució

timetable.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My timetable</title>
</head>

<body>
    <h1>My timetable</h1>
    <table>
        <tr>
            <th>Hour</th>
            <th>Monday</th>
            <th>Tuesday</th>
            <th>Wednesday</th>
            <th>Thursday</th>
            <th>Friday</th>
        </tr>
        <tr>
            <td>8:00</td>
            <td>Web</td>
            <td>Networks</td>

            <td>Hardware</td>
            <td>Office</td>
        </tr>
        <tr>

            <td>Web</td>
            <td>Networks</td>
            <td>Hardware</td>

Exercici 6.2

Exercise 6.2. Build a table with the parts of a computer you would buy with 800 €: component, model, price. Add a last row with the total, using colspan so the words "TOTAL" take two columns.

Solució

computer.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My computer</title>
</head>

<body>
    <h1>The computer I would buy (800 &euro;)</h1>
    <table>
        <tr>
            <th>Component</th>
            <th>Model</th>
            <th>Price</th>
        </tr>
        <tr>
            <td>Processor</td>
            <td>AMD Ryzen 5 5600</td>
            <td>130 &euro;</td>
        </tr>
        <tr>
            <td>Motherboard</td>
            <td>MSI B550 Pro</td>
            <td>110 &euro;</td>
        </tr>
        <tr>
            <td>Graphics card</td>
            <td>RTX 4060</td>
            <td>300 &euro;</td>
        </tr>
        <tr>
            <td>RAM and SSD</td>
            <td>16 GB DDR4 + 1 TB</td>
            <td>140 &euro;</td>
        </tr>
        <tr>
            <td>Case and power supply</td>
            <td>Mid tower + 650 W</td>
            <td>115 &euro;</td>
        </tr>
        <tr>
            <td colspan="2"><strong>TOTAL</strong></td>
            <td><strong>795 &euro;</strong></td>
        </tr>
    </table>
</body>

</html>
L'última fila usa colspan="2": la cel·la "TOTAL" ocupa dues columnes i el preu va en la tercera.

Resultat
