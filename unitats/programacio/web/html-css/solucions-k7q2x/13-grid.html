Exercici 13.1

Exercise 13.1. Nine squares. Create squares.html.

HTML.

  • a <div> with class="grid";
  • inside, nine <div> with class="square" and the numbers 1 to 9;
  • the fifth one has two classes: class="square special".

CSS.

  • .grid: display: grid, grid-template-columns: repeat(3, 1fr), gap: 10px and max-width: 400px;
  • .square: height 100px, background colour #6d5fb3, colour white, border-radius: 8px, and the number in the middle with display: flex, justify-content: center and align-items: center;
  • .square.special: background colour #ffd166 and colour #333333.

Solució

squares.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Grid</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="grid">
        <div class="square">1</div>
        <div class="square">2</div>
        <div class="square">3</div>
        <div class="square">4</div>
        <div class="square special">5</div>
        <div class="square">6</div>
        <div class="square">7</div>
        <div class="square">8</div>
        <div class="square">9</div>
    </div>
</body>

</html>
css/style.css 
.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;
    max-width: 400px;
}

.square {
    height: 100px;
    background-color: #6d5fb3;
    color: white;
    border-radius: 8px;
    display: flex;
    justify-content: center;
    align-items: center;
}

.square.special {
    background-color: #ffd166;
    color: #333333;
}

Exercici 13.2

Exercise 13.2. A photo gallery. Create gallery.html and put eight photos in the folder images.

HTML.

  • a <div> with class="gallery";
  • inside, eight <img>, each one with its alt;
  • under the gallery, a <p> with class="notes".

CSS.

  • .gallery: display: grid, grid-template-columns: repeat(auto-fit, minmax(150px, 1fr)) and gap: 10px;
  • .gallery img: width 100%, height 150px, object-fit: cover and border-radius: 6px;
  • .notes: colour #888888 and italic.

Resize the window and write in .notes how many columns you see with a wide, a medium and a narrow window.

Solució

gallery.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Grid</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="gallery">
        <img src="images/photo1.jpg" alt="Photo 1">
        <img src="images/photo2.jpg" alt="Photo 2">
        <img src="images/photo3.jpg" alt="Photo 3">
        <img src="images/photo4.jpg" alt="Photo 4">
        <img src="images/photo5.jpg" alt="Photo 5">
        <img src="images/photo6.jpg" alt="Photo 6">
        <img src="images/photo7.jpg" alt="Photo 7">
        <img src="images/photo8.jpg" alt="Photo 8">
    </div>
    <p class="notes">Wide window: 6 columns. Medium window: 4 columns. Narrow window (phone): 2 columns.</p>
</body>

</html>
css/style.css 
.gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
    gap: 10px;
}

.gallery img {
    width: 100%;
    height: 150px;
    object-fit: cover;
    border-radius: 6px;
}

.notes {
    color: #888888;
    font-style: italic;
}

Els números de columnes depenen de l'amplada de la finestra de cada alumne: el que s'avalua és que expliquen que el nombre de columnes canvia tot sol.

Exercici 13.3

Exercise 13.3. A page with a sidebar. Create blog.html.

HTML.

  • a <header> with an <h1>;
  • a <div> with class="layout"; inside, a <main> with two <article> (each with an <h2> and a <p>), and an <aside> with an <h3> and a <ul> of links;
  • a <footer> with a <p>.

CSS.

  • .layout: display: grid, grid-template-columns: 1fr 280px and gap: 20px;
  • main: padding: 20px and background colour white;
  • aside: padding: 20px, background colour #f4f1fb and border-radius: 8px;
  • header, footer: background colour #2b2b40, colour white, padding: 20px and centred text.

Solució

blog.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Grid</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <header>
        <h1>My travel blog</h1>
    </header>
    <div class="layout">
        <main>
            <article>
                <h2>A weekend in Valencia</h2>
                <p>We visited the City of Arts and Sciences and ate paella by the beach.</p>
            </article>
            <article>
                <h2>Hiking in the Espadà</h2>
                <p>A long walk among cork oaks, with a view of the sea at the top.</p>
            </article>
        </main>
        <aside>
            <h3>Links</h3>
            <ul>
                <li><a href="#">Spain</a></li>
                <li><a href="#">Portugal</a></li>
                <li><a href="#">Italy</a></li>
            </ul>
        </aside>
    </div>
    <footer>
        <p>© 2026 My travel blog</p>
    </footer>
</body>

</html>
css/style.css 
.layout {
    display: grid;
    grid-template-columns: 1fr 280px;
    gap: 20px;
}

main {
    padding: 20px;
    background-color: white;
}

aside {
    padding: 20px;
    background-color: #f4f1fb;
    border-radius: 8px;
}

header, footer {
    background-color: #2b2b40;
    color: white;
    padding: 20px;
    text-align: center;
}

Exercici 13.4

Exercise 13.4. Chessboard. Create chess.html. The picture is the model.

HTML.

  • a <div> with class="board";
  • inside, 100 <div> in order, row by row (10 rows of 10): the first row, the last row, and the first and last cell of every row have class="edge" and a letter (A–H) or a number (1–8); the 64 squares in the middle have class="light" or class="dark", alternating;
  • the labels of the right column and the bottom row also have the class flip (for example class="edge flip");
  • optional: an <img> of a piece inside the squares of the first two and the last two rows.

CSS.

  • .board: display: grid, grid-template-columns: repeat(10, 50px), grid-template-rows: repeat(10, 50px), width 500px and margin: 40px auto;
  • .edge: background colour #c35e2e;
  • .light: background colour #d1beb1;
  • .dark: background colour #473d36;
  • .edge, .light, .dark: display: flex, justify-content: center and align-items: center (the content in the middle);
  • .flip: transform: rotate(180deg).
