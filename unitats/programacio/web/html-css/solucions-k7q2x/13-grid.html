Exercici 13.1

Exercise 13.1. Build a grid of 9 coloured squares, 3 columns, with a 10px gap.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Grid</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="grid">
        <div class="square">1</div>
        <div class="square">2</div>
        <div class="square">3</div>
        <div class="square">4</div>
        <div class="square">5</div>
        <div class="square">6</div>
        <div class="square">7</div>
        <div class="square">8</div>
        <div class="square">9</div>
    </div>
</body>

</html>
css/style.css 
.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;
}

.square {
    height: 100px;
    background-color: #2d5a85;
    color: white;
    font-size: 2rem;
    text-align: center;
    line-height: 100px;
}

Exercici 13.2

Exercise 13.2. Turn it into repeat(auto-fit, minmax(150px, 1fr)) and resize the window. Describe what happens.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Grid</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="grid">
        <div class="square">1</div>
        <div class="square">2</div>
        <div class="square">3</div>
        <div class="square">4</div>
        <div class="square">5</div>
        <div class="square">6</div>
        <div class="square">7</div>
        <div class="square">8</div>
        <div class="square">9</div>
    </div>
</body>

</html>
css/style.css 
.grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
    gap: 10px;
}

.square {
    height: 100px;
    background-color: #2d5a85;
    color: white;
    font-size: 2rem;
    text-align: center;
    line-height: 100px;
}
Resposta: el nombre de columnes depén de l'ample de la finestra: caben tantes columnes de com a mínim 150 px com siga possible, i les columnes s'estiren (1fr) per a omplir la fila. En una finestra ampla hi ha moltes columnes i, en estrényer-la, es van passant quadrats a la fila següent sense necessitat de cap media query.

Resultat

Exercici 13.3

Exercise 13.3. Build an image gallery of 8 photos, all the same height, with object-fit: cover.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Gallery</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="gallery">
        <img src="images/p1.jpg" alt="Photo 1 of the trip">
        <img src="images/p2.jpg" alt="Photo 2 of the trip">
        <img src="images/p3.jpg" alt="Photo 3 of the trip">
        <img src="images/p4.jpg" alt="Photo 4 of the trip">
        <img src="images/p5.jpg" alt="Photo 5 of the trip">
        <img src="images/p6.jpg" alt="Photo 6 of the trip">
        <img src="images/p7.jpg" alt="Photo 7 of the trip">
        <img src="images/p8.jpg" alt="Photo 8 of the trip">
    </div>
</body>

</html>
css/style.css 
.gallery {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 10px;
}

.gallery img {
    width: 100%;
    height: 180px;
    object-fit: cover;
}
Totes les fotos tenen la mateixa altura (180 px); object-fit: cover retalla la imatge en lloc de deformar-la.

Resultat

Exercici 13.4

Exercise 13.4. Build a two-column layout: content on the left, sidebar of 280px on the right.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Layout</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="layout">
        <main>
            <h1>Content</h1>
            <p>The main content goes in the first column. It uses all the space that is left.</p>
        </main>
        <aside>
            <h2>Sidebar</h2>
            <p>Always 280 pixels wide.</p>
        </aside>
    </div>
</body>

</html>
css/style.css 
.layout {
    display: grid;
    grid-template-columns: 1fr 280px;
    gap: 20px;
}

aside {
    padding: 16px;
    background-color: #eeeeee;
}
La primera columna (1fr) agafa tot l'espai que queda; la segona és fixa de 280 px.

Resultat
