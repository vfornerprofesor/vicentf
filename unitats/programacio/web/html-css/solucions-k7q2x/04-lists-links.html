Exercici 4.1

Exercise 4.1. Make an ordered list with the five steps of your morning routine.

Solució

routine.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My morning routine</title>
</head>

<body>
    <h1>My morning routine</h1>
    <ol>
        <li>Wake up at 7:00.</li>
        <li>Have a shower.</li>
        <li>Eat breakfast.</li>
        <li>Brush my teeth.</li>
        <li>Take the bus to school.</li>
    </ol>
</body>

</html>

Resultat

Exercici 4.3

Exercise 4.3. Save the page of exercise 4.2 as music.html. In the same folder, create another file, films.html, with a nested list of two kinds of films and two films inside each kind. Add a link from music.html to films.html. Then add links to the Wikipedia pages of three bands (in music.html) and of three films (in films.html). The Wikipedia links must open in a new tab.

Solució

music.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My music</title>
</head>

<body>
    <h1>My music</h1>
    <ul>
        <li>Rock
            <ul>
                <li><a href="https://en.wikipedia.org/wiki/Muse_(band)" target="_blank" rel="noopener">Muse</a></li>
                <li><a href="https://en.wikipedia.org/wiki/Queen_(band)" target="_blank" rel="noopener">Queen</a></li>
            </ul>
        </li>
        <li>Pop
            <ul>
                <li><a href="https://en.wikipedia.org/wiki/Coldplay" target="_blank" rel="noopener">Coldplay</a></li>
                <li>Dua Lipa</li>
            </ul>
        </li>
    </ul>
    <p><a href="films.html">See my films</a></p>
</body>

</html>
films.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My films</title>
</head>

<body>
    <h1>My films</h1>
    <ul>
        <li>Science fiction
            <ul>
                <li><a href="https://en.wikipedia.org/wiki/Interstellar_(film)" target="_blank" rel="noopener">Interstellar</a></li>
                <li><a href="https://en.wikipedia.org/wiki/Blade_Runner_2049" target="_blank" rel="noopener">Blade Runner 2049</a></li>
            </ul>
        </li>
        <li>Comedy
            <ul>
                <li><a href="https://en.wikipedia.org/wiki/Superbad" target="_blank" rel="noopener">Superbad</a></li>
                <li>Airplane!</li>
            </ul>
        </li>
    </ul>
    <p><a href="music.html">See my music</a></p>
</body>

</html>
Els enllaços a Wikipedia porten target="_blank" (i rel="noopener") per a obrir-se en una pestanya nova. Cal posar els tres de cada pàgina; ací se'n mostren dos o tres per brevetat.

Resultat

Exercici 4.4

Exercise 4.4. In the same folder, create a home page, index.html, with a title with your name and two links: one to music.html and one to films.html. From music.html and films.html you must be able to go back to the home page.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Marc Ferrer</title>
</head>

<body>
    <h1>Marc Ferrer</h1>
    <p><a href="music.html">My music</a></p>
    <p><a href="films.html">My films</a></p>
</body>

</html>
music.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My music</title>
</head>

<body>
    <h1>My music</h1>
    <p><a href="index.html">Back to home</a></p>
</body>

</html>
films.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My films</title>
</head>

<body>
    <h1>My films</h1>
    <p><a href="index.html">Back to home</a></p>
</body>

</html>
Els tres fitxers estan en la mateixa carpeta, per això els enllaços són només el nom del fitxer.
