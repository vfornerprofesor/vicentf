Exercici 14b.1

Exercise 14b.1. Children and siblings. Create family.html. You cannot add classes to the <p>: the selectors do all the work.

HTML.

  • a <div> with class="article";
  • inside, in this order: an <h2>, three <p>, and a <div> with class="box" that has two more <p> inside.

CSS.

  • .article > p: line-height: 1.6 (only the three paragraphs that are direct children);
  • h2 + p: size 1.2rem and bold (only the first paragraph after the title);
  • h2 ~ p: colour #333333;
  • .box: background colour #f4f1fb and padding: 15px;
  • .box p: colour #888888 and italic.

Check in DevTools which rules apply to the paragraphs of the box and which do not.

Solució

family.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Advanced selectors</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="article">
        <h2>Why we sleep</h2>
        <p>Sleeping is as important as eating well and doing sport.</p>
        <p>Teenagers need between 8 and 10 hours of sleep every night.</p>
        <p>Screens before bed make it harder to fall asleep.</p>
        <div class="box">
            <p>Tip: leave your phone outside the bedroom.</p>
            <p>Tip: go to bed at the same time every day.</p>
        </div>
    </div>
</body>

</html>
css/style.css 
.article > p {
    line-height: 1.6;
}

h2 + p {
    font-size: 1.2rem;
    font-weight: bold;
}

h2 ~ p {
    color: #333333;
}

.box {
    background-color: #f4f1fb;
    padding: 15px;
}

.box p {
    color: #888888;
    font-style: italic;
}

Els paràgrafs de .box no són fills directes de .article ni germans de l'h2: no reben ni el line-height ni el color #333333.

Exercise 14b.2. A league table. Create league.html.

HTML.

  • a <table> with class="league", with a <thead> (one <tr> with three <th>: Position, Team, Points) and a <tbody> with six <tr>;
  • a <ul> with class="podium" and three <li> (the first three teams).

CSS.

  • .league: width 100% and border-collapse: collapse;
  • .league th: background colour #6d5fb3, colour white and padding: 10px;

  • tbody tr:first-child: colour #b8860b and bold;

Exercici 14b.3

Exercise 14b.3. A form with attribute selectors. Create contact.html.

HTML.

  • a <form> with: an <input> type="text", an <input> type="email", an <input> type="password", a <textarea>, an <input> type="checkbox" and a <button> type="submit"; every field with its <label>;
  • under the form, a <p> with two links: one to https://developer.mozilla.org/ and one to #top.

CSS.

  • input[type="text"], input[type="email"], input[type="password"], textarea: display: block, width 100%, padding: 8px, margin-bottom: 14px, border: 1px solid #cccccc and border-radius: 6px;
  • input:focus, textarea:focus: border-color: #6d5fb3 and background colour #fbfaff;
  • input[type="checkbox"]: width 20px and height 20px;
  • button[type="submit"]: background colour #6d5fb3, colour white, border: none, padding: 10px 20px and border-radius: 6px;
  • a[href^="https"]: colour #e07a5f (only the external link changes).

Solució

contact.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Advanced selectors</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <form action="#" method="post">
        <label for="name">Name</label>
        <input type="text" id="name" name="name">

        <label for="email">Email</label>
        <input type="email" id="email" name="email">

        <label for="password">Password</label>
        <input type="password" id="password" name="password">

        <label for="message">Message</label>
        <textarea id="message" name="message"></textarea>

        <input type="checkbox" id="accept" name="accept">
        <label for="accept">I accept the rules</label>

        <p><button type="submit">Send</button></p>
    </form>

    <p>
        <a href="https://developer.mozilla.org/">MDN Web Docs</a> ·
        <a href="#top">Back to top</a>
    </p>
</body>

</html>
css/style.css 
input[type="text"],
input[type="email"],
input[type="password"],
textarea {
    display: block;
    width: 100%;
    padding: 8px;
    margin-bottom: 14px;
    border: 1px solid #cccccc;
    border-radius: 6px;
}

input:focus,
textarea:focus {
    border-color: #6d5fb3;
    background-color: #fbfaff;
}

input[type="checkbox"] {
    width: 20px;
    height: 20px;
}

button[type="submit"] {
    background-color: #6d5fb3;
    color: white;
    border: none;
    padding: 10px 20px;
    border-radius: 6px;
}

a[href^="https"] {
    color: #e07a5f;
}

Exercici 14b.4

Exercise 14b.4. :not(), ::first-letter and the cascade. Create magazine.html.

HTML.

  • a <nav> with five <a>; the second one has class="active";
  • an <article> with a <p> with class="intro" and two more <p>;
  • an <h2> with id="main-title" and class="title".

CSS.

  • nav a:not(.active): colour #888888;
  • nav a.active: colour #6d5fb3 and bold;
  • .intro::first-letter: size 3rem and colour #6d5fb3;
  • in this order: #main-title in red, .title in green and h2 in blue.

Before you reload, write in an HTML comment which colour the <h2> will have. Then move the rules around: does the order change anything? Why?

Solució

magazine.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Advanced selectors</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <nav>
        <a href="#">Home</a>
        <a href="#" class="active">Reviews</a>
        <a href="#">Games</a>
        <a href="#">Music</a>
        <a href="#">Contact</a>
    </nav>

    <article>
        <p class="intro">Once upon a time, a group of students decided to make their own magazine.</p>
        <p>They wrote about games, music and films.</p>
        <p>Every month they published a new issue.</p>
    </article>

    <!-- Prediction: red. The id is the most specific selector,
         so it wins wherever it is written. Changing the order
         does not change anything: order only matters when the
         selectors have the same specificity. -->
    <h2 id="main-title" class="title">Issue 1</h2>
</body>

</html>
css/style.css 
nav a:not(.active) {
    color: #888888;
}

nav a.active {
    color: #6d5fb3;
    font-weight: bold;
}

.intro::first-letter {
    font-size: 3rem;
    color: #6d5fb3;
}

#main-title {
    color: red;
}

.title {
    color: green;
}

h2 {
    color: blue;
}
