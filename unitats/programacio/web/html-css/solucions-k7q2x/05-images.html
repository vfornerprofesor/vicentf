Exercici 5.1

Exercise 5.1. Download three images, put them in an images folder and show them in a page, each one with a good alt text and a heading above it.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My images</title>
</head>

<body>
    <h1>My images</h1>

    <h2>The mountain</h2>
    <img src="images/mountain.jpg" alt="Snow on a mountain at sunrise" width="400">

    <h2>The beach</h2>
    <img src="images/beach.jpg" alt="Empty beach with turquoise water" width="400">

    <h2>The city</h2>
    <img src="images/city.jpg" alt="Skyline of a city at night with lights" width="400">
</body>

</html>
Les tres imatges estan en la carpeta images/. Cada alt descriu què es veu (no val "foto 1").

Resultat

Exercici 5.2

Exercise 5.2. Add a <figure> with a caption for one of them.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My images</title>
</head>

<body>
    <h1>My images</h1>

    <h2>The mountain</h2>
    <figure>
        <img src="images/mountain.jpg" alt="Snow on a mountain at sunrise" width="400">
        <figcaption>Sunrise in the Alps, last winter.</figcaption>
    </figure>
</body>

</html>

Resultat

Exercici 5.3

Exercise 5.3. Make one of the images a link to the website where you found it.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My images</title>
</head>

<body>
    <h1>My images</h1>

    <a href="https://unsplash.com" target="_blank" rel="noopener">
        <img src="images/mountain.jpg" alt="Snow on a mountain at sunrise" width="400">
    </a>
</body>

</html>

Resultat

Exercici 5.4

Exercise 5.4. Break one image on purpose: change its src to a name that does not exist. Reload and look at what the browser shows. Now you know why alt matters.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My images</title>
</head>

<body>
    <h1>My images</h1>
    <img src="images/does-not-exist.jpg" alt="Snow on a mountain at sunrise" width="400">
</body>

</html>
Resposta: el navegador no troba el fitxer i mostra la icona d'imatge trencada amb el text de l'alt. Per això un bon alt és necessari: encara es pot entendre què havia d'haver-hi.
