Exercici 1.1

Exercise 1.1. Change the text of the h1 to your name. Save and reload.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My first page</title>
</head>

<body>
    <h1>Marc Ferrer</h1>
    <p>This is my first web page.</p>
</body>

</html>

Resultat

Exercici 1.3

Exercise 1.3. Open your page with DevTools and find your h1 in the Elements tab. Change its text from DevTools. Then reload the page. What happened? Write the answer in a comment inside your HTML file.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My first page</title>
</head>

<body>
    <h1>Marc Ferrer</h1>
    <p>This is my first web page.</p>
    <!-- 1.3: the change is lost when I reload. DevTools only changes the
         copy that is in the browser memory, not my file. -->
</body>

</html>
Resposta: el canvi desapareix en recarregar. DevTools només modifica la còpia que el navegador té en memòria, no el fitxer del disc; per a canviar-lo de veres cal editar el fitxer i guardar.
