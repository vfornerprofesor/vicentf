Exercici 10.1

Exercise 10.1. Choose a Google Font for your headings and a different one for the body text. Apply them.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My page</title>
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Lato&amp;family=Poppins:wght@600&amp;display=swap" rel="stylesheet">
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <header>
        <h1>Marc Ferrer</h1>
        <nav>
            <a href="index.html">Home</a>
            <a href="music.html">Music</a>
            <a href="films.html">Films</a>
        </nav>
    </header>
    <main>
        <h2>About me</h2>
        <p>I like rock music, above all bands with two guitars. My favourite film is Interstellar.
            I have seen it four times and I always see something new.</p>
    </main>
</body>

</html>
css/style.css 
body {
    font-family: 'Lato', Arial, sans-serif;
}

h1,
h2 {
    font-family: 'Poppins', Arial, sans-serif;
}
Una font per als títols (Poppins) i una altra per al text (Lato). Totes dues porten una font genèrica de reserva (sans-serif).

Resultat

Exercici 10.5

Exercise 10.5. Personal page. Reproduce the page in the picture: fonts, sizes, colours and text alignment. The HTML is given.

Fitxer de partida: ex1.html

Solució

index.html 
<!DOCTYPE html>
<html lang="ca">

<head>
    <meta charset="utf-8">
    <title>Pàgina personal</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="card">
        <div class="photo">
            <img src="images/bike.jpg" alt="Un ciclista amb una bicicleta de muntanya entre arbres" width="400">
        </div>
        <div class="info">
            <h1>Pere Franch</h1>
            <p>Vaig nàixer el 3 de Setembre de 2006 i tinc 17 anys</p>
            <h2>Interessos</h2>
            <table>
                <tr>
                    <td>Bicicleta</td>
                    <td>Motos</td>
                </tr>
                <tr>
                    <td>Llegir</td>
                    <td>Videojocs</td>
                </tr>
                <tr>
                    <td>Eixir amb els amics</td>
                    <td>Música</td>
                </tr>
            </table>
            <p>
                <a class="button" href="#">INSTAGRAM</a>
                <a class="button" href="#">TWITTER</a>
            </p>
        </div>
    </div>
</body>

</html>
css/style.css 
body {
    margin: 0;
    padding: 40px 0;
    background-color: #eeeeee;
    font-family: Arial, Helvetica, sans-serif;
}

.card {
    display: flex;
    align-items: center;
    gap: 30px;
    width: 860px;
    max-width: 90%;
    margin: 0 auto;
    padding: 20px;
    background-color: #ed695b;
    border-radius: 4px;
    box-shadow: 0 2px 6px rgba(0, 0, 0, 0.3);
}

.photo img {
    display: block;
    width: 400px;
    max-width: 100%;
}

.info {
    flex: 1;
    text-align: center;
}

table {
    width: 100%;
    margin-bottom: 20px;
}

td {
    padding: 4px;
}

.button {
    display: inline-block;
    padding: 14px 20px;
    background-color: #f5f0be;
    color: #111111;
    text-decoration: none;
    border-radius: 4px;
}

.button:hover {
    background-color: #ffffff;
}
Estructura: un div.card principal (amplària i marges) amb dos fills: la foto a l'esquerra i la informació a la dreta, col·locats amb flexbox. La taula ocupa tota l'amplada (width: 100%) i els botons canvien de color amb :hover.

Exercici 10.6

Exercise 10.6. Sign-up form. Style the form you built in lesson 7: fields, labels, button, focus state.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>Sign up</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <form action="#" method="post">
        <h1>Sign up</h1>
        <p>
            <label for="name">Name</label>
            <input type="text" id="name" name="name" required>
        </p>
        <p>
            <label for="mail">Email</label>
            <input type="email" id="mail" name="mail" required>
        </p>
        <p>
            <label for="pass">Password</label>
            <input type="password" id="pass" name="pass" required minlength="8">
        </p>
        <p>
            <button type="submit">Send</button>
        </p>
    </form>
</body>

</html>
css/style.css 
body {
    font-family: Arial, Helvetica, sans-serif;
    background-color: #f4f4f8;
}

form {
    max-width: 360px;
    margin: 40px auto;
    padding: 24px;
    background-color: white;
    border-radius: 8px;
}

label {
    display: block;
    margin-bottom: 4px;
    font-weight: bold;
}

input {
    width: 100%;
    padding: 8px;
    border: 1px solid #bbbbbb;
    border-radius: 4px;
    font-size: 1rem;
}

input:focus {
    border-color: #6d5fb3;
    outline: 2px solid #6d5fb3;
}

button {
    padding: 10px 20px;
    border: none;
    border-radius: 4px;
    background-color: #6d5fb3;
    color: white;
    font-size: 1rem;
    cursor: pointer;
}

button:hover {
    background-color: #53469a;
}
L'estat :focus marca el camp actiu amb un color diferent i una línia al voltant.
