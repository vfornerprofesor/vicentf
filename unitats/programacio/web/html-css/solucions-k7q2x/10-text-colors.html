Exercici 10.1

Exercise 10.1. A poem with Google Fonts. Create poem.html and choose two fonts in Google Fonts: Pacifico for the title and Lora for the text. Copy their <link> into the <head>, before your style.css.

HTML.

  • an <h1> with the title of the poem;
  • a <p> with class="author" with the name of the poet;
  • three <p> with class="verse", one per stanza (use <br> to break the lines).

CSS.

  • body: font "Lora", serif;
  • h1: font "Pacifico", cursive, size 3rem, centred (text-align: center) and colour #6d5fb3;
  • .author: italic (font-style: italic), aligned to the right and colour #888888;
  • .verse: size 1.1rem and line-height: 1.8.

Solució

poem.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text, fonts and colours</title>
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link href="https://fonts.googleapis.com/css2?family=Lora&amp;family=Pacifico&amp;display=swap" rel="stylesheet">
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <h1>The Road Not Taken</h1>
    <p class="author">Robert Frost</p>
    <p class="verse">
        Two roads diverged in a yellow wood,<br>
        And sorry I could not travel both<br>
        And be one traveler, long I stood
    </p>
    <p class="verse">
        Then took the other, as just as fair,<br>
        And having perhaps the better claim,<br>
        Because it was grassy and wanted wear
    </p>
    <p class="verse">
        I shall be telling this with a sigh<br>
        Somewhere ages and ages hence:<br>
        I took the one less traveled by
    </p>
</body>

</html>
css/style.css 
body {
    font-family: "Lora", serif;
}

h1 {
    font-family: "Pacifico", cursive;
    font-size: 3rem;
    text-align: center;
    color: #6d5fb3;
}

.author {
    font-style: italic;
    text-align: right;
    color: #888888;
}

.verse {
    font-size: 1.1rem;
    line-height: 1.8;
}

Exercici 10.2

Exercise 10.2. A newspaper article. Create news.html.

HTML.

  • an <article> with an <h1> (the headline);
  • a <p> with class="subtitle";
  • a <p> with class="date" (for example “25 November 2026”);
  • three <p> with the text of the news.

CSS.

  • body: size 1rem and line-height: 1.6;
  • h1: size 2.5rem and font-weight: 800;
  • .subtitle: size 1.25rem and font-weight: 300;
  • .date: in capitals (text-transform: uppercase), letter-spacing: 2px, size 0.8rem and colour #888888;
  • article p: justified (text-align: justify).

Change the font-size of body to 1.25rem: everything with rem grows at the same time.

Solució

news.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text, fonts and colours</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <article>
        <h1>Students build their own websites</h1>
        <p class="subtitle">The first-year class publishes twenty personal pages</p>
        <p class="date">25 November 2026</p>
        <p>After eight weeks of HTML and CSS, the students of the first year have published their own websites. Every page has a menu, a gallery and a contact form.</p>
        <p>The teacher says that the most difficult part was choosing the colours. Some students changed their colour scheme five times before they were happy.</p>
        <p>Next term they will add JavaScript to make the pages interactive.</p>
    </article>
</body>

</html>
css/style.css 
body {
    font-size: 1rem;
    line-height: 1.6;
}

h1 {
    font-size: 2.5rem;
    font-weight: 800;
}

.subtitle {
    font-size: 1.25rem;
    font-weight: 300;
}

.date {
    text-transform: uppercase;
    letter-spacing: 2px;
    font-size: 0.8rem;
    color: #888888;
}

article p {
    text-align: justify;
}

El subtítol i la data també són p dins d'article: reben el justificat, però conserven la seua mida i color perquè ningú més els canvia.

Exercici 10.3

Exercise 10.3. Navigation links. Create links.html.

HTML.

  • a <header> with a <nav> inside and four <a>: Home, Gallery, Blog, Contact;
  • a <main> with a <p> that contains a normal link <a> to any website.

CSS.

  • header: background colour #222222 and padding: 20px;
  • nav a: colour white, no underline, in capitals and margin-right: 20px;
  • nav a:hover: underlined (text-decoration: underline) and colour #ffd166;
  • main a: colour #6d5fb3, bold.

Check that the link of the <main> is still underlined: only the links of the <nav> lose the underline.

Solució

links.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text, fonts and colours</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <header>
        <nav>
            <a href="#">Home</a>
            <a href="#">Gallery</a>
            <a href="#">Blog</a>
            <a href="#">Contact</a>
        </nav>
    </header>
    <main>
        <p>Learn more about CSS on <a href="https://developer.mozilla.org/">MDN Web Docs</a>.</p>
    </main>
</body>

</html>
css/style.css 
header {
    background-color: #222222;
    padding: 20px;
}

nav a {
    color: white;
    text-decoration: none;
    text-transform: uppercase;
    margin-right: 20px;
}

nav a:hover {
    text-decoration: underline;
    color: #ffd166;
}

main a {
    color: #6d5fb3;
    font-weight: bold;
}

Exercici 10.4

Exercise 10.4. A header with a background image. Create hero.html and put a photo called hero.jpg in a folder images.

HTML.

  • a <header> with class="hero", with an <h1> and a <p> inside;
  • a <section> with class="highlight" and a <p> inside.

CSS.

  • .hero: background image url("../images/hero.jpg"), background-size: cover, background-position: center, padding: 80px 20px, centred text and colour white;
  • .hero h1, .hero p: text-shadow: 0 2px 4px rgba(0, 0, 0, 0.7), so you can read the text on any photo;
  • body: background colour #fafafa;
  • .highlight: background colour rgba(109, 95, 179, 0.15).

The path has ../ because the CSS file is inside the css folder: first it goes up one folder and then it goes into images.

Solució

hero.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text, fonts and colours</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <header class="hero">
        <h1>Welcome to Betxí</h1>
        <p>A small town with a big castle</p>
    </header>
    <section class="highlight">
        <p>The Palace of Betxí is a Renaissance castle from the 16th century.</p>
    </section>
</body>

</html>
css/style.css 
body {
    background-color: #fafafa;
}

.hero {
    background-image: url("../images/hero.jpg");
    background-size: cover;
    background-position: center;
    padding: 80px 20px;
    text-align: center;
    color: white;
}

.hero h1, .hero p {
    text-shadow: 0 2px 4px rgba(0, 0, 0, 0.7);
}

.highlight {
    background-color: rgba(109, 95, 179, 0.15);
}

Exercici 10.5

Exercise 10.5. Personal page. Create personal.html. The picture is the model.

HTML.

  • a <div> with class="profile" that contains everything;
  • inside, an <img> with class="photo" (a photo of your hobby) and a <div> with class="info";
  • inside .info: an <h1> with your name, a <p> with your birthday and age, an <h2> “Interests”, a <table> with three <tr> and two <td> in each row (six interests), and two <a> with class="button" (Instagram and Twitter).

CSS.

  • body: font Arial, sans-serif and background colour #f0f0f0;
  • .profile: background colour #ef6b5c, padding: 20px, margin: 50px auto, width 860px and border-radius: 6px;

  • table: width 100%;
  • .button: background colour #f6f1bd, colour black, no underline, in capitals and padding: 18px 20px;

The photo and the information are not side by side yet: you will put them in a row with flexbox in lesson 12. For now, one under the other is fine.

Exercici 10.6

Exercise 10.6. Sign-up form. Style the sign-up form of exercise 7.4 (signup.html). The picture is the model.

HTML.

  • the form of exercise 7.4, inside a <div> with class="box";
  • an <h1> “Computerize” and an <h2> “Sign up” at the top of the box;
  • every <label> with its for and every <input> with its id and its type (text, date, email, password, number, radio, checkbox) and a <button> type="submit".

CSS.

  • body: background colour #ff7f50 and font "Noto Sans", sans-serif (Google Fonts);
  • .box: background colour white, width 500px, margin: 40px auto, padding: 20px, border-radius: 6px and centred text;
  • h1, h2, label: colour #ff7f50; h1, h2: in capitals;
  • label: display: block;
  • input[type="text"], input[type="date"], input[type="email"], input[type="password"], input[type="number"]: width 300px, border: 1px solid #ff7f50 and border-radius: 3px;
  • input:focus: outline: 2px solid #ff7f50;
  • button: width 300px, background colour #ff7f50, colour white, border: none, size 1.2rem and in capitals.

The attribute selectors (input[type="text"]) are explained in Advanced selectors; for now, copy them as they are.

Solució

signup.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text, fonts and colours</title>
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link href="https://fonts.googleapis.com/css2?family=Noto+Sans&amp;display=swap" rel="stylesheet">
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="box">
        <h1>Computerize</h1>
        <h2>Sign up</h2>
        <form action="#" method="post">
            <label for="name">Name:</label>
            <input type="text" id="name" name="name">

            <label for="surname">Surname:</label>
            <input type="text" id="surname" name="surname">

            <label for="birthday">Birthday:</label>
            <input type="date" id="birthday" name="birthday">

            <label for="email">Email:</label>
            <input type="email" id="email" name="email">

            <label for="password">Password:</label>
            <input type="password" id="password" name="password">

            <label for="devices">Number of computing devices:</label>
            <input type="number" id="devices" name="devices" min="0">

            <p>
                <label>Gender:</label>
                Male: <input type="radio" name="gender" value="male">
                Female: <input type="radio" name="gender" value="female">
                Other: <input type="radio" name="gender" value="other">
            </p>

            <p>
                Do you want to receive the newsletter?
                <input type="checkbox" id="newsletter" name="newsletter">
            </p>

            <button type="submit">Sign up</button>
        </form>
    </div>
</body>

</html>
