Exercici 12.1

Exercise 12.1. Three ways to put boxes in a row. Create rows.html.

HTML.

  • three <div> one after the other, with the classes row, row between and row column;
  • inside each one, three <div> with class="box" and the texts One, Two, Three.

CSS.

  • .row: display: flex, justify-content: center, gap: 20px, padding: 20px, margin-bottom: 20px and background colour #eeeeee;
  • .box: width 100px, height 100px, background colour #c4baeb and border-radius: 8px;
  • .row.between: justify-content: space-between;
  • .row.column: flex-direction: column and align-items: center.

Write a <p> under each row explaining what changes.

Solució

rows.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Flexbox</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="row">
        <div class="box">One</div>
        <div class="box">Two</div>
        <div class="box">Three</div>
    </div>
    <p>justify-content: center puts the three boxes together in the middle, with 20px between them.</p>

    <div class="row between">
        <div class="box">One</div>
        <div class="box">Two</div>
        <div class="box">Three</div>
    </div>
    <p>space-between puts the first box on the left, the last one on the right, and the free space between them.</p>

    <div class="row column">
        <div class="box">One</div>
        <div class="box">Two</div>
        <div class="box">Three</div>
    </div>
    <p>flex-direction: column puts the boxes one under the other; align-items: center centres them horizontally.</p>
</body>

</html>
css/style.css 
.row {
    display: flex;
    justify-content: center;
    gap: 20px;
    padding: 20px;
    margin-bottom: 20px;
    background-color: #eeeeee;
}

.box {
    width: 100px;
    height: 100px;
    background-color: #c4baeb;
    border-radius: 8px;
}

.row.between {
    justify-content: space-between;
}

.row.column {
    flex-direction: column;
    align-items: center;
}

HTML.

HTML.

  • an <h1> “Countries I want to visit”;
  • a <div> with class="countries" and three <div> with class="country";

HTML.
