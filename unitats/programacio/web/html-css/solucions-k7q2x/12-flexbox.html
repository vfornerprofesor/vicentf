Exercici 12.1

Exercise 12.1. Put three coloured boxes in a row, centred, with a 20px gap.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Flexbox</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="container">
        <div class="box">1</div>
        <div class="box">2</div>
        <div class="box">3</div>
    </div>
</body>

</html>
css/style.css 
.container {
    display: flex;
    justify-content: center;
    gap: 20px;
}

.box {
    width: 100px;
    height: 100px;
    background-color: #2d5a85;
    color: white;
    font-size: 2rem;
    text-align: center;
    line-height: 100px;
}

Exercici 12.2

Exercise 12.2. Repeat with space-between, then with column. Write down the difference.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Flexbox</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="container">
        <div class="box">1</div>
        <div class="box">2</div>
        <div class="box">3</div>
    </div>
</body>

</html>
css/style.css 
/* a) space-between */
.container {
    display: flex;
    justify-content: space-between;
}

/* b) column: canvia "justify-content: space-between" per aquestes dues línies
.container {
    display: flex;
    flex-direction: column;
}
*/

.box {
    width: 100px;
    height: 100px;
    background-color: #2d5a85;
    color: white;
    font-size: 2rem;
    text-align: center;
    line-height: 100px;
}
Resposta: amb space-between la primera caixa va a l'extrem esquerre, l'última a l'extrem dret i l'espai que sobra es reparteix entre elles. Amb flex-direction: column l'eix principal passa a ser vertical: les caixes s'apilen una damunt de l'altra (i justify-content passa a actuar en vertical).

Exercici 12.3

Exercise 12.3. Centre a single box in the middle of a 400px tall container, both horizontally and vertically.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <div class="container">
        <div class="box">Centre</div>
    </div>
</body>

</html>
css/style.css 
.container {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 400px;
    background-color: #eeeeee;
}

.box {
    width: 100px;
    height: 100px;
    background-color: #2d5a85;
    color: white;
    font-size: 2rem;
    text-align: center;
    line-height: 100px;
}
justify-content centra en l'eix principal (horitzontal) i align-items en l'eix transversal (vertical).

Exercici 12.4

Exercise 12.4. Build the nav bar of the example with your own colours.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Nav</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <header class="site-header">
        <a class="logo" href="index.html">Marc.dev</a>
        <nav class="menu">
            <a href="index.html">Home</a>
            <a href="music.html">Music</a>
            <a href="films.html">Films</a>
            <a href="contact.html">Contact</a>
        </nav>
    </header>
</body>

</html>
css/style.css 
* {
    box-sizing: border-box;
}

body {
    margin: 0;
    font-family: Arial, Helvetica, sans-serif;
}

.site-header {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 12px 24px;
    background-color: #1f3c5a;
}

.logo {
    color: #f2a541;
    font-size: 1.4rem;
    font-weight: bold;
    text-decoration: none;
}

.menu {
    display: flex;
    gap: 8px;
}

.menu a {
    padding: 8px 14px;
    border-radius: 6px;
    color: white;
    text-decoration: none;
    transition: background-color 0.25s ease;
}

.menu a:hover {
    background-color: #f2a541;
    color: #1f3c5a;
}

Exercici 12.5

Exercise 12.5. Build a row of 6 cards (image + title + text) that wraps to a second line when the window is narrow.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Cards</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <h1>Places</h1>
    <div class="cards">
        <article class="card">
            <img src="images/c1.jpg" alt="Mountain at sunrise">
            <h2>Mountain</h2>
            <p>Snow and silence at 2,000 metres.</p>
        </article>
        <article class="card">
            <img src="images/c2.jpg" alt="Empty beach">
            <h2>Beach</h2>
            <p>Turquoise water and no people.</p>
        </article>
        <article class="card">
            <img src="images/c3.jpg" alt="City at night">
            <h2>City</h2>
            <p>Lights, noise and good food.</p>
        </article>
        <article class="card">
            <img src="images/c4.jpg" alt="Forest path">
            <h2>Forest</h2>
            <p>A path under very tall trees.</p>
        </article>
        <article class="card">
            <img src="images/c5.jpg" alt="Desert dunes">
            <h2>Desert</h2>
            <p>Dunes as far as you can see.</p>
        </article>
        <article class="card">
            <img src="images/c6.jpg" alt="Lake with mountains">
            <h2>Lake</h2>
            <p>A mirror between two mountains.</p>
        </article>
    </div>
</body>

</html>
css/style.css 
* {
    box-sizing: border-box;
}

body {
    margin: 0;
    padding: 20px;
    font-family: Arial, Helvetica, sans-serif;
}

.cards {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}

.card {
    flex: 1 1 250px;
    max-width: 320px;
    padding: 12px;
    border: 1px solid #dddddd;
    border-radius: 12px;
}

.card img {
    display: block;
    width: 100%;
    height: 160px;
    object-fit: cover;
    border-radius: 8px;
}
flex-wrap: wrap passa les targetes a la línia següent quan no caben; flex: 1 1 250px les fa créixer i encongir-se a partir d'una base de 250 px.
