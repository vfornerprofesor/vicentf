Exercici 15.1

Exercise 15.1. A page with variables. Create variables.html.

HTML.

  • a <header> with an <h1>;
  • a <main> with three <div> with class="card", each one with an <img>, an <h2>, a <p> and an <a> with class="btn".

CSS.

  • a :root block with four variables: --main-color: #6d5fb3, --main-color-dark: #4b3f8f, --light-grey: #f4f1fb and --text-color: #333333;
  • body: colour var(--text-color) and background colour var(--light-grey);
  • header: background colour var(--main-color), colour white and padding: 20px;
  • h2: colour var(--main-color);
  • .btn: background colour var(--main-color), colour white, no underline and padding: 8px 16px;
  • .btn:hover: background colour var(--main-color-dark).

Change only --main-color to #e07a5f: the header, the titles and the buttons change at the same time.

Solució

variables.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS variables and good practice</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <header>
        <h1>My design system</h1>
    </header>
    <main>
        <div class="card">
            <img src="images/card1.jpg" alt="Photo 1">
            <h2>Card 1</h2>
            <p>A short text about this card.</p>
            <a class="btn" href="#">Read more</a>
        </div>
        <div class="card">
            <img src="images/card2.jpg" alt="Photo 2">
            <h2>Card 2</h2>
            <p>A short text about this card.</p>
            <a class="btn" href="#">Read more</a>
        </div>
        <div class="card">
            <img src="images/card3.jpg" alt="Photo 3">
            <h2>Card 3</h2>
            <p>A short text about this card.</p>
            <a class="btn" href="#">Read more</a>
        </div>
    </main>
</body>

</html>
css/style.css 
:root {
    --main-color: #6d5fb3;
    --main-color-dark: #4b3f8f;
    --light-grey: #f4f1fb;
    --text-color: #333333;
}

body {
    color: var(--text-color);
    background-color: var(--light-grey);
}

header {
    background-color: var(--main-color);
    color: white;
    padding: 20px;
}

h2 {
    color: var(--main-color);
}

.btn {
    background-color: var(--main-color);
    color: white;
    text-decoration: none;
    padding: 8px 16px;
}

.btn:hover {
    background-color: var(--main-color-dark);
}

Exercici 15.4

Exercise 15.4. Put your CSS in order. Take the CSS of variables.html and organise it.

HTML.

  • no changes in the HTML, except the class names that you rename in the CSS.

CSS.

  • five section comments, in this order: /* ============ 1. Variables ============ */, 2. Reset and base, 3. Layout, 4. Components and 5. Media queries;
  • move every rule to its section;
  • add a @media (min-width: 900px) in the last section that puts the three cards in a row with display: grid and grid-template-columns: repeat(3, 1fr) on main;
  • if a class has a name that says how it looks (.red, .big, .box1), rename it to what it is (.warning, .title, .card), in the HTML and in the CSS.

Go through the checklist of this page and fix everything that fails.

css/style.css 
/* ============ 1. Variables ============ */
:root {
    --main-color: #6d5fb3;
    --main-color-dark: #4b3f8f;
    --light-grey: #f4f1fb;
    --text-color: #333333;
    --radius: 12px;
    --shadow: 0 2px 8px rgba(0, 0, 0, 0.12);
}

/* ============ 2. Reset and base ============ */
* {
    box-sizing: border-box;
}

body {
    margin: 0;
    color: var(--text-color);
    background-color: var(--light-grey);
}

h2 {
    color: var(--main-color);
}

img {
    max-width: 100%;
}

/* ============ 3. Layout ============ */
header {
    background-color: var(--main-color);
    color: white;
    padding: 20px;
}

main {
    display: grid;
    gap: 20px;
    padding: 20px;
}

/* ============ 4. Components ============ */
.card {
    background-color: white;
    padding: 20px;
    border-radius: var(--radius);
    box-shadow: var(--shadow);
    transition: transform 0.3s ease;
}

.card:hover {
    transform: translateY(-5px);
}

.card img {
    width: 100%;
    border-radius: var(--radius);
}

.btn {
    background-color: var(--main-color);
    color: white;
    text-decoration: none;
    padding: 8px 16px;
    border-radius: var(--radius);
    transition: background-color 0.3s ease;
    cursor: pointer;
}

.btn:hover {
    background-color: var(--main-color-dark);
}

/* ============ 5. Media queries ============ */
@media (min-width: 900px) {
    main {
        grid-template-columns: repeat(3, 1fr);
    }
}

Al model les classes ja tenen noms de funció (.card, .btn), així que no cal canviar-ne cap. Si l'alumne té .red, .box1... es valora que les haja canviades.
