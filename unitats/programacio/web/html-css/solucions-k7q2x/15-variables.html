Exercici 15.1

Exercise 15.1. Take your CSS file and move every colour to a :root block of variables. Then change your main colour and check that the whole page follows.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Variables</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <header class="site-header">
        <h1>Marc.dev</h1>
    </header>
    <main class="container">
        <article class="card">
            <h2>Project one</h2>
            <p>A small website about my favourite band.</p>
            <a class="button" href="#">See more</a>
        </article>
        <article class="card">
            <h2>Project two</h2>
            <p>A responsive menu with flexbox.</p>
            <a class="button" href="#">See more</a>
        </article>
    </main>
</body>

</html>
css/style.css 
:root {
    --color-primary: #1f3c5a;
    --color-accent: #f2a541;
    --color-bg: #f6f5f0;
    --color-text: #23272f;
    --color-surface: #ffffff;
}

body {
    margin: 0;
    font-family: Arial, Helvetica, sans-serif;
    color: var(--color-text);
    background-color: var(--color-bg);
}

.site-header {
    padding: 16px 24px;
    background-color: var(--color-primary);
}

.site-header h1 {
    margin: 0;
    color: var(--color-accent);
}

.card {
    margin-bottom: 16px;
    padding: 20px;
    background-color: var(--color-surface);
    border: 1px solid var(--color-primary);
}

.button {
    display: inline-block;
    padding: 8px 16px;
    background-color: var(--color-accent);
    color: var(--color-primary);
    text-decoration: none;
}

.container {
    max-width: 800px;
    margin: 0 auto;
    padding: 20px;
}
Per a comprovar que tot segueix el canvi, es modifica només --color-primary i es veu que la capçalera, la vora de les targetes i el color del botó canvien alhora.

css/style.css 
/* =========================================================
   My website - styles
   ========================================================= */

/* ---------- 1. Variables ---------- */
:root {
    --color-primary: #1f3c5a;
    --color-accent: #f2a541;
    --color-bg: #f6f5f0;
    --color-text: #23272f;
    --color-surface: #ffffff;
    --radius: 12px;
    --shadow: 0 4px 14px rgba(31, 60, 90, 0.15);
}

/* ---------- 2. Base ---------- */
body {
    margin: 0;
    font-family: Arial, Helvetica, sans-serif;
    color: var(--color-text);
    background-color: var(--color-bg);
}

/* ---------- 3. Layout ---------- */
.container {
    max-width: 800px;
    margin: 0 auto;
    padding: 20px;
}

.site-header {
    padding: 16px 24px;
    background-color: var(--color-primary);
}

.site-header h1 {
    margin: 0;
    color: var(--color-accent);
}

/* ---------- 4. Components ---------- */
.card {
    margin-bottom: 16px;
    padding: 20px;
    background-color: var(--color-surface);
    border-radius: var(--radius);
    box-shadow: var(--shadow);
}

.button {
    display: inline-block;
    padding: 8px 16px;
    background-color: var(--color-accent);
    color: var(--color-primary);
    text-decoration: none;
    border-radius: var(--radius);
}
El fitxer queda dividit en seccions comentades i les regles s'ordenen de general a específic: variables, base, layout i components.
