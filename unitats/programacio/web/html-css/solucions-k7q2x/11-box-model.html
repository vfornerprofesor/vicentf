Exercici 11.1

Exercise 11.1. A profile card. Create profile.html.

HTML.

  • a <div> with class="card";
  • inside: an <img> (your avatar or any photo), an <h2> with a name, a <p> with a short description and an <a> with class="button" and the text “Follow”.

CSS.

  • * { box-sizing: border-box; } at the top of the file;
  • body: background colour #eeeeee;
  • .card: width 300px, padding: 20px, border: 1px solid #dddddd, background colour white and margin: 40px auto (it is centred);
  • .card img: width 100%;
  • .button: display: inline-block, padding: 10px 20px, background colour #6d5fb3, colour white, no underline and border-radius: 6px.

Solució

profile.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>The box model</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="card">
        <img src="images/avatar.jpg" alt="My avatar">
        <h2>Laura Gil</h2>
        <p>I like drawing, video games and my cat Pixel.</p>
        <a class="button" href="#">Follow</a>
    </div>
</body>

</html>
css/style.css 
* {
    box-sizing: border-box;
}

body {
    background-color: #eeeeee;
}

.card {
    width: 300px;
    padding: 20px;
    border: 1px solid #dddddd;
    background-color: white;
    margin: 40px auto;
}

.card img {
    width: 100%;
}

.button {
    display: inline-block;
    padding: 10px 20px;
    background-color: #6d5fb3;
    color: white;
    text-decoration: none;
    border-radius: 6px;
}

Exercici 11.2

Exercise 11.2. Measure two boxes. Create boxes.html. Do not put the universal box-sizing rule in this file.

HTML.

  • a <div> with class="box-a" and a <div> with class="box-b"; each one with a <p> inside.

CSS.

  • .box-a, .box-b: width 200px, padding: 20px, border: 5px solid #6d5fb3 and margin-bottom: 20px;
  • .box-b: box-sizing: border-box.

Measure both boxes in DevTools and write the real width inside each <p> (for example “I am 250px wide”). Explain in one more <p> why they are different.

Solució

boxes.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>The box model</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="box-a">
        <p>I am 250px wide: 200 + 20 + 20 (padding) + 5 + 5 (border).</p>
    </div>
    <div class="box-b">
        <p>I am 200px wide: with border-box, the padding and the border go inside.</p>
    </div>
    <p>They are different because box-a uses content-box (the default): the width is only the content, and the padding and the border are added outside. box-b uses border-box: the width includes the padding and the border.</p>
</body>

</html>
css/style.css 
.box-a, .box-b {
    width: 200px;
    padding: 20px;
    border: 5px solid #6d5fb3;
    margin-bottom: 20px;
}

.box-b {
    box-sizing: border-box;
}

Exercici 11.3

Exercise 11.3. Products with rounded corners and shadows. Create shop.html.

HTML.

  • a <section> with three <div> with class="product";
  • each product has an <h3>, a <p> with the description and a <span> with class="price" (for example “12 €”).

CSS.

  • .product: padding: 16px, margin-bottom: 20px, background colour white, border-radius: 12px and box-shadow: 0 2px 8px rgba(0, 0, 0, 0.12);
  • .product:hover: box-shadow: 0 6px 18px rgba(0, 0, 0, 0.25);
  • .price: display: inline-block, padding: 4px 10px, background colour #ffd166, border-radius: 20px and bold.

</head>

<body>
    <section>
        <div class="product">
            <h3>Wireless mouse</h3>
            <p>Small, silent and with a battery that lasts a year.</p>
            <span class="price">12 €</span>
        </div>
        <div class="product">
            <h3>Keyboard</h3>
            <p>Mechanical keyboard with lights.</p>
            <span class="price">45 €</span>
        </div>
        <div class="product">
            <h3>Headphones</h3>
            <p>Comfortable headphones with a microphone.</p>
            <span class="price">25 €</span>
        </div>
    </section>
</body>

</html>

Exercici 11.4

Exercise 11.4. A centred page with button links. Create centred.html.

HTML.

  • a <div> with class="container" that contains all the page;
  • inside: a <header> with an <h1> and a <nav> with four <a>; a <main> with two <section> (each one with an <h2> and a <p>); a <footer> with a <p>.

CSS.

  • .container: max-width: 1000px, margin: 0 auto and padding: 0 20px;
  • nav a: display: inline-block, padding: 10px 18px, margin: 4px, background colour #3d405b, colour white, no underline and border-radius: 8px;
  • nav a:hover: background colour #e07a5f;
  • section: padding: 20px, margin-bottom: 30px and border-left: 5px solid #e07a5f;
  • footer: border-top: 1px solid #cccccc, padding-top: 20px and margin-top: 40px.

Make the window wider and narrower: the content never gets wider than 1000px and it is always in the middle.

Solució

centred.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>The box model</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="container">
        <header>
            <h1>My blog</h1>
            <nav>
                <a href="#">Home</a>
                <a href="#">Posts</a>
                <a href="#">About</a>
                <a href="#">Contact</a>
            </nav>
        </header>
        <main>
            <section>
                <h2>My first post</h2>
                <p>Today I started learning CSS and it is great.</p>
            </section>
            <section>
                <h2>The box model</h2>
                <p>Every element is a box with padding, border and margin.</p>
            </section>
        </main>
        <footer>
            <p>© 2026 My blog</p>
        </footer>
    </div>
</body>

</html>
css/style.css 
.container {
    max-width: 1000px;
    margin: 0 auto;
    padding: 0 20px;
}

nav a {
    display: inline-block;
    padding: 10px 18px;
    margin: 4px;
    background-color: #3d405b;
    color: white;
    text-decoration: none;
    border-radius: 8px;
}

nav a:hover {
    background-color: #e07a5f;
}

section {
    padding: 20px;
    margin-bottom: 30px;
    border-left: 5px solid #e07a5f;
}
