Exercici 9.1

Exercise 9.1. My favourite film. Create film.html and css/style.css, and link the CSS from the <head>.

HTML.

  • an <h1> with the title of the film;
  • three <p> that explain what the film is about;
  • an <h2> with the text “Main actors” and a <ul> with four <li>, one actor each.

CSS.

  • a comment at the top of the file with your name: /* Made by ... */;
  • body: background colour #f5f5f5 and text colour #333333;
  • h1: colour darkred;
  • h2: colour #4b3f8f;
  • li: colour #555555.

Check in the HTML that there is no style= attribute: all the design is in the CSS file.

Solució

film.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS basics</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <h1>Spirited Away</h1>
    <p>Chihiro is a ten-year-old girl who is moving to a new town with her parents.</p>
    <p>On the way they find an abandoned theme park, and her parents turn into pigs.</p>
    <p>Chihiro has to work in a bathhouse for spirits to save them and go back home.</p>
    <h2>Main actors</h2>
    <ul>
        <li>Rumi Hiiragi</li>
        <li>Miyu Irino</li>
        <li>Mari Natsuki</li>
        <li>Takashi Naito</li>
    </ul>
</body>

</html>
css/style.css 
/* Made by Vicent Forner */

body {
    background-color: #f5f5f5;
    color: #333333;
}

h1 {
    color: darkred;
}

h2 {
    color: #4b3f8f;
}

li {
    color: #555555;
}

Exercici 9.2

Exercise 9.2. A recipe with classes and an id. Create recipe.html, linked to the same css/style.css.

HTML.

  • an <h1> with id="recipe-title" and the name of the recipe;
  • an <h2> “Ingredients” followed by a <ul> with class="ingredients" and five <li>;
  • an <h2> “Steps” followed by an <ol> with class="steps" and four <li>;
  • one <p> with class="tip" with a cooking tip;
  • two <p> with class="warning" (for example: “Careful, the oven is hot!”).

CSS.

  • h1, h2 in one single rule (a group): font Arial, sans-serif;
  • #recipe-title: colour #e07a5f and size 40px;
  • .ingredients: colour #2e7d32;
  • .steps: colour #3d405b;
  • .tip: background colour #fff3b0;
  • .warning: colour #c0392b and bold text (font-weight: bold).

Solució

recipe.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS basics</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <h1 id="recipe-title">Potato omelette</h1>

    <h2>Ingredients</h2>
    <ul class="ingredients">
        <li>4 potatoes</li>
        <li>5 eggs</li>
        <li>1 onion</li>
        <li>Olive oil</li>
        <li>Salt</li>
    </ul>

    <h2>Steps</h2>
    <ol class="steps">
        <li>Peel and cut the potatoes and the onion.</li>
        <li>Fry them slowly in olive oil.</li>
        <li>Beat the eggs and mix everything.</li>
        <li>Cook the omelette on both sides.</li>
    </ol>

    <p class="tip">Tip: let the mix rest for five minutes before cooking it.</p>
    <p class="warning">Careful, the oil is very hot!</p>
    <p class="warning">Use a big plate to turn the omelette.</p>
</body>

</html>
css/style.css 
h1, h2 {
    font-family: Arial, sans-serif;
}

#recipe-title {
    color: #e07a5f;
    font-size: 40px;
}

.ingredients {
    color: #2e7d32;
}

.steps {
    color: #3d405b;
}

.tip {
    background-color: #fff3b0;
}

.warning {
    color: #c0392b;
    font-weight: bold;
}

Exercici 9.3

Exercise 9.3. A school page with descendants. Create school.html. In this exercise you cannot use classes or ids: only tag selectors and descendant selectors (with a space).

HTML.

  • a <header> with an <h1> (the name of your school) and a <p> (the town);
  • a <main> with two <article>; each article has an <h2> and two <p>;
  • a <footer> with a <p> and two <a> (to the website of the school and to your town hall).

CSS.

  • header p: colour #777777;
  • article p: line-height: 1.6;
  • article h2: colour #6d5fb3;
  • footer p: size 14px;
  • footer a: colour green.

Check that the paragraph of the header and the paragraphs of the articles look different, even if they are all <p>.

Solució

school.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS basics</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <header>
        <h1>IES Betxí</h1>
        <p>Betxí, Castelló</p>
    </header>
    <main>
        <article>
            <h2>Computer science</h2>
            <p>This year we are learning HTML and CSS.</p>
            <p>At the end of the term we will build our own website.</p>
        </article>
        <article>
            <h2>Sports day</h2>
            <p>Next Friday there is a sports day for all the school.</p>
            <p>Bring water and comfortable clothes.</p>
        </article>
    </main>
    <footer>
        <p>Contact us:</p>
        <a href="https://portal.edu.gva.es/iesbetxi/">School website</a>
        <a href="https://www.betxi.es/">Betxí town hall</a>
    </footer>
</body>

</html>
css/style.css 
header p {
    color: #777777;
}

article p {
    line-height: 1.6;
}

article h2 {
    color: #6d5fb3;
}

footer p {
    font-size: 14px;
}

footer a {
    color: green;
}

Exercici 9.4

Exercise 9.4. A menu with hover and featured cards. Create cards.html.

HTML.

  • a <nav> with four <a> (Home, News, Games, Contact); the first one has class="active";
  • three <div> with class="card", each one with an <h3> and a <p>;
  • the second card has two classes: class="card featured".

CSS.

  • nav a: colour #6d5fb3, no underline (text-decoration: none) and bold;
  • nav a:hover: colour #e07a5f;
  • nav a.active: colour black;
  • .card: background colour white, padding: 20px and margin-bottom: 20px;
  • .card.featured: border-left: 6px solid #ffd166;
  • .card:hover: background colour #f4f1fb;
  • body: background colour #eeeeee.

Solució

cards.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS basics</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <nav>
        <a href="#" class="active">Home</a>
        <a href="#">News</a>
        <a href="#">Games</a>
        <a href="#">Contact</a>
    </nav>

    <div class="card">
        <h3>New computers</h3>
        <p>The computer room has 30 new computers.</p>
    </div>
    <div class="card featured">
        <h3>Coding club</h3>
        <p>Every Tuesday at break time.</p>
    </div>
    <div class="card">
        <h3>Game jam</h3>
        <p>Make a game in one weekend.</p>
    </div>
</body>

</html>
css/style.css 
body {
    background-color: #eeeeee;
}

nav a {
    color: #6d5fb3;
    text-decoration: none;
    font-weight: bold;
}

nav a:hover {
    color: #e07a5f;
}

nav a.active {
    color: black;
}

.card {
    background-color: white;
    padding: 20px;
    margin-bottom: 20px;
}

.card.featured {
    border-left: 6px solid #ffd166;
}

.card:hover {
    background-color: #f4f1fb;
}

Exercici 9.5

Exercise 9.5. Colours and the cascade. Create colours.html.

HTML.

  • four <p> with the classes name, hex, rgb and rgba, with the texts “Red as a name”, “Red in hexadecimal”, “Red in rgb” and “Red half transparent”;
  • two more <p> without class, and a third one with class="note".

CSS.

  • .name: colour red; .hex: colour #ff0000; .rgb: colour rgb(255, 0, 0); .rgba: colour rgba(255, 0, 0, 0.5);
  • then, in this order: .note in purple, p in blue and p in green.

Before you reload, write in an HTML comment (<!-- -->) which colour you think each paragraph will have, and why. Then check it in the browser and in DevTools (the rules that lose appear crossed out).

Solució

colours.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS basics</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <p class="name">Red as a name</p>
    <p class="hex">Red in hexadecimal</p>
    <p class="rgb">Red in rgb</p>
    <p class="rgba">Red half transparent</p>

    <!-- Prediction:
         - the two paragraphs without class: green (two rules "p", the last one wins)
         - the paragraph with class="note": purple (a class beats a tag,
           even if .note is written before the p rules) -->
    <p>Paragraph without class</p>
    <p>Another paragraph without class</p>
    <p class="note">Paragraph with class="note"</p>
</body>

</html>
css/style.css 
.name {
    color: red;
}

.hex {
    color: #ff0000;
}

.rgb {
    color: rgb(255, 0, 0);
}

.rgba {
    color: rgba(255, 0, 0, 0.5);
}

.note {
    color: purple;
}

p {
    color: blue;
}

p {
    color: green;
}

Compte: les quatre primeres també són p, però tenen classe, així que es queden roges (la classe guanya a les dues regles p).
