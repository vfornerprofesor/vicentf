Exercici 9.1

Exercise 9.1. Create css/style.css, link it from your page, and make all the paragraphs dark grey.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My page</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <h1 id="title">Marc Ferrer</h1>
    <nav>
        <a href="index.html">Home</a>
        <a href="music.html">Music</a>
        <a href="films.html">Films</a>
    </nav>
    <h2>About me</h2>
    <p>I like rock music, above all bands with two guitars.</p>
    <p>My favourite film is Interstellar.</p>
    <p>I have seen it four times.</p>
    <p>I study at a school in Valencia.</p>
</body>

</html>
css/style.css 
p {
    color: #333333;
}
El fitxer es guarda com css/style.css i s'enllaça des del head amb <link rel="stylesheet" href="css/style.css">.

Resultat

Exercici 9.4

Exercise 9.4. Write a rule that only affects the links that are inside the nav.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My page</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <h1 id="title">Marc Ferrer</h1>
    <nav>
        <a href="index.html">Home</a>
        <a href="music.html">Music</a>
        <a href="films.html">Films</a>
    </nav>
    <h2>About me</h2>
    <p>I like rock music, above all bands with two guitars.</p>
    <p class="highlight">My favourite film is Interstellar.</p>
    <p class="highlight">I have seen it four times.</p>
    <p>I study at a school in Valencia.</p>
</body>

</html>
css/style.css 
nav {
    background-color: #222222;
    padding: 10px;
}

nav a {
    color: white;
    text-decoration: none;
}
El selector descendent nav a només afecta els enllaços que estan dins de nav. (El fons fosc i el padding no formen part de l'exercici: només es veu bé l'enllaç blanc.)
