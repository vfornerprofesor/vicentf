Exercici 2.1

Exercise 2.1. Find the three errors in this code and write the correct version.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <title>My page</title>
</head>

<body>
    <h1>Welcome</h1>
    <p>Hello there.</p>
</body>

</html>
Resposta: els tres errors són: <title> sense tancar, <h1> tancat amb <h1> en lloc de </h1>, i el <p> sense tancar.

Resultat
