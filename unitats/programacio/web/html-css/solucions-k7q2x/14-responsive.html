Exercici 14.1

Exercise 14.1. A page that fits on a phone. Create phone.html. Put the viewport tag in the <head>: <meta name="viewport" content="width=device-width, initial-scale=1.0">.

HTML.

  • an <h1>;
  • an <img> with class="hero-img" and a big photo (more than 1500px wide);
  • two <p> with text.

CSS.

  • img: max-width: 100% and height: auto;
  • body: padding: 10px and margin: 0;
  • .hero-img: border-radius: 10px.

Open DevTools, choose a phone in device mode and check that you never have to scroll to the side. Then remove the img rule and see what happens.

Solució

phone.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Responsive design</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <h1>My trip to the mountains</h1>
    <img class="hero-img" src="images/mountains.jpg" alt="Mountains at sunset">
    <p>Last summer we went to the Pyrenees for a week.</p>
    <p>The photo above is 2000px wide, but it never gets wider than the screen.</p>
</body>

</html>
css/style.css 
img {
    max-width: 100%;
    height: auto;
}

body {
    padding: 10px;
    margin: 0;
}

.hero-img {
    border-radius: 10px;
}

Sense la regla img, la foto fa 2000px i apareix la barra de desplaçament horitzontal.

Exercici 14.2

Exercise 14.2. Cards: one, two, three columns. Create responsive-cards.html. Work mobile first: first the rules for the phone, then the media queries with min-width.

HTML.

  • a <section> with class="cards";
  • inside, six <article> with class="card", each one with an <h3> and a <p>.

CSS.

  • .cards: display: grid, grid-template-columns: 1fr and gap: 20px;
  • .card: padding: 20px, background colour white and border-radius: 10px;
  • @media (min-width: 600px): .cards with grid-template-columns: repeat(2, 1fr);
  • @media (min-width: 900px): .cards with grid-template-columns: repeat(3, 1fr).

Solució

responsive-cards.html

<html lang="en">

<head>

    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <section class="cards">
        <article class="card">
            <h3>Card 1</h3>
            <p>A short text about this card.</p>
        </article>
        <article class="card">
            <h3>Card 2</h3>
            <p>A short text about this card.</p>
        </article>
        <article class="card">
            <h3>Card 3</h3>
            <p>A short text about this card.</p>
        </article>
        <article class="card">
            <h3>Card 4</h3>
            <p>A short text about this card.</p>
        </article>
        <article class="card">
            <h3>Card 5</h3>
            <p>A short text about this card.</p>
        </article>
        <article class="card">
            <h3>Card 6</h3>
            <p>A short text about this card.</p>
        </article>
    </section>
</body>

</html>
css/style.css 
.cards {
    display: grid;
    grid-template-columns: 1fr;
    gap: 20px;
}

.card {
    padding: 20px;
    background-color: white;
    border-radius: 10px;
}

@media (min-width: 600px) {
    .cards {
        grid-template-columns: repeat(2, 1fr);
    }
}

@media (min-width: 900px) {
    .cards {
        grid-template-columns: repeat(3, 1fr);
    }
}

Les targetes són blanques: per a veure-les bé, posa un fons gris a body o redimensiona la previsualització (es pot estirar per la cantonada).

Exercici 14.3

Exercise 14.3. A nav bar that turns into a column. Copy the nav bar of exercise 12.3 into responsive-nav.html, with the same HTML and CSS.

HTML.

  • the same <header> with class="site-header", the <div> with class="logo" and the <ul> with class="menu" of exercise 12.3.

CSS.

  • at the end of the file, @media (max-width: 600px):
  • inside it, .site-header: flex-direction: column, gap: 12px and centred text;
  • inside it, .menu: flex-direction: column and gap: 8px.

Solució

responsive-nav.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Responsive design</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <header class="site-header">
        <div class="logo">Marc Ferrer</div>
        <nav>
            <ul class="menu">
                <li><a href="#">Home</a></li>
                <li><a href="#">Projects</a></li>
                <li><a href="#">About</a></li>
                <li><a href="#">Contact</a></li>
            </ul>
        </nav>
    </header>
</body>

</html>
css/style.css 
.site-header {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 15px 30px;
    background-color: #2b2b40;
}

.logo {
    color: white;
    font-weight: bold;
    font-size: 1.5rem;
}

.menu {
    display: flex;
    gap: 20px;
    list-style: none;
    margin: 0;
    padding: 0;
}

.menu a {
    color: white;
    text-decoration: none;
}

.menu a:hover {
    color: #ffd166;
}

@media (max-width: 600px) {
    .site-header {
        flex-direction: column;
        gap: 12px;
        text-align: center;
    }

    .menu {
        flex-direction: column;
        gap: 8px;
    }
}

Exercici 14.4

Exercise 14.4. A sidebar only for big screens. Create sidebar.html, mobile first.

HTML.

  • an <h1>;
  • a <div> with class="layout", with a <main> (two <p>) and an <aside> (an <h3> and a <ul> of links).

CSS.

  • h1: size 1.8rem;
  • aside: display: none (on a phone it is hidden);
  • @media (min-width: 768px): h1 with size 3rem; .layout with display: grid, grid-template-columns: 2fr 1fr and gap: 20px; aside with display: block.

Add a <p> at the end of the page with your opinion, in two lines: is it a good idea to hide content on mobile?

Solució

sidebar.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Responsive design</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <h1>Healthy recipes</h1>
    <div class="layout">
        <main>
            <p>Eating well does not have to be difficult or expensive.</p>
            <p>Here you will find quick recipes with fresh ingredients.</p>
        </main>
        <aside>
            <h3>Categories</h3>
            <ul>
                <li><a href="#">Breakfast</a></li>
                <li><a href="#">Lunch</a></li>
                <li><a href="#">Dinner</a></li>
            </ul>
        </aside>
    </div>
    <p>In my opinion it is not a good idea to hide important content on mobile, because many people only use the phone. It is fine to hide decorative things or move them to the end of the page.</p>
</body>

</html>
css/style.css 
h1 {
    font-size: 1.8rem;
}

aside {
    display: none;
}

@media (min-width: 768px) {
    h1 {
        font-size: 3rem;
    }

    .layout {
        display: grid;
        grid-template-columns: 2fr 1fr;
        gap: 20px;
    }

    aside {
        display: block;
    }
}

Exercici 14.5

Exercise 14.5. Responsive band page. Take the band page of exercise 12.7 and make it work on a phone.

HTML.

  • the same HTML of exercise 12.7, with the viewport tag in the <head>.

CSS.

  • img, iframe: max-width: 100%;
  • .gallery: change it to display: grid, grid-template-columns: 1fr and gap: 20px (one column on a phone);
  • @media (min-width: 600px): .gallery with grid-template-columns: repeat(2, 1fr);
  • @media (min-width: 900px): .gallery with grid-template-columns: repeat(3, 1fr);
  • .songs: flex-direction: column on a phone, and flex-direction: row from 900px;
  • .main-photo: width 100% on a phone and 50% from 900px.
