Exercici 14.1

Exercise 14.1. Add the viewport tag and img { max-width: 100%; } to all your pages. Compare the result on a narrow window before and after.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Cards</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="cards">
        <div class="card">Card 1</div>
        <div class="card">Card 2</div>
        <div class="card">Card 3</div>
        <div class="card">Card 4</div>
        <div class="card">Card 5</div>
        <div class="card">Card 6</div>
    </div>
</body>

</html>
css/style.css 
img {
    max-width: 100%;
}
Resposta: sense el viewport el mòbil dibuixa la pàgina com si la pantalla fóra de ~980 px i la redueix (tot es veu xicotet); sense max-width: 100% les imatges grans surten de la pantalla i apareix scroll horitzontal. Amb les dues coses la pàgina s'adapta a l'ample.
En cada pàgina cal posar <meta name="viewport" content="width=device-width, initial-scale=1.0"> en el head i la regla img { max-width: 100%; } en el CSS.

Exercici 14.2

Exercise 14.2. Make your row of cards show 3 per line on a desktop, 2 on a tablet and 1 on a phone. Use mobile first.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Cards</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="cards">
        <div class="card">Card 1</div>
        <div class="card">Card 2</div>
        <div class="card">Card 3</div>
        <div class="card">Card 4</div>
        <div class="card">Card 5</div>
        <div class="card">Card 6</div>
    </div>
</body>

</html>
css/style.css 
* {
    box-sizing: border-box;
}

/* Mobile first: 1 per línia */
.cards {
    display: grid;
    grid-template-columns: 1fr;
    gap: 16px;
    padding: 16px;
}

.card {
    padding: 40px 16px;
    background-color: #2d5a85;
    color: white;
    text-align: center;
    border-radius: 8px;
}

/* Tablet: 2 per línia */
@media (min-width: 600px) {
    .cards {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* Escriptori: 3 per línia */
@media (min-width: 900px) {
    .cards {
        grid-template-columns: repeat(3, 1fr);
    }
}
Mobile first: l'estil base és el del mòbil (1 columna) i els @media (min-width) van afegint columnes quan la pantalla creix.

Exercici 14.3

Exercise 14.3. Make your nav bar become a vertical column below 600px.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Nav</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <header class="site-header">
        <a class="logo" href="index.html">Marc.dev</a>
        <nav class="menu">
            <a href="index.html">Home</a>
            <a href="music.html">Music</a>
            <a href="films.html">Films</a>
        </nav>
    </header>
</body>

</html>
css/style.css 
* {
    box-sizing: border-box;
}

body {
    margin: 0;
    font-family: Arial, Helvetica, sans-serif;
}

.site-header {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 12px 24px;
    background-color: #1f3c5a;
}

.logo {
    color: #f2a541;
    font-weight: bold;
    text-decoration: none;
}

.menu {
    display: flex;
    gap: 8px;
}

.menu a {
    padding: 8px 14px;
    color: white;
    text-decoration: none;
}

@media (max-width: 600px) {
    .site-header {
        flex-direction: column;
        gap: 12px;
        text-align: center;
    }

    .menu {
        flex-direction: column;
        gap: 8px;
    }
}

Exercici 14.4

Exercise 14.4. Hide the sidebar (aside) on screens under 768px using display: none. Then think: is it a good idea to hide content on mobile? Write two lines with your opinion.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Sidebar</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <div class="layout">
        <main>
            <h1>Content</h1>
            <p>The content is always visible.</p>
        </main>
        <aside>
            <h2>Sidebar</h2>
            <p>Related links.</p>
        </aside>
    </div>
</body>

</html>
css/style.css 
.layout {
    display: grid;
    grid-template-columns: 1fr 280px;
    gap: 20px;
}

aside {
    padding: 16px;
    background-color: #eeeeee;
}

@media (max-width: 767px) {
    .layout {
        grid-template-columns: 1fr;
    }

    aside {
        display: none;
    }
}
Resposta: opinió (exemple): no és bona idea amagar contingut important en el mòbil, perquè una persona que entra des del telèfon també el necessita. Millor reordenar-lo o col·locar-lo davall del contingut principal; amagar només el que és decoratiu o repetit.

Resultat

Exercici 14.4

Exercise 14.4. Take the band page of exercise 12.6 and make it work on a phone: one column under 600 px, two between 600 and 900, three above.

Solució

index.html 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Buhos</title>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>
    <h1>Buhos</h1>
    <h2>Gallery</h2>
    <div id="galeria">
        <img src="images/buhos1.png" alt="Photo 1 of the band" class="img_galeria">
        <img src="images/buhos2.png" alt="Photo 2 of the band" class="img_galeria">
        <img src="images/buhos3.png" alt="Photo 3 of the band" class="img_galeria">
        <img src="images/buhos4.png" alt="Photo 4 of the band" class="img_galeria">
        <img src="images/buhos5.png" alt="Photo 5 of the band" class="img_galeria">
        <img src="images/buhos6.png" alt="Photo 6 of the band" class="img_galeria">
        <img src="images/buhos7.png" alt="Photo 7 of the band" class="img_galeria">
    </div>
</body>

</html>
css/style.css 
* {
    box-sizing: border-box;
}

body {
    margin: 0;
    padding: 16px;
    background-color: #2a2a2a;
    color: white;
    font-family: sans-serif;
}

h1,
h2 {
    text-align: center;
}

/* Mobile first: una columna */
#galeria {
    display: grid;
    grid-template-columns: 1fr;
    gap: 16px;
}

.img_galeria {
    width: 100%;
    height: auto;
}

/* Entre 600 i 899 px: dues columnes */
@media (min-width: 600px) {
    #galeria {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* A partir de 900 px: tres columnes */
@media (min-width: 900px) {
    #galeria {
        grid-template-columns: repeat(3, 1fr);
    }
}
Només es mostra la galeria; la resta de la pàgina de l'exercici 12.6 (menú, vídeos i lletres) segueix el mateix patró. Si hi ha més blocs en columnes (per exemple #millors_cancons), s'usa la mateixa tècnica: 1 columna per defecte i repeat(2, 1fr) a partir de 900 px.
