The box model
Everything is a box In CSS, every element is a rectangle. Even a word inside a sentence. Every box has four layers, from the inside out:
  • *content* — the text or the image;
  • *padding* — space ~inside~ the box, between the content and the border;
  • *border* — the line around the box;
  • *margin* — space ~outside~ the box, between this box and its neighbours.
    •  Open DevTools, select any element and scroll down in the Styles panel. You will see this same diagram with the real numbers of that element. It is the fastest way to understand why a box is where it is.     Padding, border, margin .card { padding: 20px; /* the same on the four sides */ padding: 10px 20px; /* top-bottom left-right */ padding: 10px 20px 30px 40px; /* top right bottom left (clockwise) */ border: 2px solid #333333; /* width style colour */ border-bottom: 4px solid red; /* only one side */ margin: 20px; margin-bottom: 40px; } <style> .card { padding: 10px 20px 30px 40px; border: 2px solid #333333; border-bottom: 4px solid red; margin: 20px; margin-bottom: 40px; background: #f5f5f5; } </style> <div class="card">Card with asymmetric padding, a dark border and a thicker red bottom.</div> <div class="card">Second card, so the margins between them are visible.</div> Border styles: solid, dashed, dotted, none. Width and height .box { width: 300px; height: 200px; max-width: 100%; /* never wider than its container */ } <style> .box { width: 300px; height: 200px; max-width: 100%; background: #c4baeb; } </style> <div class="box">300 x 200</div> max-width: 100% is a small rule that saves you a lot of problems on phones. Use it on images too: img { max-width: 100%; height: auto; } box-sizing: the fix By default, width: 300px is the width of the *content only*. If you add 20px of padding and a 2px border on each side, the box really takes 300 + 40 + 4 = 344px. That is confusing. Put this at the top of every CSS file you write, forever: * { box-sizing: border-box; } Same width, padding and border, only the box-sizing changes: <style> .compare { display: flex; gap: 20px; flex-wrap: wrap; } .compare div { width: 200px; padding: 20px; border: 4px solid #333333; background: #f5f5f5; } .border-box { box-sizing: border-box; } </style> <div class="compare"> <div>Default (content-box): this box ends up WIDER than 200px, because the padding and the border are added on top.</div> <div class="border-box">box-sizing: border-box: this box really is 200px wide in total, padding and border included.</div> </div> * means "all the elements". With border-box, width: 300px means the box is really 300px, padding and border included. Much easier. Block and inline .menu-item { display: block; /* takes the full line */ display: inline; /* stays inside the text line */ display: inline-block; /* stays in the line, but accepts width and height */ display: none; /* disappears completely */ } <div>, <p>, <h1> are block by default. <span>, <a>, <strong> are inline. An inline element *ignores* width, height and vertical margins. If you need them, use inline-block. Rounded corners and shadows .card { border-radius: 12px; /* rounded corners */ box-shadow: 0 2px 8px rgba(0, 0, 0, 0.15); /* x y blur colour */ } .avatar { border-radius: 50%; /* a perfect circle, if the box is square */ } <style> .card { border-radius: 12px; box-shadow: 0 2px 8px rgba(0, 0, 0, 0.15); padding: 16px; background: white; width: fit-content; } .avatar { border-radius: 50%; width: 60px; height: 60px; background: #9b87d6; } </style> <div class="card">A card with rounded corners and a soft shadow</div> <div class="avatar"></div> Centring a box .container { width: 90%; max-width: 1000px; margin: 0 auto; /* 0 top and bottom, auto left and right = centred */ } <style> .container { width: 90%; max-width: 220px; margin: 0 auto; background: #c4baeb; padding: 10px; text-align: center; } </style> <div class="container">Centred box</div> margin: 0 auto is the classic way to centre a block box.
