CSS basics
What is CSS? HTML says ~what~ things are. *CSS* says ~how they look~. CSS means ~Cascading Style Sheets~. With CSS you choose colours, fonts, sizes, borders, and where each box goes on the screen. The same HTML page can look completely different with a different CSS file. The content does not change; only the clothes do. Three ways to add CSS *1. Inline* (inside the tag). Quick, but terrible: you have to repeat it for every element. <p style="color: red;">This text is red.</p> <p style="color: red;">This text is red.</p> *2. Internal* (a <style> block in the <head>). Fine for a test page. <head> <style> p { color: red; } </style> </head> *3. External* (a separate .css file). ~This is the one we use.~ One file styles all the pages of your site, so you change a colour once and the whole site changes. <head> <link rel="stylesheet" href="css/style.css"> </head> Create a folder css inside your project and put style.css there. From now on, every page of every exercise starts with that link in the head. The syntax of a rule h1 { color: darkblue; font-size: 40px; } <style> h1 { color: darkblue; font-size: 40px; } </style> <h1>My website</h1>
  • h1 is the *selector*: which elements this rule affects.
  • Inside { } go the *declarations*.
  • Each declaration is a *property* (color), a colon, a *value* (darkblue), and a semicolon.
    •  The semicolon at the end of each line is easy to forget, and when you forget it the rest of the rule stops working. Comments in CSS are different from HTML: /* This is a CSS comment */     Selectors /* All the paragraphs */ p { color: #333333; } /* All the elements with class="warning" */ .warning { color: red; } /* The single element with id="main-title" */ #main-title { font-size: 48px; } /* Two selectors at once */ h1, h2 { font-family: Arial, sans-serif; } /* Only the paragraphs that are inside an article */ article p { line-height: 1.6; } In the HTML: <h1 id="main-title">My site</h1> <p class="warning">Careful with this!</p> <article> <p>This paragraph gets the line-height.</p> </article> Both files together, in the browser: <style> p { color: #333333; } .warning { color: red; } #main-title { font-size: 48px; } h1, h2 { font-family: Arial, sans-serif; } article p { line-height: 1.6; } </style> <h1 id="main-title">My site</h1> <p class="warning">Careful with this!</p> <article> <p>This paragraph gets the line-height. It has extra space between its lines so it is easier to read.</p> </article>

Colours Four ways to write the same colour: p { color: red; /* a name (there are about 140) */ color: #ff0000; /* hexadecimal: red, green, blue */ color: rgb(255, 0, 0); /* the same, in numbers 0-255 */ color: rgba(255, 0, 0, 0.5); /* the same, half transparent */ } Hexadecimal is the most common. It is #RRGGBB: two characters for red, two for green, two for blue, from 00 to ff. #000000 is black, #ffffff is white. You do not have to guess: VS Code shows a colour picker when you click on a colour, and DevTools has one too. Check your contrast. Light grey text on a white background is impossible to read for many people. Use the contrast checker in DevTools: it tells you if your text and background are different enough. When two rules fight If two rules say something different about the same element, the browser decides like this:
  • The *more specific* selector wins: #id beats .class, and .class beats p.
  • If both are equally specific, the *last one in the file* wins.
    •  p { color: blue; } p { color: green; } /* this one wins: it comes later */ .note { color: red; } /* this beats both: a class is more specific */ <style> p { color: blue; } p { color: green; } .note { color: red; } </style> <p>A plain paragraph: green wins, it is the last rule.</p> <p class="note">A paragraph with class="note": red wins, a class beats a tag.</p>     All the selectors on a real page Download [The Pixel Times|download](unitats/programacio/web/html-css/exercises/09-css-basics/selectors.html): a school magazine with a header, a menu, cards, lists, a table, a form and a footer, and no CSS at all. Create css/style.css next to it (the HTML already links it) and add the rules below *one by one*. Save and reload after each one to see what changes. Some rules use properties from the next units (padding, border-radius, border...). Copy them as they are: they are there so the page looks nice. Today we look at the *selectors*. Tags, groups and id *1.* *Universal selector* *: it selects every element of the page. * { font-family: Arial, Helvetica, sans-serif; } *2.* *Tag selectors*: all the elements of that tag. body { background-color: #f4f1fb; color: #333333; margin: 0; } p { line-height: 1.6; } *3.* *Group* several selectors with commas: one rule for four tags. h1, h2, h3, h4 { color: #4b3f8f; } *4.* *id selector* #: only one element in the page has this id. #main-title { color: white; font-size: 48px; margin: 0; } Descendants and classes *5.* *Descendant selector* (a space): header p means the paragraphs that are inside the header. The other paragraphs do not change. header { background-color: #6d5fb3; padding: 30px; text-align: center; } header p { color: #e4defa; } *6.* The *same tag in different places*: the links of the menu and the links of the footer look different. nav a { color: white; text-decoration: none; font-weight: bold; margin: 0 12px; } footer a { color: #ffd166; } *7.* *Class selectors* .: all the elements with that class. Look at .date: it is also a p, but the class wins because it is more specific. .card { background-color: white; padding: 20px; margin-bottom: 20px; border-radius: 10px; } .date { color: #888888; font-size: 14px; } .warning { color: #c0392b; font-weight: bold; } .note { background-color: #fff6d6; padding: 8px; } *8.* *Two classes together*, with no space: only the elements that have both classes (class="card featured"). With a space, .card .featured, it would look for a .featured inside a .card, and there is none. .card.featured { border-left: 6px solid #ffd166; } *9.* *Class + descendant*: only the h3 inside the review cards. .review h3 { color: #e07a5f; } *10.* Two lists with the *same tags but different classes*. .pros li { color: #2e7d32; } .cons li { color: #c0392b; } .score { font-size: 22px; font-weight: bold; text-align: right; } Family: children and siblings *11.* *Child selector* >: only the direct children. main > section selects the sections that are right inside main, not deeper. main > section { max-width: 800px; margin: 0 auto; padding: 20px; } *12.* *Adjacent sibling* +: the element that comes *right after* another one, at the same level. Here, the first paragraph after each date. .date + p { font-size: 18px; } *13.* *General sibling* ~: *all* the elements after another one, at the same level. Here, every paragraph after the warning. .warning ~ p { font-style: italic; } blockquote { font-style: italic; color: #6d5fb3; border-left: 4px solid #6d5fb3; padding-left: 12px; } Pseudo-classes: state and position *14.* :hover: when the mouse is over the element. Move the mouse over the menu, the cards and the button. nav a:hover { color: #ffd166; } .card:hover { background-color: #fbfaff; } button:hover { background-color: #4b3f8f; } *15.* :first-child, :last-child and :nth-child(): the position among its siblings. even means 2, 4, 6...; odd means 1, 3, 5... .steps li:first-child { font-weight: bold; } .steps li:last-child { color: #6d5fb3; } table { width: 100%; border-collapse: collapse; background-color: white; } th { background-color: #6d5fb3; color: white; } th, td { padding: 10px; text-align: left; } tbody tr:nth-child(even) { background-color: #f4f1fb; } tbody tr:first-child { font-weight: bold; color: #b8860b; } Attributes *16.* *Attribute selectors* [ ]: elements with an attribute or a value. [href^="https"] means the href *starts with* https: only the external links of the footer change, not Back to top. input[type="text"], input[type="email"], textarea { display: block; width: 100%; box-sizing: border-box; padding: 8px; margin: 4px 0 14px; border: 1px solid #c9c1ec; border-radius: 6px; } a[href^="https"] { font-style: italic; } label { font-weight: bold; } button { background-color: #6d5fb3; color: white; border: none; padding: 10px 20px; border-radius: 6px; cursor: pointer; } *17.* :focus: the field where you are writing right now. Click on a field of the form. input:focus, textarea:focus { border-color: #6d5fb3; background-color: #fbfaff; } :not() and pseudo-elements *18.* :not(): everything *except* what is inside the brackets. All the cards except the featured one. .card:not(.featured) { border-left: 6px solid #c9c1ec; } *19.* *Pseudo-element* ::first-letter (two colons): a part of the element, here only its first letter. Like in old books. .featured .date + p::first-letter { font-size: 32px; color: #6d5fb3; } footer { background-color: #333333; color: white; text-align: center; padding: 20px; } The cascade, live *20.* Write the same rule twice with different colours. Same specificity: the *last one wins*. Then give a class to one of the footer paragraphs and style the class *before* these rules: it still wins, because a class beats a tag. footer p { color: yellow; } footer p { color: #cccccc; /* this one wins: it comes later */ } Open DevTools (F12), click on any element and look at the *Styles* panel: you see every rule that applies to it, and the ones that lose appear crossed out.
