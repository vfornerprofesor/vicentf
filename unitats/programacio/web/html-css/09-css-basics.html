CSS basics
What is CSS? HTML says ~what~ things are. *CSS* says ~how they look~. CSS means ~Cascading Style Sheets~. With CSS you choose colours, fonts, sizes, borders, and where each box goes on the screen. The same HTML page can look completely different with a different CSS file. The content does not change; only the clothes do. Three ways to add CSS *1. Inline* (inside the tag). Quick, but terrible: you have to repeat it for every element. <p style="color: red;">This text is red.</p> <p style="color: red;">This text is red.</p> *2. Internal* (a <style> block in the <head>). Fine for a test page. <head> <style> p { color: red; } </style> </head> *3. External* (a separate .css file). ~This is the one we use.~ One file styles all the pages of your site, so you change a colour once and the whole site changes. <head> <link rel="stylesheet" href="css/style.css"> </head> Create a folder css inside your project and put style.css there. From now on, every page of every exercise starts with that link in the head. The syntax of a rule h1 { color: darkblue; font-size: 40px; } <style> h1 { color: darkblue; font-size: 40px; } </style> <h1>My website</h1>
  • h1 is the *selector*: which elements this rule affects.
  • Inside { } go the *declarations*.
  • Each declaration is a *property* (color), a colon, a *value* (darkblue), and a semicolon.
    •  The semicolon at the end of each line is easy to forget, and when you forget it the rest of the rule stops working. Comments in CSS are different from HTML: /* This is a CSS comment */     Selectors /* All the paragraphs */ p { color: #333333; } /* All the elements with class="warning" */ .warning { color: red; } /* The single element with id="main-title" */ #main-title { font-size: 48px; } /* Two selectors at once */ h1, h2 { font-family: Arial, sans-serif; } /* Only the paragraphs that are inside an article */ article p { line-height: 1.6; } In the HTML: <h1 id="main-title">My site</h1> <p class="warning">Careful with this!</p> <article> <p>This paragraph gets the line-height.</p> </article> Both files together, in the browser: <style> p { color: #333333; } .warning { color: red; } #main-title { font-size: 48px; } h1, h2 { font-family: Arial, sans-serif; } article p { line-height: 1.6; } </style> <h1 id="main-title">My site</h1> <p class="warning">Careful with this!</p> <article> <p>This paragraph gets the line-height. It has extra space between its lines so it is easier to read.</p> </article>

Colours Four ways to write the same colour: p { color: red; /* a name (there are about 140) */ color: #ff0000; /* hexadecimal: red, green, blue */ color: rgb(255, 0, 0); /* the same, in numbers 0-255 */ color: rgba(255, 0, 0, 0.5); /* the same, half transparent */ } Hexadecimal is the most common. It is #RRGGBB: two characters for red, two for green, two for blue, from 00 to ff. #000000 is black, #ffffff is white. You do not have to guess: VS Code shows a colour picker when you click on a colour, and DevTools has one too. Check your contrast. Light grey text on a white background is impossible to read for many people. Use the contrast checker in DevTools: it tells you if your text and background are different enough. When two rules fight If two rules say something different about the same element, the browser decides like this:
  • The *more specific* selector wins: #id beats .class, and .class beats p.
  • If both are equally specific, the *last one in the file* wins.
    •  p { color: blue; } p { color: green; } /* this one wins: it comes later */ .note { color: red; } /* this beats both: a class is more specific */ <style> p { color: blue; } p { color: green; } .note { color: red; } </style> <p>A plain paragraph: green wins, it is the last rule.</p> <p class="note">A paragraph with class="note": red wins, a class beats a tag.</p>     Exercises *Exercise 9.1.* Create css/style.css, link it from your page, and make all the paragraphs dark grey. *Exercise 9.2.* Give the class highlight to two paragraphs, and make that class yellow background and bold text. *Exercise 9.3.* Give an id to your main title and make it a different colour from the other headings. *Exercise 9.4.* Write a rule that only affects the links that are inside the nav. nav a { color: white; text-decoration: none; } <style> nav { background-color: #333333; padding: 12px; } nav a { color: white; text-decoration: none; margin-right: 16px; } </style> <nav> <a href="#">Home</a> <a href="#">About</a> <a href="#">Contact</a> </nav> (The preview also gives the nav a dark background and some padding, just so the white links are visible — that part is not in the exercise.) ← Previous: Semantic HTML Unit index Next: Text, fonts and colours →
