CSS basics
What is CSS? HTML says ~what~ things are. *CSS* says ~how they look~. CSS means ~Cascading Style Sheets~. With CSS you choose colours, fonts, sizes, borders, and where each box goes on the screen. The same HTML page can look completely different with a different CSS file. The content does not change; only the clothes do. Three ways to add CSS *1. Inline* (inside the tag). Quick, but terrible: you have to repeat it for every element. <p style="color: red;">This text is red.</p> <p style="color: red;">This text is red.</p> *2. Internal* (a <style> block in the <head>). Fine for a test page. <head> <style> p { color: red; } </style> </head> *3. External* (a separate .css file). ~This is the one we use.~ One file styles all the pages of your site, so you change a colour once and the whole site changes. <head> <link rel="stylesheet" href="css/style.css"> </head> Create a folder css inside your project and put style.css there. From now on, every page of every exercise starts with that link in the head. The syntax of a rule h1 { color: darkblue; font-size: 40px; } <style> h1 { color: darkblue; font-size: 40px; } </style> <h1>My website</h1>
  • h1 is the *selector*: which elements this rule affects.
  • Inside { } go the *declarations*.
  • Each declaration is a *property* (color), a colon, a *value* (darkblue), and a semicolon.
    •  The semicolon at the end of each line is easy to forget, and when you forget it the rest of the rule stops working. Comments in CSS are different from HTML: /* This is a CSS comment */     Selectors /* All the paragraphs */ p { color: #333333; } /* All the elements with class="warning" */ .warning { color: red; } /* The single element with id="main-title" */ #main-title { font-size: 48px; } /* Two selectors at once */ h1, h2 { font-family: Arial, sans-serif; } /* Only the paragraphs that are inside an article */ article p { line-height: 1.6; } In the HTML: <h1 id="main-title">My site</h1> <p class="warning">Careful with this!</p> <article> <p>This paragraph gets the line-height.</p> </article> Both files together, in the browser: <style> p { color: #333333; } .warning { color: red; } #main-title { font-size: 48px; } h1, h2 { font-family: Arial, sans-serif; } article p { line-height: 1.6; } </style> <h1 id="main-title">My site</h1> <p class="warning">Careful with this!</p> <article> <p>This paragraph gets the line-height. It has extra space between its lines so it is easier to read.</p> </article>

Colours Four ways to write the same colour: p { color: red; /* a name (there are about 140) */ color: #ff0000; /* hexadecimal: red, green, blue */ color: rgb(255, 0, 0); /* the same, in numbers 0-255 */ color: rgba(255, 0, 0, 0.5); /* the same, half transparent */ } Hexadecimal is the most common. It is #RRGGBB: two characters for red, two for green, two for blue, from 00 to ff. #000000 is black, #ffffff is white. You do not have to guess: VS Code shows a colour picker when you click on a colour, and DevTools has one too. Check your contrast. Light grey text on a white background is impossible to read for many people. Use the contrast checker in DevTools: it tells you if your text and background are different enough. When two rules fight If two rules say something different about the same element, the browser decides like this:
  • The *more specific* selector wins: #id beats .class, and .class beats p.
  • If both are equally specific, the *last one in the file* wins.
    •  p { color: blue; } p { color: green; } /* this one wins: it comes later */ .note { color: red; } /* this beats both: a class is more specific */ <style> p { color: blue; } p { color: green; } .note { color: red; } </style> <p>A plain paragraph: green wins, it is the last rule.</p> <p class="note">A paragraph with class="note": red wins, a class beats a tag.</p>     All the selectors on a real page Download [The Pixel Times|download](unitats/programacio/web/html-css/exercises/09-css-basics/selectors.html): a school magazine with a header, a menu, cards, lists, a table, a form and a footer, and no CSS at all. Create css/style.css next to it (the HTML already links it) and add the rules below *one by one*. Save and reload after each one to see what changes. Some rules use properties from the next units (padding, border-radius, border...). Copy them as they are: they are there so the page looks nice. Today we look at the *selectors*. Tags, groups and id *1.* *Universal selector* *: it selects every element of the page. * { font-family: Arial, Helvetica, sans-serif; } *2.* *Tag selectors*: all the elements of that tag. body { background-color: #f4f1fb; color: #333333; margin: 0; } p { line-height: 1.6; } *3.* *Group* several selectors with commas: one rule for four tags. h1, h2, h3, h4 { color: #4b3f8f; } *4.* *id selector* #: only one element in the page has this id. #main-title { color: white; font-size: 48px; margin: 0; } Descendants and classes *5.* *Descendant selector* (a space): header p means the paragraphs that are inside the header. The other paragraphs do not change. header { background-color: #6d5fb3; padding: 30px; text-align: center; } header p { color: #e4defa; } *6.* The *same tag in different places*: the links of the menu and the links of the footer look different. nav a { color: white; text-decoration: none; font-weight: bold; margin: 0 12px; } footer a { color: #ffd166; } *7.* *Class selectors* .: all the elements with that class. Look at .date: it is also a p, but the class wins because it is more specific. .card { background-color: white; padding: 20px; margin-bottom: 20px; border-radius: 10px; } .date { color: #888888; font-size: 14px; } .warning { color: #c0392b; font-weight: bold; } .note { background-color: #fff6d6; padding: 8px; } *8.* *Two classes together*, with no space: only the elements that have both classes (class="card featured"). With a space, .card .featured, it would look for a .featured inside a .card, and there is none. .card.featured { border-left: 6px solid #ffd166; } *9.* *Class + descendant*: only the h3 inside the review cards. .review h3 { color: #e07a5f; } *10.* Two lists with the *same tags but different classes*. .pros li { color: #2e7d32; } .cons li { color: #c0392b; } .score { font-size: 22px; font-weight: bold; text-align: right; } Pseudo-classes: :hover *11.* :hover: when the mouse is over the element. Move the mouse over the menu, the cards and the button. nav a:hover { color: #ffd166; } .card:hover { background-color: #fbfaff; } button:hover { background-color: #4b3f8f; } There are more selectors: children, siblings, positions, attributes... We will finish The Pixel Times with them later, in [Advanced selectors](unitats/programacio/web/html-css/14b-advanced-selectors.html). Exercises Every exercise is a small page: you write the HTML exactly as it is described (tags, ids, classes, types...) and then the CSS rules in css/style.css. Do not change the HTML to make the CSS easier. *Exercise 9.1. My favourite film.* Create film.html and css/style.css, and link the CSS from the <head>. *HTML.* Create these elements:
  • an <h1> with the title of the film;
  • three <p> that explain what the film is about;
  • an <h2> with the text “Main actors” and a <ul> with four <li>, one actor each.
    •  *CSS.* Write these rules:
  • a comment at the top of the file with your name: /* Made by ... */;
  • body: background colour #f5f5f5 and text colour #333333;
  • h1: colour darkred;
  • h2: colour #4b3f8f;
  • li: colour #555555.
    •  Check in the HTML that there is no style= attribute: all the design is in the CSS file. *Exercise 9.2. A recipe with classes and an id.* Create recipe.html, linked to the same css/style.css. *HTML.* Create these elements:
  • an <h1> with id="recipe-title" and the name of the recipe;
  • an <h2> “Ingredients” followed by a <ul> with class="ingredients" and five <li>;
  • an <h2> “Steps” followed by an <ol> with class="steps" and four <li>;
  • one <p> with class="tip" with a cooking tip;
  • two <p> with class="warning" (for example: “Careful, the oven is hot!”).
    •  *CSS.* Write these rules:
  • h1, h2 in one single rule (a group): font Arial, sans-serif;
  • #recipe-title: colour #e07a5f and size 40px;
  • .ingredients: colour #2e7d32;
  • .steps: colour #3d405b;
  • .tip: background colour #fff3b0;
  • .warning: colour #c0392b and bold text (font-weight: bold).
    •  *Exercise 9.3. A school page with descendants.* Create school.html. In this exercise *you cannot use classes or ids*: only tag selectors and descendant selectors (with a space). *HTML.* Create these elements:
  • a <header> with an <h1> (the name of your school) and a <p> (the town);
  • a <main> with two <article>; each article has an <h2> and two <p>;
  • a <footer> with a <p> and two <a> (to the website of the school and to your town hall).
    •  *CSS.* Write these rules:
  • header p: colour #777777;
  • article p: line-height: 1.6;
  • article h2: colour #6d5fb3;
  • footer p: size 14px;
  • footer a: colour green.
    •  Check that the paragraph of the header and the paragraphs of the articles look different, even if they are all <p>. *Exercise 9.4. A menu with hover and featured cards.* Create cards.html. *HTML.* Create these elements:
  • a <nav> with four <a> (Home, News, Games, Contact); the first one has class="active";
  • three <div> with class="card", each one with an <h3> and a <p>;
  • the second card has *two classes*: class="card featured".
    •  *CSS.* Write these rules:
  • nav a: colour #6d5fb3, *no underline* (text-decoration: none) and bold;
  • nav a:hover: colour #e07a5f;
  • nav a.active: colour black;
  • .card: background colour white, padding: 20px and margin-bottom: 20px;
  • .card.featured: border-left: 6px solid #ffd166;
  • .card:hover: background colour #f4f1fb;
  • body: background colour #eeeeee.
    •  *Exercise 9.5. Colours and the cascade.* Create colours.html. *HTML.* Create these elements:
  • four <p> with the classes name, hex, rgb and rgba, with the texts “Red as a name”, “Red in hexadecimal”, “Red in rgb” and “Red half transparent”;
  • two more <p> without class, and a third one with class="note".
    •  *CSS.* Write these rules:
  • .name: colour red; .hex: colour #ff0000; .rgb: colour rgb(255, 0, 0); .rgba: colour rgba(255, 0, 0, 0.5);
  • then, in this order: .note in purple, p in blue and p in green.
