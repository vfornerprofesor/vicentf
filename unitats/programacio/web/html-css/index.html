Web Pages with HTML and CSS Situació d'aprenentatge (professorat)
Welcome! In this module you will learn to build web pages from zero. You do *not* need to know anything about programming to start. We use two languages. *HTML* puts the content in the page: titles, text, images, links. *CSS* decides how that content looks: colours, sizes, position on the screen. At the end you will build your own personal website with four pages, and it will work on a phone too. What you will learn
  • How a web page works: the browser, the files, and the folder where you keep them.
  • How to write HTML: the tags that give a page its structure and its content.
  • How to write text, lists, links, images, tables and forms.
  • How to use semantic tags, so people and machines understand your page.
  • How to write CSS: the language that gives your page colours, fonts and layout.
  • How to place boxes on the screen with the box model, flexbox and grid.
  • How to make a page that looks good on a phone and on a computer.
  • How to build a complete personal website, from an empty folder to a finished site.
    •      How I know I have learned it RA1 — I can build web pages with HTML
  • I write a complete HTML skeleton (doctype, html with lang, head with charset and title, body), with every tag closed and well nested, my code indented, comments, headings in order, special characters and correct file names.
  • I add lists (ordered, unordered and nested), relative and absolute links that connect the pages of my site, images with a descriptive alt text and relative paths, and tables with a header row and merged cells.
  • I build forms with a label for each field, different input types (text, email, password, date, radio, checkbox, select, textarea), basic validation with required and fields grouped with fieldset.
  • I organise the page with semantic tags (header, nav, main, section, article, footer) and I fix my code until the W3C validator shows zero errors.
    •  RA2 — I can style and lay out web pages with CSS
  • I link an external style sheet and use tag, class, id, descendant and :hover selectors, solving conflicts between rules. I style text (web fonts, sizes in rem, line height, colours, backgrounds) with good contrast.
  • I use the box model (padding, border, margin, box-sizing, block and inline elements, border-radius, box-shadow) and I centre the content in a container with a maximum width.
  • I lay out components and pages with flexbox (a navigation bar, rows of cards that wrap) and with grid (galleries, two-column layouts), and I choose the right technique for each case.
  • I adapt my design to phone, tablet and computer with the viewport tag, flexible images and media queries, working ~mobile first~.
  • I organise my style sheet with CSS variables, commented sections and consistent names, I add transitions, I check my site with a checklist before delivering it, and I explain my decisions in a short presentation.
