Exercise 1 · Selectors · about 8 min

In style.css, write these two rules:

  1. Only the paragraphs with class lead that are inside the section with class intro must have: font size 1.25rem, colour #1f3c5a and line height 1.6.
    The paragraph lead of the news section must not change.
  2. The title with the id title must be centred and in uppercase.

Exercise 2 · Box model · about 8 min

This is the CSS of a box in a web page:

.card {
    width: 200px;
    height: 120px;
    padding: 15px 25px;
    border: 4px solid #1f3c5a;
    margin: 10px 30px;
}

In answers.txt answer these two questions. Write the calculation, not only the result.

  1. With the default box-sizing, what is the real width and height of the visible box?
  2. If we add box-sizing: border-box to the rule, what is the width and the height of the visible box, and what is the width and the height of the content area?

Exercise 3 · Centre with flexbox · about 6 min

In the section Centre the box, the dark box (.box) is stuck in the top left corner of its light container (.stage). With flexbox, write the CSS that puts the box in the exact centre of the container, horizontally and vertically.

Note: do not change the size of the box or the container.

Exercise 4 · Navigation bar · about 10 min

Now the menu is a vertical list with bullets. Write the CSS to make a horizontal navigation bar with flexbox:

  • The four links in one row, centred in the page, with a space of 1rem between them.
  • No bullets in the list and no extra margin or padding.
  • Every link looks like a button: padding 0.5rem 1rem, background #1f3c5a, white text, rounded corners of 6px and no underline.
  • When the mouse is over a link: background #f2a541 and text #1f3c5a.

Exercise 5 · Gallery with grid · about 8 min

Write the CSS to make the six photos (.photo) of the section Gallery a grid of 3 columns of the same width, with a space of 1rem between them. The photos must be two rows of three.

Exercise 6 · Find the errors · about 12 min

Open errors.html in the browser. The CSS file errors.css has 5 errors and because of them the page does not look as it should. Fix them in errors.css.

When all the errors are fixed, the page must look like this:

  • The title is centred and its lines have a height of 1.5.
  • The page has a light grey background and no margin.
  • The two products are white boxes of 300px of width, centred in the page, with a thin grey border, some padding and dark grey text.

Tip: write a comment next to each error you fix. It helps you to count them.
