CSS exam · Retro Games Club

Name: ______________________________ Group: ________ Date: ____/____/________ Time: 55 minutes

The page of the Retro Games Club has all its HTML, but no style. You write all its CSS, from the colours of the text to the layout of the page.

Before you start

  • Create a folder called surname-name-css and copy inside it exam.html and style.css from the starter folder.
  • In exam.html you only add the line that links style.css, in the right place. Do not change anything else in the HTML: no style=, no new classes.
  • You write your CSS in style.css, under the comment of each exercise. The CSS under "Given styles" is already written: do not change it.
  • You can use VS Code, the browser and its developer tools. You cannot use notes, the lessons, the internet to search for answers, a mobile phone or any AI tool.
  • Save often. At the end, hand in the whole folder.

How your code is marked

  • Each selector must choose only the elements that the exercise asks for.
  • Sizes of text in rem. Colours in hexadecimal, as in the exercise.
  • The CSS validator must say 0 errors.

Exercise 1 · Text and boxes · about 25 min

  1. The page. No margin around the page, background #f4f3fa, text #23272f, font Arial (or Helvetica, or any sans-serif) and lines with a height of 1.5. The content of main (class container) is never wider than 960px, it is centred in the page and it has 1rem of space on the left and on the right.
  2. The title (id title): centred, in uppercase and with the colour #1f3c5a.
  3. The lead paragraphs. Only the paragraphs with class lead that are inside the section intro: font size 1.25rem, colour #1f3c5a and line height 1.6. The lead paragraph of the news must not change.
  4. The box of the tournament (class box): width 200px, height 100px, padding 10px 20px, a border of 5px solid #f2a541, background #1f3c5a and white text.
    • Inside the rule, write a comment with the calculation (not only the result): A) what is the real width and height of the visible box now?
    • Then add box-sizing: border-box to the rule and answer in the same comment: B) what is the width and height of the visible box now, and of the content area?
    • Check your answers with the box model of the developer tools.
  5. The cards (class card): white background, padding 1rem, a thin border #d8d6e3, rounded corners of 8px and a soft shadow.

Exercise 2 · The layout · about 25 min

  1. Navigation bar (with flexbox). The four links in one row, centred in the page, with 1rem between them. No bullets and no extra margin or padding in the list. Each link looks like a button: padding 0.5rem 1rem, background #1f3c5a, white text, rounded corners of 6px and no underline. When the mouse is over a link: background #f2a541 and text #1f3c5a.
  2. The tournament (with flexbox). The box is in the exact centre of its light container (.stage), horizontally and vertically. Do not change the size of the container.
  3. The cards (with flexbox). The three cards side by side, with the same width and 1rem between them. When the window is narrow (try it), they go down to a new line instead of getting very thin.
  4. The gallery (with grid). The six photos in 3 columns of the same width, with 1rem between them: two rows of three.

Tip: before you write each layout, think which element is the container: display: flex and display: grid go in the parent, not in the children.

Before you hand in

  • Your folder has exam.html and style.css, and the page shows your styles.
  • Make the window narrow and wide: the cards go down, the content stays centred.
  • Run the CSS validator on style.css.
