Flexbox
The problem flexbox solves Until now, every block element takes a full line. But real pages have things *side by side*: a menu across the top, three cards in a row, a logo on the left and buttons on the right. *Flexbox* puts elements in a row (or in a column) and shares the space between them. It is one line of CSS to start. The container and the items You always work with *two levels*: the ~container~ (the parent) and the ~items~ (its direct children). <div class="row"> <div class="item">One</div> <div class="item">Two</div> <div class="item">Three</div> </div> .row { display: flex; } That is it. The three boxes are now in a row. *You put display: flex on the parent, never on the children.* Both files together, in the browser: <style> .row { display: flex; gap: 12px; } .item { padding: 16px 24px; background: #c4baeb; border-radius: 8px; } </style> <div class="row"> <div class="item">One</div> <div class="item">Two</div> <div class="item">Three</div> </div> (The previews in this lesson also give .item a background, some padding and rounded corners, just so the boxes are visible — only the flex properties shown in the code above are actually part of the lesson.) Without flexbox With display: flex Direction .row { display: flex; flex-direction: row; /* the default: left to right */ flex-direction: column; /* top to bottom */ } <style> .row { display: flex; flex-direction: column; gap: 12px; } .item { padding: 16px 24px; background: #c4baeb; border-radius: 8px; } </style> <div class="row"> <div class="item">One</div> <div class="item">Two</div> <div class="item">Three</div> </div> justify-content Space along the row: .row { display: flex; justify-content: flex-start; /* all at the start (default) */ justify-content: center; /* all in the centre */ justify-content: flex-end; /* all at the end */ justify-content: space-between; /* first at the start, last at the end, equal gaps */ justify-content: space-around; /* equal space around each item */ } <style> .row { display: flex; justify-content: space-around; } .item { padding: 16px 24px; background: #c4baeb; border-radius: 8px; } </style> <div class="row"> <div class="item">One</div> <div class="item">Two</div> <div class="item">Three</div> </div> justify-content: center justify-content: space-between justify-content: space-around align-items Space across the row: .row { display: flex; height: 200px; align-items: stretch; /* items fill the height (default) */ align-items: center; /* vertically centred */ align-items: flex-start; /* at the top */ align-items: flex-end; /* at the bottom */ } <style> .row { display: flex; height: 200px; align-items: flex-end; gap: 12px; background: #f5f5f5; } .item { padding: 16px 24px; background: #c4baeb; border-radius: 8px; } </style> <div class="row"> <div class="item">One</div> <div class="item">Two<br>lines of text</div> <div class="item">Three<br>lines<br>of<br>text</div> </div> justify-content works along the direction of the row. align-items works across it. If you change flex-direction to column, the two swap meaning. gap .row { display: flex; gap: 20px; /* space between items */ } <style> .row { display: flex; gap: 20px; } .item { width: 60px; height: 60px; background: #c4baeb; border-radius: 8px; } </style> <div class="row"> <div class="item"></div> <div class="item"></div> <div class="item"></div> </div> gap is the modern way to separate flex items. Before, we used margins and it was painful. flex-wrap .row { display: flex; flex-wrap: wrap; /* if there is no room, go to the next line */ } Without wrap, five cards in a narrow screen get squashed to nothing. With wrap, they jump to a second line. Almost always you want wrap. <style> .row { display: flex; gap: 10px; } .item { flex: 1 1 120px; padding: 12px; background: #c4baeb; border-radius: 8px; text-align: center; } </style> <div class="row"> <div class="item">Card 1</div> <div class="item">Card 2</div> <div class="item">Card 3</div> <div class="item">Card 4</div> <div class="item">Card 5</div> </div> <style> .row { display: flex; flex-wrap: wrap; gap: 10px; } .item { flex: 1 1 120px; padding: 12px; background: #c4baeb; border-radius: 8px; text-align: center; } </style> <div class="row"> <div class="item">Card 1</div> <div class="item">Card 2</div> <div class="item">Card 3</div> <div class="item">Card 4</div> <div class="item">Card 5</div> </div> Making a nav bar <header class="site-header"> <div class="logo">Marc Ferrer</div> <nav> <ul class="menu"> <li><a href="index.html">Home</a></li> <li><a href="about.html">About</a></li> <li><a href="contact.html">Contact</a></li> </ul> </nav> </header> .site-header { display: flex; justify-content: space-between; align-items: center; padding: 15px 30px; background-color: #2b2b40; } .logo { color: white; font-weight: bold; font-size: 1.3rem; } .menu { display: flex; gap: 25px; list-style: none; /* removes the bullet points */ margin: 0; padding: 0; } .menu a { color: white; text-decoration: none; } .menu a:hover { color: #ffcc00; } Both files together, in the browser: <style> .site-header { display: flex; justify-content: space-between; align-items: center; padding: 15px 30px; background-color: #2b2b40; } .logo { color: white; font-weight: bold; font-size: 1.3rem; } .menu { display: flex; gap: 25px; list-style: none; margin: 0; padding: 0; } .menu a { color: white; text-decoration: none; } .menu a:hover { color: #ffcc00; } </style> <header class="site-header"> <div class="logo">Marc Ferrer</div> <nav> <ul class="menu"> <li><a href="index.html">Home</a></li> <li><a href="about.html">About</a></li> <li><a href="contact.html">Contact</a></li> </ul> </nav> </header> Making a row of cards .cards { display: flex; flex-wrap: wrap; gap: 20px; justify-content: center; } .card { flex: 1 1 280px; /* grow, shrink, minimum width 280px */ max-width: 350px; } <style> .cards { display: flex; flex-wrap: wrap; gap: 20px; justify-content: center; } .card { flex: 1 1 280px; max-width: 350px; padding: 20px; background: #f5f5f5; border-radius: 12px; text-align: center; } </style> <div class="cards"> <div class="card">Card one</div> <div class="card">Card two</div> <div class="card">Card three</div> <div class="card">Card four</div> </div> (The preview also gives .card some padding, a light background and rounded corners, just so each card is visible as a box — only flex and max-width are in the lesson's code.) flex: 1 1 280px means: this card can grow to fill space, can shrink if needed, and its base width is 280px. With wrap, you get a grid that adapts by itself. Exercises Every exercise is a small page: you write the HTML exactly as it is described (tags, ids, classes, types...) and then the CSS rules in css/style.css. Do not change the HTML to make the CSS easier. *Exercise 12.1. Three ways to put boxes in a row.* Create rows.html. *HTML.* Create these elements:
  • three <div> one after the other, with the classes row, row between and row column;
  • inside each one, three <div> with class="box" and the texts One, Two, Three.
    •  *CSS.* Write these rules:
  • .row: display: flex, justify-content: center, gap: 20px, padding: 20px, margin-bottom: 20px and background colour #eeeeee;
  • .box: width 100px, height 100px, background colour #c4baeb and border-radius: 8px;
  • .row.between: justify-content: space-between;
  • .row.column: flex-direction: column and align-items: center.
    •  Write a <p> under each row explaining what changes. *Exercise 12.2. A box in the middle.* Create centre.html. *HTML.* Create these elements:
  • a <div> with class="screen";
  • inside, a <div> with class="message" with an <h2> (“Welcome!”) and a <p>.
    •  *CSS.* Write these rules:
  • .screen: height 400px, display: flex, justify-content: center, align-items: center and background colour #2b2b40;
  • .message: background colour white, padding: 30px, border-radius: 12px and centred text.
    •  *Exercise 12.3. A navigation bar.* Create navbar.html. *HTML.* Create these elements:
  • a <header> with class="site-header";
  • inside: a <div> with class="logo" and your name, and a <nav> with a <ul> with class="menu";
  • the <ul> has four <li>, each one with an <a>: Home, Projects, About, Contact.
    •  *CSS.* Write these rules:
  • .site-header: display: flex, justify-content: space-between, align-items: center, padding: 15px 30px and background colour #2b2b40;
  • .logo: colour white, bold and size 1.5rem;
  • .menu: display: flex, gap: 20px, list-style: none, margin: 0 and padding: 0;
  • .menu a: colour white and no underline;
  • .menu a:hover: colour #ffd166.
    •  *Exercise 12.4. A row of cards that wraps.* Create cards.html. *HTML.* Create these elements:
  • a <section> with class="cards";
  • inside, six <article> with class="card"; each one with an <img>, an <h3> and a <p>.
    •  *CSS.* Write these rules:
  • .cards: display: flex, flex-wrap: wrap and gap: 20px;
  • .card: flex: 1 1 250px, background colour white, padding: 15px, border-radius: 10px and box-shadow: 0 2px 8px rgba(0, 0, 0, 0.12);
  • .card img: width 100% and border-radius: 8px;
  • body: background colour #f4f1fb.
    •  Make the window narrower: the cards go down to a second (and a third) line by themselves.     More exercises *Exercise 12.5. A bar menu.* Create bar-menu.html. The picture is the model. *HTML.* Create these elements:
  • a <header> with an <h1> (the name of the bar);

    •  *CSS.* Write these rules:

  • .band-header, h2: centred text;
  • .menu: display: flex, justify-content: center and gap: 40px;
  • .menu-button: padding: 10px, border: 1px solid white, border-radius: 5px, colour white, no underline, bold and in capitals;
  • .menu-button:hover: background colour white and colour #2a2a2a;
  • .main-photo: width 50%, display: block and margin: 0 auto;
  • .gallery: display: flex, flex-wrap: wrap and justify-content: space-around;
  • .gallery img: max-width: 400px and margin: 20px;
  • .songs: display: flex, justify-content: space-around and centred text.
