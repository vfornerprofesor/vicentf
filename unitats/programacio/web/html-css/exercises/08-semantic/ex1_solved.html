Computer Networks and Systems

Study programme overview

Year 2 - 24/25

Computer security

Computer security is essential to protect systems and data from external threats. In this module you will learn to identify and reduce risks to the security of computer systems. You will study different types of attacks, such as viruses, trojans and denial-of-service attacks, and you will learn to apply security measures to prevent them. You will also explore concepts such as firewalls, intrusion detection systems and cryptography.

Network operating systems

A network operating system is software that manages a computer's resources and allows communication with other computers connected to the network. This module will teach you to configure and manage network operating systems, such as Windows Server and Linux. You will learn to create and manage user accounts, share resources between different computers and configure network services. You will also explore concepts such as domains, workgroups and network protocols.

Web applications

In this module you will learn to develop and manage web applications. Web applications are programs that run on a server and are displayed through a web browser. These applications are the basis of many online services we use every day, such as social networks, online shops and email. You will study the programming languages used to build web applications, such as HTML, CSS and JavaScript, and you will learn to design intuitive and functional user interfaces. You will also explore concepts such as databases, web security and performance optimisation.

Network services

Network services are programs that run on a server and provide specific functions to other devices connected to the network. This module will teach you to configure and manage several network services, such as email servers, web servers, FTP servers and database servers. You will learn to configure the communication protocols needed for each service and to ensure their availability and security. You will also explore concepts such as IP addresses, DNS and communication ports.
