CSS variables and good practice
Repeating yourself is a bug Imagine your main colour #6d5fb3 appears 30 times in your CSS. Your client says "make it a bit darker". Now you have to find and change 30 lines, and you will miss two. CSS variables A *variable* is a name that holds a value. You write the value once, and you use the name everywhere. :root { --main-color: #6d5fb3; --main-color-dark: #4f4488; --text-color: #2b2b2b; --light-grey: #f5f5f5; --radius: 12px; --shadow: 0 2px 8px rgba(0, 0, 0, 0.12); } .button { background-color: var(--main-color); border-radius: var(--radius); box-shadow: var(--shadow); } .button:hover { background-color: var(--main-color-dark); } <style> :root { --main-color: #6d5fb3; --main-color-dark: #4f4488; --text-color: #2b2b2b; --light-grey: #f5f5f5; --radius: 12px; --shadow: 0 2px 8px rgba(0, 0, 0, 0.12); } body { padding: 20px; background: var(--light-grey); } .button { background-color: var(--main-color); border-radius: var(--radius); box-shadow: var(--shadow); color: white; border: 0; padding: 10px 20px; font-size: 1rem; cursor: pointer; } .button:hover { background-color: var(--main-color-dark); } </style> <button class="button">Click me</button>
  • :root means "the whole document". Put your variables there, at the top of the file.
  • A variable name always starts with two dashes: --main-color.
  • To use it: var(--main-color).
    •  Now, changing the whole site is changing *one line*. This is exactly how this website you are reading works. Open styles/general.css and you will see the same :root block with the colours of the site.     A small design system Define, at the start of your project:
  • *3 to 5 colours*: one main, one dark version, one light background, one text colour, maybe one accent.
  • *2 fonts* maximum.
  • *One radius* and *one shadow*, used everywhere.
  • *A spacing scale*: 8px, 16px, 24px, 32px. Do not invent random numbers like 13px or 27px.
    •  A page looks professional when the same few decisions are repeated, not when it has many different ones.     Organising your CSS file /* ============ 1. Variables ============ */ :root { ... } /* ============ 2. Reset and base ============ */ * { box-sizing: border-box; } body { ... } /* ============ 3. Layout ============ */ .container { ... } .site-header { ... } .site-footer { ... } /* ============ 4. Components ============ */ .button { ... } .card { ... } /* ============ 5. Media queries ============ */ @media (min-width: 768px) { ... } Naming things Class names in English, lowercase, with dashes: main-menu, product-card, price-tag. Name things by *what they are*, not by how they look. .red-text is a bad name: the day you change it to blue, the name lies. .error-message is a good name. Keep it short: 0.2s to 0.4s. Longer feels slow. Checklist before you deliver
  • The page passes the W3C validator with no errors.
  • Every image has a real alt.
  • Every input has its label.
  • There are no style= attributes left in the HTML.
  • All the colours come from variables.
  • It works on a 375px wide screen with no horizontal scrolling.
  • All the links work (test every one).
  • File and folder names: lowercase, no spaces, no accents.
    •      Exercises Every exercise is a small page: you write the HTML exactly as it is described (tags, ids, classes, types...) and then the CSS rules in css/style.css. Do not change the HTML to make the CSS easier. *Exercise 15.1. A page with variables.* Create variables.html. *HTML.* Create these elements:
  • a <header> with an <h1>;
  • a <main> with three <div> with class="card", each one with an <img>, an <h2>, a <p> and an <a> with class="btn".
    •  *CSS.* Write these rules:
  • a :root block with four variables: --main-color: #6d5fb3, --main-color-dark: #4b3f8f, --light-grey: #f4f1fb and --text-color: #333333;
  • body: colour var(--text-color) and background colour var(--light-grey);
  • header: background colour var(--main-color), colour white and padding: 20px;
  • h2: colour var(--main-color);
  • .btn: background colour var(--main-color), colour white, no underline and padding: 8px 16px;
  • .btn:hover: background colour var(--main-color-dark).
    •  Change only --main-color to #e07a5f: the header, the titles and the buttons change at the same time. *Exercise 15.2. Radius and shadow.* Continue with variables.html. *HTML.* Create these elements:
  • the same HTML as exercise 15.1.
    •  *CSS.* Write these rules:
  • add to :root: --radius: 12px and --shadow: 0 2px 8px rgba(0, 0, 0, 0.12);
  • .card: background colour white, padding: 20px, border-radius: var(--radius) and box-shadow: var(--shadow);
  • .card img: width 100% and border-radius: var(--radius);
  • .btn: border-radius: var(--radius).
    •  *Exercise 15.3. Smooth transitions.* Continue with variables.html. *HTML.* Create these elements:
  • the same HTML as exercise 15.1.
    •  *CSS.* Write these rules:
  • .card: transition: transform 0.3s ease;
  • .card:hover: transform: translateY(-5px);
  • .btn: transition: background-color 0.3s ease and cursor: pointer.
    •  *Exercise 15.4. Put your CSS in order.* Take the CSS of variables.html and organise it. *HTML.* Create these elements:
  • no changes in the HTML, except the class names that you rename in the CSS.
    •  *CSS.* Write these rules:
  • five section comments, in this order: /* ============ 1. Variables ============ */, 2. Reset and base, 3. Layout, 4. Components and 5. Media queries;
  • move every rule to its section;
  • add a @media (min-width: 900px) in the last section that puts the three cards in a row with display: grid and grid-template-columns: repeat(3, 1fr) on main;
  • if a class has a name that says how it looks (.red, .big, .box1), rename it to what it is (.warning, .title, .card), in the HTML and in the CSS.
