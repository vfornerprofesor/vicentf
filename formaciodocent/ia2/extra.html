  • Chat.
  • Cowork: treballa amb els fitxers d'una carpeta de l'ordinador; llig, crea i organitza documents, fulls de càlcul i presentacions.
  • Code: crea aplicacions; tu només parles, ell escriu el codi i el prova.

Claude Code a l'app d'escriptori
Idea: una app web amb lliçons curtes, vides, ratxa de dies, punts d'experiència, nivells que es desbloquegen i retroacció immediata. Es guarda com a fitxers en una carpeta i s'obri amb el navegador (i es pot publicar gratis, per exemple arrossegant la carpeta a [Netlify Drop](https://app.netlify.com/drop) o a [GitHub Pages](https://pages.github.com)). Exemple de primària: «Taules campiones» (3r-4t) Infantil/Primària Crea una aplicació web en una carpeta nova, tot en valencià, tipus Duolingo, per practicar les taules de multiplicar. Requisits: un camí de nivells (taula del 2 al 10, i un nivell final barrejat) que es desbloquegen en superar l'anterior; cada lliçó té 10 preguntes de tipus variat (triar resposta, escriure el resultat, arrossegar el número que falta); 3 vides per lliçó; punts d'experiència i ratxa de dies guardats al navegador; animació i so quan encerten; botons grans per a tauleta. Quan acabes, obri-la al navegador perquè la prove. Exemple de secundària: «Vocab Quest» (anglés 2n ESO) Secundària Adaptable a qualsevol matèria. Crea una app web tipus Duolingo per aprendre vocabulari d'anglés de 2n d'ESO. Els continguts han d'estar en un fitxer `vocabulari.json` separat perquè jo puga afegir unitats sense tocar el codi. Unitats: "Food", "Travel", "Jobs" (20 paraules cada una, amb frase d'exemple). Tipus d'exercici: traducció, escoltar i escriure (usa la veu del navegador), completar la frase, parelles. Vides, ratxa, XP, repàs automàtic de les paraules fallades i pantalla de resultats final. Interfície en valencià. Itera: «fes-la més colorida», «afegeix un mode professor per veure els errors més freqüents», «afegeix la unitat 4 amb aquestes paraules: …». Prompts d'iteració Fes-la més colorida: Fes la interfície més colorida i atractiva per a [alumnat de 3r-4t de primària]: colors vius, cantonades arrodonides, un personatge mascota que reaccione als encerts i als errors, i animacions suaus. No canvies el funcionament ni el contingut. Quan acabes, obri-la al navegador perquè la prove. Mode professor per veure els errors més freqüents: Afegeix un mode professor, protegit amb una contrasenya senzilla ([1234]), que mostre per a cada lliçó les preguntes més fallades i el percentatge d'encert, a partir de les dades guardades al navegador. Afegeix un botó per exportar aquestes dades a un fitxer CSV. Afegir una unitat (joc de secundària): Afegeix la unitat 4, «[School]», al fitxer vocabulari.json amb aquestes paraules i frases d'exemple: [enganxa la llista]. Comprova que apareix al camí de nivells, que es desbloqueja en superar la unitat 3 i que tots els tipus d'exercici funcionen amb les paraules noves. Publicar el joc Abans d'arrossegar la carpeta a Netlify Drop o a GitHub Pages, demana a Claude Code que la deixe preparada: Prepara l'aplicació per publicar-la com a web estàtica: comprova que funciona obrint només index.html, que totes les rutes són relatives i que no necessita cap servidor ni cap instal·lació. Després explica'm pas a pas, sense usar el terminal, com publicar-la gratis arrossegant la carpeta a Netlify Drop, i com obtindre l'enllaç per compartir-lo amb l'alumnat. Corregir entregues a partir de fotos
Claude Cowork
Funciona amb fotos? Sí, amb matisos: Claude llig bé la lletra manuscrita clara de secundària i de primària a partir de 3r-4t; costa més amb lletra d'infantil/1r cicle, fotos tortes, amb ombres o en llapis fluix.
  • Foto zenital, bona llum, una pàgina per foto (o escaneja amb el mòbil: Google Drive o l'app de càmera en mode document).
  • Funciona millor amb respostes curtes o problemes que amb redaccions llargues de lletra difícil.
  • La IA proposa, el professorat decidix: revisa sempre la nota i el comentari.
  • Protecció de dades: anomena els fitxers amb un codi (A01.jpg, A02.jpg), no amb el nom; no fotografies el nom (tapa'l o doblega la capçalera). La relació codi–nom només la té el professor.
